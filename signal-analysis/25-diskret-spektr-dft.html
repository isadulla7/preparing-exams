25. Diskret spektr, polosa va DFT ga kirish

O'qish vaqti: 50 daqiqa. Manba: 29-ma'ruza ("Energy spectrum, bandwidth of a discrete-time signal. Example of DTFT. Introduction to Discrete Fourier Transform"). Kerakli bilim: DTFT (24-dars), polosa ta'riflari (15-dars), energiya spektri (17-dars).

Bu B mavzu. Imtihonda: "Diskret Parseval: E = ?", "aⁿu(n) ning energiya spektri?", "cos(2πf0n) ning DTFT si?", "2K + 1 ta birlik DTFT si?", "N nuqtali DFT ta'rifi / teskarisi?", "DFT va DTFT bog'liqligi (fk = k/N)?", "FFT murakkabligi?", "{…} ning 4 nuqtali DFT si?".
Bu darsda nimani bilib olasiz: diskret energiya spektri va Parseval tengligi (isboti bilan); diskret signal polosasining 4 ta'rifi; muhim DTFT juftliklari (δ, 1, ej2πf0n, cos, sin, to'rtburchak); DFT — nima uchun kerak, ta'rifi, teskarisi (isboti bilan), davriy kengaytma; FFT va uning tezligi; DFT ni qo'lda hisoblash.

1. Diskret signal energiya spektri

Sx(f) = |X(ej2πf)|²

x(n) energiyasining garmonik tashkil etuvchilar (chastotalar) bo'yicha taqsimlanishi — 17-darsdagining diskret varianti. Xossalari: haqiqiy va Sx(f) ≥ 0 har doim; x(n) haqiqiy bo'lsa — juft (simmetrik); davri 1.

Ma'ruza misoli: x(n) = aⁿu(n), a haqiqiy, |a| < 1. X = 1/(1 − ae−j2πf).

Sx(f) = 1/[(1 − ae−j2πf)(1 − ae+j2πf)] = 1/(1 + a² − ae−j2πf − aej2πf) = 1/(1 + a² − 2a·cos(2πf))

(|X|² = X·X*, haqiqiy a da X* = 1/(1 − ae+j2πf); ejθ + e−jθ = 2cos θ.) a = 0,5: S(0) = 1/(1 − a)² = 4, S(½) = 1/(1 + a)² = 4/9.

2. Parseval tengligi

Ex = Σk=−∞+∞ |x(k)|² = ∫−½½ |X(ej2πf)|² df

Ketma-ketlik energiyasi = DTFT modul kvadratining bitta davr bo'yicha integrali.

Isbot: |x(k)|² = x(k)·x*(k). x*(k) ni IDTFT (24-dars) bilan yozamiz: x*(k) = [∫X(ej2πf)ej2πfkdf]* = ∫X*(ej2πf)e−j2πfkdf. Yig'indi va integralni almashtiramiz:

E = ∫−½½ X*(ej2πf)·[Σkx(k)e−j2πfk]df = ∫−½½ X*·X df = ∫−½½ |X|² df ✓

Tekshiruv 1: {1, 0, 3, −2}: E = 1 + 9 + 4 = 14. |1 + 3e−j4πf − 2e−j6πf|² ni ochsak, turli e−j2πfm (m ≠ 0) li hadlar bitta davr bo'yicha 0 ga integrallanadi, faqat 1² + 3² + 2² = 14 qoladi ✓.

Tekshiruv 2: aⁿu(n): E = Σa2n = 1/(1 − a²). a = 0,5 → E = 4/3 (∫Sxdf ham shuni beradi).

3. Diskret signal polosasi

Analog signallardagi kabi (15-dars) bir nechta ta'rif bor, hammasi Sx(f) ga asoslangan. Farqi: chastota raqamli, faqat [−½, ½] da qaraladi.

  • Absolyut polosa Bx < ½: |X(ej2πf)| oraliq [−Bx, Bx] dan tashqarida (bitta davr ichida) aynan nol.
  • Ekvivalent polosa Beq: asosi [−Beq, Beq], balandligi Sx maksimumi XM² bo'lgan to'g'ri to'rtburchak energiyasi signal energiyasiga teng: 2Beq·XM² = ∫−½½Sxdf = Σ|x(n)|².
  • Bx%: energiyaning x% i joylashgan eng kichik oraliq: ∫−BBSxdf = (x/100)·Σ|x(n)|².
  • 3 dB polosa: Sx(B3dB) = XM²/2.

Misol: aⁿu(n), a = 0,5. XM² = S(0) = 4, E = 4/3.

Beq = E/(2XM²) = (4/3)/8 = 1/6 ≈ 0,167.

B3dB: 1/(1,25 − cos 2πB) = 2 → 1,25 − cos 2πB = ½ → cos 2πB = 0,75 → 2πB = 0,7227 → B3dB ≈ 0,115.

Agar fc = 1 kHz bilan diskretlangan bo'lsa: fizik 3 dB polosa ≈ 0,115·1000 = 115 Hz.

4. Muhim DTFT juftliklari (ma'ruza)

δ(n) ↔ 1: Σδ(k)e−j2πfk = e0 = 1 — barcha chastotalar teng (analogdagi δ(t) ↔ 1 kabi).

x(n) = 1 ↔ Σnδ(f − n): Σe−j2πfn — 16-darsdagi Puasson formulasi (T = 1). Bitta davrda [−½, ½]: X = δ(f).

ej2πf0n ↔ δ(f − f0) (davrda): Σe−j2π(f − f0)k = DTFT[1] ning f − f0 dagi qiymati (modulyatsiya xossasi).

cos(2πf0n) ↔ ½[δ(f − f0) + δ(f + f0)];   sin(2πf0n) ↔ (1/2j)[δ(f − f0) − δ(f + f0)] (Eyler formulalari).

Barchasi davri 1 bilan takrorlanadi (masalan, cos uchun deltalar ±f0 + butun sonlarda).

Diskret to'rtburchak

x(n) = p2K+1(n) = 1, |n| ≤ K; 0, |n| > K (2K + 1 ta birlik, markaz 0 da). (Slaydda "0, |n| > 0" deb yozilgan — |n| > K bo'lishi kerak.)

1-qadam: kauzal versiya z(n) = x(n − K), 0 ≤ n ≤ 2K. Geometrik yig'indi (a + ar + … + arn−1 = a(1 − rⁿ)/(1 − r)):

Z(ej2πf) = Σk=02Ke−j2πfk = (1 − e−j2πf(2K+1))/(1 − e−j2πf)

2-qadam: surat va maxrajdan "yarim" fazani chiqaramiz: 1 − e−j2θ = e−jθ(ejθ − e−jθ) = e−jθ·2j·sin θ:

Z(ej2πf) = [sin(πf(2K + 1))/sin(πf)]·e−j2πfK

3-qadam: x(n) = z(n + K) → X = Z·e+j2πfK:

X(ej2πf) = sin(πf(2K + 1)) / sin(πf)

Haqiqiy va juft (x juft ✓). f = 0 da 2K + 1 (birliklar soni), nollar f = m/(2K + 1) da. Analogdan farqi: sinc emas — davri 1 bo'lgan funksiya (maxrajda sin(πf), πf emas).

5. Diskret Furye almashtirishi (DFT)

Nega yangi almashtirish kerak?

  • DTFT — cheksiz ketma-ketlik uchun, natijasi uzluksiz o'zgaruvchi f (yoki ω) ning funksiyasi. Kompyuter uzluksiz funksiyani saqlay olmaydi — f ni chekli sondagi nuqtalarda olish kerak.
  • Amaldagi signallar odatda chekli N namunali. DTFT ni har bir nuqtada to'g'ridan hisoblash ~N² ko'paytirish va qo'shish talab qiladi.
  • Shuning uchun chekli ketma-ketliklar uchun hisoblashga qulay usul kerak.

Ta'rif

X(k) = Σn=0N−1 x(n)·e−j2πnk/N,    k = 0, 1, …, N − 1   (N nuqtali DFT)
DFT = DTFT ning N ta teng oraliqdagi namunasi: X(k) = X(ej2πf)|f = fk,   fk = k/N, k = 0 … N − 1 (bitta davr [0, 1) ni N bo'lakka bo'lish).
x(n) = (1/N)·Σk=0N−1 X(k)·e+j2πnk/N,    n = 0, 1, …, N − 1   (IDFT)

k — o'lchamsiz chastota indeksi (0 … N − 1), n — diskret vaqt indeksi (0 … N − 1). Teskari almashtirishda: ishora +, oldida 1/N.

Teskarisi isboti: IDFT ga X(k) ni qo'yamiz:

(1/N)Σk[Σix(i)e−j2πik/N]ej2πnk/N = (1/N)Σix(i)·Σk=0N−1e−j2π(i−n)k/N

Ichki yig'indi: i = n da har bir had 1 → N. i ≠ n da geometrik qator, r = e−j2π(i−n)/N ≠ 1: (1 − rN)/(1 − r), rN = e−j2π(i−n) = 1 → 0. Ya'ni ichki yig'indi = N·δ(i − n), natija (1/N)·x(n)·N = x(n) ✓.

Davriy kengaytma

DFT va IDFT formulalarini barcha k va n uchun hisoblasak (0 … N − 1 bilan cheklanmasdan), natija N davrli ketma-ketliklar bo'ladi: X̃(k) va x̃(n) — X(k) va x(n) ning davriy kengaytmalari. Asosiy davrda [0, N − 1] ular X(k), x(n) bilan bir xil.

Muhim: DFT aslida davriy kengaytmalar orasidagi bog'liqlik. Ya'ni DFT x(n) ni "N davr bilan takrorlanadi" deb hisoblaydi (16-darsdagi qoida: chastotada diskret ⇔ vaqtda davriy). DFT bilan DTFT ni yaqinlashtirganda buni hisobga olish kerak (26–27-darslar: aylanma o'ram, vaqt aliasingi).

FFT — tez Furye almashtirishi

  • DFT ning har bir X(k) namunasi — barcha x(n) larning e−j2πnk/N bilan o'lchangan yig'indisi: N ta ko'paytirish va N − 1 qo'shish. N ta k uchun — ~N² kompleks amal.
  • FFT (Fast Fourier Transform) — DFT va IDFT ni hisoblashning samarali algoritmi: murakkabligi N·log2N (N — 2 ning darajasi bo'lsa). U kompleks eksponentalarning simmetriya va davriylik xossalaridan foydalanadi.
  • Son bilan: N = 1024 → DFT ≈ 1 048 576 amal, FFT ≈ 1024·10 = 10 240 amal — ~100 marta tez. FFT natijasi DFT bilan aynan bir xil — faqat tezroq hisoblanadi.

6. DFT ni qo'lda hisoblash

Misol 1: x = {1, 0, 3, −2}, N = 4. e−j2πnk/4 = (−j)nk, ya'ni 1, −j, −1, j, … DTFT dan (24-dars) foydalanish ham mumkin: X(k) = 1 + 3e−jπk − 2e−j3πk/2.

k = 0: 1 + 3 − 2 = 2.

k = 1: 1 + 3(−1) − 2(j) = −2 − 2j (e−j3π/2 = j).

k = 2: 1 + 3(1) − 2(−1) = 6.

k = 3: 1 + 3(−1) − 2(−j) = −2 + 2j.

Tekshiruvlar: X(0) = Σx ✓; haqiqiy x → X(N − k) = X*(k): X(3) = X*(1) ✓; IDFT: x(0) = (2 + (−2 − 2j) + 6 + (−2 + 2j))/4 = 4/4 = 1 ✓.

Misol 2: x(n) = δ(n), N nuqta: X(k) = e0 = 1 barcha k da (DTFT = 1 ning namunalari).

Misol 3: x(n) = 1, n = 0 … N − 1: X(k) = Σe−j2πnk/N = N (k = 0), 0 (k ≠ 0) — isbotdagi geometrik yig'indi. Ya'ni X(k) = N·δ(k).

Misol 4: x(n) = cos(2πn/4), N = 4: x = {1, 0, −1, 0}. X(k) = 1 − (−1)k: X = {0, 2, 0, 2} — chiziqlar k = 1 (f = ¼) va k = 3 (f = ¾ ≡ −¼) da, har biri N/2 = 2.
