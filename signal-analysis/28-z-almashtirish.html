28. Z-almashtirish va yaqinlashish sohasi (ROC)

O'qish vaqti: 55 daqiqa. Manba: 32-ma'ruza ("Introduction to Z-Transform. Region of Convergence"), mashg'ulot: "Exercises 2 — Z-Transform" (1, 2-masalalar).

Bu A mavzu — imtihonda deyarli albatta bo'ladi: "X(z) = … ning ROC i qaysi?", "qutblari va nollari?", "kauzal ketma-ketlikning ROC i qanday ko'rinishda?", "u(n) va −u(−n−1) ning Z-almashtirishi bir xilmi?". Z-jadval imtihonda beriladi, lekin ROC ni tanlash va qutblarni topish o'zingizdan.
Bu darsda nimani bilib olasiz: Z-almashtirish nima va nega kerak; DTFT va Laplas bilan bog'liqligi; z-tekislik va birlik aylana; yaqinlashish sohasi (ROC) va uning uch turi; qutblar va nollar; asosiy juftliklar jadvali; mashg'ulotdagi 7 ta masala yechimi.

1. Nima uchun Z-almashtirish?

Z-almashtirish diskret signallar uchun — uzluksiz signallardagi Laplas almashtirishining o'xshashi. Ikki afzalligi (ma'ruza):

  • DTFT dan kengroq. DTFT (24-dars) hamma ketma-ketlik uchun yaqinlashmaydi: masalan, u(n) yoki o'zgarmas 1 uchun (agar δ kabi umumlashgan funksiyalarni ishlatmasak). Z-almashtirish esa ancha keng sinf uchun mavjud.
  • LTI tizimlar uchun qulay. Ayirmali tenglamalarni (30-dars) algebraik tenglamalarga aylantiradi — ularni yechish ancha oson.

2. Ta'rif

DTFT: X(ejω) = Σ x(n)e−jωn. Bu yerda ejω o'rniga umumiy kompleks son z qo'yamiz:

X(z) = Z[x(n)] = Σn=−∞+∞ x(n)·z−n,    z = ρ·ejω = ρ·ej2πf
  • z — kompleks o'zgaruvchi (kompleks pulsatsiya): moduli ρ, fazasi ω (3-darsdagi qutb ko'rinishi). U butun kompleks tekislikda qiymat oladi.
  • X(z) — z−1 bo'yicha "ko'phad": z−n oldidagi koeffitsiyent — signalning n-lahzadagi qiymati, z ning darajasi esa vaqt ma'lumotini saqlaydi.
O'xshatish — javon. X(z) — raqamlangan javon: z0 tokchasida x(0), z−1 tokchasida x(1), z−2 da x(2), z+1 da x(−1)… Ketma-ketlikni Z ga o'tkazish — har bir sonni o'z tokchasiga qo'yish. Masalan, {2, 1, 4} (n = −1, 0, 2 da) → 2z + 1 + 4z−2.

Furye — mavhum o'q s = j2πf dagi LaplasDTFT — birlik aylana |z| = 1 dagi Z: X(ejω) = X(z)|z=ejω

ω (yoki f) o'zgarganda z = ejω birlik aylana bo'ylab yuradi. f = 0 → z = 1; f = ±½ (ω = ±π) → bitta nuqta z = −1 (aylana uchlari tutashadi). Bu 21-darsdagi "chastota oralig'i uzunligi 1" xossasining geometrik ko'rinishi.

4. Yaqinlashish sohasi (ROC)

X(z) qatori (Koshi–Loran qatori) yaqinlashadigan z nuqtalar to'plami — yaqinlashish sohasi, ROC (Region Of Convergence). ROC ichida X(z) "yaxshi" (analitik: uzluksiz, cheksiz marta differensiallanuvchi) funksiya.

z = ρejω ni qo'yamiz:

X(z) = Σ x(n)(ρejω)−n = Σ [x(n)ρ−n]·e−jωn

Bu — x(n)ρ−n ketma-ketlikning DTFT si. U mavjud bo'lishi uchun x(n)ρ−n absolyut yig'iluvchi bo'lishi kerak: Σ|x(n)|·ρ−n < ∞. Muhim xulosa:

ROC faqat |z| = ρ ga bog'liq, fazaga bog'liq emas. Shuning uchun ROC chegaralari — markazi 0 da bo'lgan aylanalar. ROC ning shakli: aylana tashqarisi, aylana ichi yoki ikki aylana orasidagi halqa.

Kauzal va antikauzal qismlar

Yig'indini ikkiga ajratamiz:

Σ|x(n)|ρ−n = Σi=1∞ |x(−i)|·ρi  (antikauzal, n < 0)  +  Σk=0∞ |x(k)|/ρk  (kauzal, n ≥ 0)
  • Antikauzal qism (ρi bilan): ρ yetarlicha kichik bo'lsa yaqinlashadi → ROC: |z| < ρ1 (aylana ichi).
  • Kauzal qism (1/ρk bilan): ρ yetarlicha katta bo'lsa yaqinlashadi → ROC: |z| > ρ2 (aylana tashqarisi).
  • Ikki tomonlama ketma-ketlik: ikkalasi bir vaqtda kerak → halqa ρ2 < |z| < ρ1. Agar ρ1 < ρ2 bo'lsa, kesishma bo'sh — X(z) mavjud emas.

Ketma-ketlik turlari (ma'ruza): ikki tomonlama; kauzal bir tomonlama (n < 0 da nol); antikauzal bir tomonlama (n ≥ 0 da nol — 0 ham kiradi).

5. Asosiy misollar (ma'ruza)

δ(n) va δ(n − n0)

Z[δ(n)] = Σδ(n)z−n = z0 = 1 — butun tekislikda yaqinlashadi.

Z[δ(n − n0)] = z−n0. n0 = 0 — hamma joyda; n0 > 0 — z = 0 da uzoqlashadi (1/zn0 → ∞); n0 < 0 — |z| = ∞ da uzoqlashadi.

u(n) va antikauzal pog'ona

Z[u(n)] = Σn=0∞ z−n = Σ(z−1)ⁿ = 1/(1 − z−1) = z/(z − 1), sharti |z−1| < 1, ya'ni |z| > 1 (birlik aylana tashqarisi).

Antikauzal pog'ona x(n) = −u(−n − 1) (n ≤ −1 da −1, aks holda 0): X(z) = −Σn=−∞−1 z−n = −Σm=1∞ zm = −z/(1 − z) = 1/(1 − z−1), sharti |z| < 1.

Imtihon tuzog'i: u(n) va −u(−n − 1) ning formulasi bir xil, faqat ROC lari har xil! Shuning uchun X(z) ROC siz to'liq emas: ROC ko'rsatilmasa, qaysi ketma-ketlik ekanini bilib bo'lmaydi. (Ma'ruza slaydida bu misol "u(−n − 1)" deb nomlangan, lekin hisob minus ishorasi bilan, ya'ni −u(−n − 1) uchun bajarilgan.)

Chekli tayanchli ketma-ketliklar

X(z) = Σn=n1n2 x(n)z−n — chekli yig'indi, har doim yaqinlashadi, faqat:

  • z = 0 bundan mustasno, agar z−k (k > 0) hadlar bo'lsa (ya'ni n > 0 dagi namunalar);
  • |z| = ∞ bundan mustasno, agar zk (k > 0) hadlar bo'lsa (ya'ni n < 0 dagi namunalar).

Ma'ruza misoli: x(n) = 2δ(n + 1) + δ(n) + 4δ(n − 2) → X(z) = 2z + 1 + 4z−2. 2z hadi tufayli ∞ chiqariladi, 4z−2 tufayli 0. ROC: 0 < |z| < ∞.

6. Ratsional X(z), qutblar va nollar

Ko'pincha X(z) ikki ko'phad nisbati:

X(z) = N(z)/D(z) = Σi=0pn biz−i / Σi=0pd aiz−i = (b0/a0)·zpd−pn·Π(z − ci) / Π(z − di)
  • Nollar (zeros) ci — surat ildizlari, X(ci) = 0. z-tekislikda ○ bilan belgilanadi.
  • Qutblar (poles) di — maxraj ildizlari, X(di) = ∞. z-tekislikda × bilan belgilanadi.
  • zpd−pn ko'paytuvchi z = 0 da qo'shimcha nol (pd > pn) yoki qutb (pd < pn) beradi.
Amaliy maslahat: qutb va nollarni topish uchun X(z) ni z ning musbat darajalarida yozing (surat va maxrajni z ning eng katta darajasiga ko'paytiring). Masalan, 1/(1 − ½z−1) = z/(z − ½): nol z = 0, qutb z = ½.

Ma'ruzadagi uch misol

x1(n) = (1/3)ⁿu(n) (kauzal): X1(z) = Σ(⅓z−1)ⁿ = 1/(1 − ⅓z−1) = z/(z − ⅓), |⅓z−1| < 1 → |z| > ⅓. Nol 0, qutb ⅓. (MATLAB: zplane([1 0],[1 -1/3]).)

x2(n) = (−½)ⁿu(−n − 1) (antikauzal): X2(z) = Σn=−∞−1 (−½)ⁿz−n = Σk=1∞ (−2z)k = −1 + 1/(1 + 2z) = −2z/(1 + 2z) = −z/(z + ½), |2z| < 1 → |z| < ½. Nol 0, qutb −½.

x3(n) = (1/3)ⁿu(n) − (−½)ⁿu(−n − 1) (ikki tomonlama): X3 = X1 − X2 = z/(z − ⅓) + z/(z + ½) = 2z(z + 1/12) / (z² + z/6 − 1/6). ROC — kesishma: ⅓ < |z| < ½ (halqa). Nollar 0 va −1/12, qutblar ⅓ va −½. (MATLAB: zplane([2 1/6 0],[1 1/6 -1/6]).)

8. Yechilgan misollar (Exercises 2)

1.1-masala: x[n] = αⁿu[n] (α haqiqiy)

Ta'rif bo'yicha: X(z) = Σn=0∞ αⁿz−n = Σ(αz−1)ⁿ = 1/(1 − αz−1), |z| > |α|. Qutb: z = α (nol z = 0).

Mashg'ulot rasmlari: α = 0,5 — qutb aylana ichida, signal so'nadi; α = 1 — qutb aylana ustida, signal o'zgarmas (u(n)); α = 1,5 — qutb tashqarida, signal o'sib ketadi. α < 0 da (−0,5; −1; −1,5) xuddi shunday, lekin ishora almashadi. Qutbning birlik aylanaga nisbatan joyi signalning so'nishini ko'rsatadi — 32-darsdagi turg'unlikning asosi.

1.2-masala: x[n] = sin(ω0n)u[n]

Eyler: sin(ω0n) = (ejω0n − e−jω0n)/(2j). Har biri 1.1 ko'rinishida (α = e±jω0, |α| = 1):

X(z) = (1/2j)·[1/(1 − ejω0z−1) − 1/(1 − e−jω0z−1)],   |z| > 1

Umumiy maxrajga keltiramiz: surat z−1(ejω0 − e−jω0)/(2j) = z−1sin ω0; maxraj (1 − ejω0z−1)(1 − e−jω0z−1) = 1 − 2cos ω0·z−1 + z−2.

X(z) = z−1sin ω0 / (1 − 2cos ω0z−1 + z−2) = z·sin ω0 / [(z − ejω0)(z − e−jω0)]

Nol: z = 0. Qutblar: z = e±jω0 — birlik aylana ustida, qo'shma juftlik.

1.3-masala: x[n] = cos(ω0n)u[n]

Xuddi shunday, cos = (ejω0n + e−jω0n)/2:

X(z) = (1 − cos ω0·z−1) / (1 − 2cos ω0z−1 + z−2) = z(z − cos ω0) / [(z − ejω0)(z − e−jω0)],   |z| > 1

Nollar: z = 0, z = cos ω0. Qutblar: z = e±jω0.

1.4-masala: x[n] = αⁿcos(ω0n)u[n]

1.3 dagi har bir e±jω0 o'rniga αe±jω0:

X(z) = (1 − α·cos ω0·z−1) / (1 − 2α·cos ω0·z−1 + α²z−2),   |z| > |α|

Nollar: z = 0, z = α·cos ω0. Qutblar: z = αe±jω0 — radiusi α bo'lgan aylanada qo'shma juftlik. α < 1 — so'nuvchi tebranish, α = 1 — doimiy, α > 1 — o'suvchi.

2.1-masala: x[n] = α|n|

Ikki tomonlama — ikkiga ajratamiz:

X(z) = Σn=0∞ αⁿz−n + Σn=−∞−1 α−nz−n = Σ(αz−1)ⁿ + Σm=0∞(αz)m − 1 = 1/(1 − αz−1) + 1/(1 − αz) − 1

(ikkinchi yig'indini m = 0 dan boshlab, ortiqcha m = 0 hadi uchun 1 ni ayiramiz). Umumiy maxraj: X(z) = (1 − α²) / [(1 − αz−1)(1 − αz)].

ROC: |αz−1| < 1 va |αz| < 1 → |α| < |z| < 1/|α|. Halqa bo'sh emas faqat |α| < 1 bo'lganda (aks holda α|n| ikki tomonga o'sib ketadi).

2.2-masala: x[n] = 1, 0 ≤ n ≤ N − 1 (quti)

X(z) = Σn=0N−1 z−n = (1 − z−N)/(1 − z−1) = z−N(zN − 1)/(z−1(z − 1)) = (zN − 1)/(zN−1(z − 1)) (chekli geometrik qator).

Nollar: zN = 1 → z = ej2πk/N, k = 0, …, N − 1 (birlik aylanada teng taqsimlangan N ta nuqta). k = 0 dagi nol z = 1 dagi qutbni qisqartiradi. Qoladi: z = 0 da (N − 1) karrali qutb. ROC: |z| > 0 — chekli kauzal ketma-ketlik uchun kutilganidek.

2.3-masala: uchburchak x[n] = n (0 ≤ n ≤ N), 2N − n (N + 1 ≤ n ≤ 2N), 0 aks holda

Hiyla: uchburchak — ikki qutining o'rami (22-dars, ma'ruzadagi trapetsiya misoli kabi). xp[n] = 1 (0 ≤ n ≤ N − 1) bo'lsa, xp * xp = {1, 2, …, N, …, 2, 1} (n = 0 … 2N − 2). Bir namuna kechiktirsak, aynan x[n]: x[n] = xp[n] * xp[n − 1].

O'ram → ko'paytma, kechikish → z−1 (29-dars xossalari):

X(z) = z−1·[Xp(z)]² = z−1·[(1 − z−N)/(1 − z−1)]²,   ROC: |z| > 0

Qo'shimcha (3.3-masala): x(n) = 2ⁿu(−n)

Antikauzal (n ≤ 0): X(z) = Σn=−∞0 2ⁿz−n = Σm=0∞ (½z)m = 1/(1 − ½z) = −2/(z − 2), sharti |½z| < 1 → |z| < 2.

(Mashg'ulot yechimida natija z/(z − ½) deb yozilgan, lekin to'g'ri hisob 1/(1 − ½z) = −2/(z − 2): qutb z = 2 da, ROC |z| < 2 — qutbning ichki tomoni, antikauzal qoidaga mos. ROC ning o'zi to'g'ri yozilgan.)

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (32-ma'ruza):

  1. X(z) = Σx(n)z−n, z = ρejω — kompleks. z−n koeffitsiyenti = x(n). Laplasning diskret o'xshashi; ayirmali tenglamalarni algebraik qiladi; DTFT dan kengroq sinfda mavjud.
  2. DTFT = X(z) birlik aylanada: X(ejω) = X(z)|z=ejω. f = 0 → z = 1; f = ±½ → z = −1.
  3. ROC — qator yaqinlashadigan z lar; faqat |z| ga bog'liq → aylanalar bilan chegaralangan. ROC da qutb yo'q.
  4. Kauzal: |z| > dM (eng uzoq qutb tashqarisi). Antikauzal: |z| < dm (eng yaqin qutb ichi). Ikki tomonlama: halqa (bo'sh bo'lishi mumkin). Chekli: butun tekislik, ehtimol 0 va/yoki ∞ siz.
  5. δ(n) → 1; δ(n − n0) → z−n0.
  6. aⁿu(n) → 1/(1 − az−1), |z| > |a|; −aⁿu(−n − 1) → 1/(1 − az−1), |z| < |a| — formula bir xil, ROC farqli! a = 1: u(n).
  7. Nol — surat ildizi (○), qutb — maxraj ildizi (×). Musbat darajalarda yozib toping.
  8. Ma'ruza: (⅓)ⁿu(n) → z/(z − ⅓), |z| > ⅓; (−½)ⁿu(−n−1) → −z/(z + ½), |z| < ½; ayirmasi → halqa ⅓ < |z| < ½.
  9. Mashg'ulot: sin/cos(ω0n)u(n) — qutblar e±jω0; α|n| → (1 − α²)/[(1 − αz−1)(1 − αz)], |α| < |z| < 1/|α|; quti → (1 − z−N)/(1 − z−1), nollar ej2πk/N.
