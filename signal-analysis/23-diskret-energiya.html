23. Diskret energiya, quvvat, korrelyatsiya

O'qish vaqti: 45 daqiqa. Manba: 27-ma'ruza ("Energy and Average Power. Correlation Function"), mashg'ulot: "Exercises 1" (3-masala, a–e).

Bu A mavzu. Imtihonda: "aⁿu(n) ning energiyasi?", "u(n) ning o'rtacha quvvati?", "energiya signalimi yoki quvvat signalimi?", "Rx(0) nimaga teng?", "{1, 0, 2, 3} ning avtokorrelyatsiyasi?". 4-darsdagi analog formulalar bilan bir xil g'oya — integral o'rniga yig'indi.
Bu darsda nimani bilib olasiz: diskret energiya va o'rtacha quvvat; davriy ketma-ketlik quvvati; diskretlangan analog signal uchun Tc ko'paytuvchisi; o'zaro korrelyatsiya va avtokorrelyatsiya, ularni hisoblash; mashg'ulotdagi 5 ta masala; DTFT/DFT ga kirish so'zi.

1. Energiya

Ex = Σn=−∞+∞ |x(n)|²

Ya'ni har bir namuna modulining kvadratini olib, hammasini qo'shamiz. Analogdagi E = ∫|x(t)|²dt ning diskret varianti (4-dars). Ex < ∞ bo'lsa, ketma-ketlik chekli energiyali (21-darsdagi "kvadratik yig'iluvchi").

Chekli energiyali ketma-ketliklar xossalari (ma'ruza):

  • energiya — haqiqiy, chekli, qat'iy musbat son (nol signaldan tashqari);
  • energiya vaqtda surishga bog'liq emas: Σ|x(n)|² = Σ|x(n − N)|² istalgan butun N uchun (bir xil sonlar qo'shilyapti, faqat boshqa joyda).

Ma'ruza misoli: x(n) = αⁿu(n), 0 < α < 1

Ex = Σn=0∞ (αⁿ)² = Σ (α²)ⁿ = 1/(1 − α²) (geometrik qator Σqⁿ = 1/(1 − q), bu yerda q = α² < 1).

Masalan, α = 0,5: E = 1/(1 − 0,25) = 4/3.

Geometrik qator — bu bo'limning asosiy quroli: Σn=0∞ qⁿ = 1/(1 − q) (|q| < 1),   Σn=0N−1 qⁿ = (1 − qN)/(1 − q). Imtihondagi deyarli barcha energiya masalalari shunga keltiriladi.

2. O'rtacha quvvat

Energiyasi cheksiz ketma-ketliklar uchun o'rtacha quvvat aniqlanadi — "bitta namunaga to'g'ri keladigan o'rtacha energiya":

Px = limN→∞ 1/(2N + 1) · Σn=−N+N |x(n)|²

[−N, N] oynada 2N + 1 ta namuna bor — shuning uchun 2N + 1 ga bo'lamiz.

Ikki toifa (ma'ruza): chekli energiyali ketma-ketlikning quvvati nol; quvvati noldan farqli (chekli) ketma-ketlikning energiyasi cheksiz. Shuning uchun signal yoki energiya signali (0 < E < ∞, P = 0), yoki quvvat signali (E = ∞, 0 < P < ∞), yoki hech biri (masalan, n·u(n): E = ∞, P = ∞).

Ma'ruza misoli: x(n) = u(n)

Oyna [−N, N] da u(n) = 1 faqat n = 0 … N da: N + 1 ta bir. Px = lim (N + 1)/(2N + 1) = ½. Mantiq: oynaning yarmi bo'sh, yarmi to'la.

Davriy ketma-ketlik quvvati

Davri N bo'lgan ketma-ketlik uchun bitta davr bo'yicha o'rtacha olish kifoya:

Px = (1/N) · Σn=0N−1 |x(n)|²

Ma'ruza misoli (N = 6): bir davrdagi qiymatlar: 3; ikki marta 1,5; ikki marta −1; bitta 0.

Px = (1/6)·[3² + 2·(1,5)² + 2·(−1)² + 0²] = (1/6)·[9 + 4,5 + 2] = 15,5/6 = 31/12 ≈ 2,58.

3. Diskretlangan analog signallar: Tc ni unutmang

Agar ketma-ketlik analog signalni Tc qadam bilan diskretlab olingan bo'lsa va analog signalning energiyasi/quvvati kerak bo'lsa, integralni yig'indi bilan taqriban almashtiramiz (vaqt o'qi Tc kenglikdagi bo'laklarga bo'linadi, har bo'lak "to'rtburchak"):

Ex = ∫|x(t)|²dt ≈ Tc · Σ |x(nTc)|²
  • Davriy (davri T = NTc): Px = (1/T)∫0T|x(t)|²dt ≈ (1/(NTc))·Σ|x(nTc)|²·Tc = (1/N)·Σn=0N−1|x(nTc)|² — Tc qisqaradi.
  • Davriy bo'lmagan: Px ≈ lim 1/((2N + 1)Tc)·Σ|x(nTc)|²·Tc = lim 1/(2N + 1)·Σ|x(nTc)|² — yana Tc qisqaradi.
Xulosa: energiyada Tc ko'paytuvchisi qoladi, quvvatda esa qisqarib ketadi (quvvat — "vaqt birligiga energiya", ikkalasida ham Tc bor).

4. Korrelyatsiya funksiyalari

O'zaro korrelyatsiya (mutual / cross-correlation) — ikki chekli energiyali ketma-ketlikning bir-biriga qanchalik o'xshashligini o'lchaydi, ulardan biri n namunaga surilganda:

Rx,y(n) = Σk x*(k + n)·y(k) = Σk x*(k)·y(k − n)

(Ikkinchi ko'rinish k → k − n almashtirishdan chiqadi.) x va y o'rnini almashtirsak: Ry,x(n) = Σ y*(k + n)x(k) = Σ y*(k)x(k − n). Haqiqiy ketma-ketliklar uchun:

Rx,y(n) = Ry,x(−n)
O'xshatish. Ikki shaffof plyonkaga chizilgan naqshlarni ustma-ust qo'yib, birini sekin siljitamiz. Har bir siljishda "mos tushgan joylar"ni o'lchaymiz. Eng katta qiymat — naqshlar eng yaxshi mos kelgan siljish. Radar shu tarzda aks-sado qaytish vaqtini topadi.

Avtokorrelyatsiya

y(n) = x(n) bo'lsa — avtokorrelyatsiya:

Rx(n) = Σk x*(k + n)·x(k) = Σk x*(k)·x(k − n),    Rx(0) = Σ|x(k)|² = Ex

Nolinchi siljishda signal o'zi bilan to'liq mos keladi — natija energiya. Haqiqiy signal uchun Rx(n) = Rx(−n) — juft funksiya, maksimumi n = 0 da.

Quvvat signallari uchun

Chekli o'rtacha quvvatli ketma-ketliklar uchun yig'indi oynaning uzunligiga bo'linadi:

Φx,y(n) = limN→∞ 1/(2N + 1)·Σk=−NN x*(k + n)y(k),    Φx(n) — xuddi shunday y = x bilan

Davri N bo'lsa: Φx,y(n) = (1/N)·Σk=0N−1 x*(k + n)y(k), Φx(n) = (1/N)·Σk=0N−1 x*(k + n)x(k). Bu yerda Φx(0) = Px.

Ma'ruza misoli: x(n) = {1, 0, 2, 3}, y(n) = {1, 2, 2}

Ikkalasi n = 0 dan boshlanadi. Haqiqiy, shuning uchun Rx,y(n) = Σ x(k)·y(k − n): y ni n ga suramiz (n > 0 — o'ngga) va x bilan ustma-ust tushgan juftlarni ko'paytirib qo'shamiz. Teskari aylantirish yo'q — o'ramdan asosiy farqi shu!

Natija: Rx,y(n) = {2, 2, 5, 10, 8, 3}, n = −2 … 3 (ma'ruza bilan bir xil). O'rnini almashtirsak: Ry,x(n) = {3, 8, 10, 5, 2, 2}, n = −3 … 2 — xuddi o'sha sonlar teskari tartibda, chunki Ry,x(n) = Rx,y(−n).

Tez usul: haqiqiy signallar uchun Rx,y(n) = x(n) * y(−n) — y ni teskari yozib, oddiy o'ram qilamiz (22-darsdagi jadval usuli). Tekshiring: {1, 0, 2, 3} * {2, 2, 1} = {2, 2, 5, 10, 8, 3} ✓, boshlanish 0 + (−2) = −2. Yig'indi tekshiruvi ham ishlaydi: 30 = 6·5.

Ma'ruza misoli: x(n) = {1, 0, 2, 3} ning avtokorrelyatsiyasi

Rx(0) = 1² + 0² + 2² + 3² = 14 = Ex.

Rx(1) = Σx(k)x(k − 1) = x(1)x(0) + x(2)x(1) + x(3)x(2) = 0 + 0 + 6 = 6.

Rx(2) = x(2)x(0) + x(3)x(1) = 2 + 0 = 2.   Rx(3) = x(3)x(0) = 3.

Juftlik bo'yicha Rx(−n) = Rx(n): Rx(n) = {3, 2, 6, 14, 6, 2, 3}, n = −3 … 3. Uzunlik 2·4 − 1 = 7.

5. Yechilgan misollar (Exercises 1, 3-masala)

Quyidagi ketma-ketliklarning energiyasi va quvvatini toping. Mashg'ulotdagi ta'riflar: Ex = Σ|x(n)|²; Px = lim 1/(2N+1)·Σ−NN|x(n)|²; davriy: Px = (1/N0)·Σn=1N0|x(n)|².

3a: x[n] = e−n (n ≥ 0), 0 (n < 0)

Ex = Σn=0∞ e−2n = Σ (e−2)ⁿ = 1/(1 − e−2) ≈ 1,157 (q = e−2 ≈ 0,135). Chekli energiya → Px = 0. (Bu αⁿu(n) misoli, α = e−1.)

3b: x[n] = A (o'zgarmas)

Energiya, albatta, cheksiz (cheksiz ko'p A² qo'shiladi). Px = lim (2N + 1)A²/(2N + 1) = A².

3c: x[n] = A·e−j2πn/N

Kompleks eksponenta: |x(n)|² = A²·|e−j2πn/N|² = A² (moduli har doim 1, 3-dars). Demak hammasi 3b bilan bir xil: E = ∞, Px = A². (Davriy formula bilan ham: (1/N)·N·A² = A².)

3d: x[n] = A (n ≥ 0), 0 (n < 0) — ya'ni A·u(n)

Oyna [−N, N] da N + 1 ta A²: Px = lim (N + 1)A²/(2N + 1) = A²/2. E = ∞. (Ma'ruzadagi u(n) misoli, A marta katta.)

3e: x[n] = A (|n − n0| ≤ N), 0 (aks holda)

Bu n0 markazli, uzunligi 2N + 1 bo'lgan "quti" (rasmda N = 2: 5 ta namuna). Ex = A²(2N + 1) — n0 ga bog'liq emas (surishga invariantlik!). Chekli energiya → P = 0.

6-misol: diskret sinusoida quvvati

x(n) = cos(πn/2) ning quvvati?

f0 = 1/4 → davr 4: qiymatlar 1, 0, −1, 0. P = (1/4)(1 + 0 + 1 + 0) = ½ — analog sinusoidadagi A²/2 bilan bir xil. Lekin ehtiyot bo'ling: cos(πn) = (−1)ⁿ uchun P = 1 (har namunada |x|² = 1), A²/2 emas.

7-misol: diskretlangan analog signal energiyasi

x(t) = e−tu(t) ni Tc = 0,1 s bilan diskretladik. Namunalar bo'yicha analog energiyani baholang.

x(nTc) = e−0,1n, Σ e−0,2n = 1/(1 − e−0,2) ≈ 5,52. E ≈ Tc·5,52 = 0,552. Aniq qiymat ∫e−2tdt = 0,5 — yaqin (Tc kichraygan sari aniqroq). Tc ni unutsak, 5,52 — 11 marta xato!

8-misol: energiya signalimi yoki quvvat?

a) (0,9)ⁿu(n) — energiya signali: E = 1/(1 − 0,81) ≈ 5,26, P = 0.

b) 2cos(2π·0,1n) — davriy, quvvat signali: P = 4/2 = 2, E = ∞.

c) n·u(n) — hech biri: |x|² o'sib boradi, E = ∞ va P = ∞.

d) δ(n − 5) — energiya signali: E = 1.

6. Keyingi qadam: chastota sohasi (ma'ruza oxiri)

Ma'ruza oxirida keyingi mavzuga ko'prik: ketma-ketlikni deltalar yig'indisi x(n) = Σx(k)δ(n − k) sifatida yozish mumkin edi (21-dars). Muqobil ko'rinishlar:

  • kompleks eksponentalar e−j2πfn orqali — DTFT (diskret vaqtli Furye almashtirishi): istalgan ketma-ketlikni uzluksiz f funksiyasiga aylantiradi (24-dars);
  • DFT (diskret Furye almashtirishi): uzunligi N bo'lgan ketma-ketlikni N ta teng oraliqdagi chastota namunasiga aylantiradi — kompyuterda hisoblanadigani shu (25–27-darslar);
  • z−n ketma-ketliklar orqali — Z-almashtirish (Laplas almashtirishining diskret o'xshashi, 28-dars).

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (27-ma'ruza):

  1. Energiya: Ex = Σ|x(n)|²; haqiqiy, musbat, surishga bog'liq emas.
  2. Geometrik qator: Σn≥0 qⁿ = 1/(1 − q). αⁿu(n): E = 1/(1 − α²); e−nu(n): E = 1/(1 − e−2).
  3. Quvvat: Px = lim 1/(2N+1)·Σ−NN|x(n)|². Davriy: P = (1/N)Σbir davr|x(n)|².
  4. Chekli energiya → P = 0; P > 0 → E = ∞.
  5. Natijalar: A → P = A²; A·u(n) → P = A²/2; Aejθn → P = A²; quti 2N + 1 → E = A²(2N + 1); N = 6 misoli → P = 31/12.
  6. Diskretlangan analog: E ≈ TcΣ|x(nTc)|² (Tc qoladi), quvvatda Tc qisqaradi.
  7. O'zaro korrelyatsiya: Rx,y(n) = Σx*(k + n)y(k) = Σx*(k)y(k − n) — teskari aylantirishsiz siljitish. Haqiqiy: Rx,y(n) = Ry,x(−n); tez usul: Rx,y = x(n) * y(−n).
  8. Avtokorrelyatsiya: Rx(0) = Ex, juft, maksimum 0 da. Quvvat signali: Φx (1/(2N+1) yoki 1/N bilan), Φx(0) = Px.
  9. Ma'ruza misollari: Rx,y = {2, 2, 5, 10, 8, 3} (n = −2 … 3); Ry,x = {3, 8, 10, 5, 2, 2}; Rx = {3, 2, 6, 14, 6, 2, 3}.
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
