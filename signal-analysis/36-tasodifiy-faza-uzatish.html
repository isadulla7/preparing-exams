36. Tasodifiy fazali sinusoida, raqamli uzatish; statsionarlik

O'qish vaqti: 50 daqiqa. Manba: 37-ma'ruza, 3-qism ("Random-phase sinusoid", "Deterministic signal seen as a random process", "Signal for numerical transmission"). 5-bo'lim (statsionarlik, quvvat spektri, oq shovqin) — ma'ruza slaydlarida yo'q, qisqa qo'shimcha. Kerakli bilim: 33–35-darslar.

Bu B mavzu. Imtihonda: "φ tekis [0, 2π] da bo'lsa Acos(2πf0t + φ) ning o'rtachasi / avtokorrelyatsiyasi?", "qaysi holda R faqat t1 − t2 ga bog'liq?", "deterministik signalning 1-tartibli PDF si?", "Σαir(t − iT) ning o'rtachasi?", "mustaqil αi da E[αiαj] = ?".
Bu darsda nimani bilib olasiz: tasodifiy fazali sinusoida — umumiy hol va tekis faza holi (ma'ruzaning to'liq hisobi); qarshi misollar (yarim davrli faza, ikki qiymatli faza); deterministik signal statistikasi; raqamli uzatish jarayonining o'rtachasi va avtokorrelyatsiyasi (±1 va PAM-4 uchun oxirigacha hisoblangan); qisqacha: keng ma'noda statsionarlik, vaqt bo'yicha o'rtacha, quvvat spektri, oq shovqin, filtrdan o'tish.

1. Tasodifiy fazali sinusoida

X(t) = A·cos(2πf0t + φ),    φ — tasodifiy miqdor (PDF fφ(θ)); A, f0 — aniq sonlar

1.1. Umumiy hol

O'rtacha: A — aniq son, tashqariga chiqadi; cos ning kutilgan qiymati E[g(φ)] = ∫g(θ)fφ(θ)dθ formulasi bilan (33-dars):

mX(t) = A·E[cos(2πf0t + φ)] = A∫fφ(θ)cos(2πf0t + θ)dθ

Natija φ ning PDF siga bog'liq.

Avtokorrelyatsiya — cos α·cos β = ½[cos(α + β) + cos(α − β)] formulasi bilan (ma'ruza: "mashqlar uchun foydali odatiy trigonometrik bog'liqlik"):

RX(t1, t2) = A²E[cos(2πf0t1 + φ)cos(2πf0t2 + φ)] = (A²/2)·E[cos(2πf0(t1 + t2) + 2φ)] + (A²/2)·cos(2πf0(t1 − t2))

Ikkinchi hadda φ yo'q (α − β da φ qisqarib ketadi) — u E dan tashqariga chiqadi.

1.2. φ tekis [0, 2π] da

fφ(θ) = 1/(2π), 0 ≤ θ ≤ 2π.

O'rtacha: mX(t) = A∫02π(1/2π)cos(2πf0t + θ)dθ = (A/2π)[sin(2πf0t + θ)]02π = 0 — bitta to'liq davr bo'yicha kosinus integrali nol. Ma'ruza: "bu holda ham ansambl o'rtachasi vaqtga bog'liq emas".

Avtokorrelyatsiya: birinchi hadda E[cos(c + 2φ)] = (1/2π)∫02πcos(c + 2θ)dθ = 0 (ikki to'liq davr). Qoladi:

RX(t1, t2) = (A²/2)·cos(2πf0(t1 − t2))

Ma'ruza: "bu holda avtokorrelyatsiya faqat vaqt farqi t1 − t2 ga bog'liq". 35-darsdagi tasodifiy amplitudali sinusoidadan farqi — u yerda t1 + t2 li had qolgan edi.

Natijalar: o'rtacha quvvat RX(t, t) = A²/2 — har qanday t da bir xil (18-darsdagi cos ning quvvati bilan bir xil!). m = 0 bo'lgani uchun KX = RX, σX² = A²/2.

Son misol: A = 2, f0 = 50 Hz. R(t1, t2) = 2cos(100π(t1 − t2)). t1 − t2 = 0: R = 2 (quvvat); = 5 ms (chorak davr): R = 2cos(π/2) = 0; = 10 ms (yarim davr): R = −2 — yarim davr farq bilan qiymatlar doim qarama-qarshi ishorali.

1.3. Qarshi misollar — tekis taqsimot to'liq davrda bo'lishi muhim

a) φ tekis [0, π] da (yarim davr), fφ = 1/π: mX(t) = (A/π)[sin(2πf0t + θ)]0π = (A/π)(−sin(2πf0t) − sin(2πf0t)) = −(2A/π)sin(2πf0t) — o'rtacha endi vaqtga bog'liq. (sin(x + π) = −sin x.)

b) φ ∈ {0, π}, har biri ½ ehtimol bilan: bu A·cos(…) yoki −A·cos(…), ya'ni aslida ±A tasodifiy amplituda. m = 0, lekin 2φ ∈ {0, 2π} → E[cos(c + 2φ)] = cos c ≠ 0, va R = A²cos(2πf0t1)cos(2πf0t2) — 35-darsdagi formulaga qaytdik, R t1 va t2 ga alohida bog'liq.

2. Deterministik signal tasodifiy jarayon sifatida

X(t) = Acos(2πf0t + φ) da barcha parametrlar aniq haqiqiy sonlar bo'lsin (ma'ruza):

O'rtachamX(t) = A·cos(2πf0t + φ) — signalning o'zi
AvtokorrelyatsiyaRX(t1, t2) = A²cos(2πf0t1 + φ)cos(2πf0t2 + φ)
1-tartibli PDFfX(x1; t1) = δ(x1 − Acos(2πf0t1 + φ))
2-tartibli PDFfX1X2(x1, x2; t1, t2) = δ(x1 − X(t1))·δ(x2 − X(t2))

PDF — delta: qiymat 1 ehtimollik bilan aniq ma'lum (33-dars, 3-bo'lim). Avtokovariatsiya K = R − m(t1)m(t2) = 0 — hech qanday tasodifiylik yo'q.

3. Raqamli uzatish signali

X(t) = Σi=−∞∞ αi·r(t − iT)

r(t) — deterministik impuls, αi — diskret tasodifiy miqdorlar, o'zaro statistik mustaqil. Demak (33-dars) ular korrelyatsiyalanmagan: i ≠ j da E[αiαj*] = E[αi]E[αj*].

O'rtacha (E chiziqli, r(t − iT) — aniq):

mX(t) = E[Σαir(t − iT)] = Σi E[αi]·r(t − iT)

Avtokorrelyatsiya (ikki yig'indini ko'paytiramiz, E ni ichkariga kiritamiz):

RX(t1, t2) = E[Σiαir(t1 − iT)·Σjαj*r*(t2 − jT)] = ΣiΣj E[αiαj*]·r(t1 − iT)·r*(t2 − jT)

Ma'ruza: 1- va 2-tartibli statistikalar (FX(x1; t1) = P(X(t1) < x1), FX1,X2) umumiy holda hisoblash juda qiyin.

Oxirigacha: αi = ±1 teng ehtimolli, r — davomiyligi T bo'lgan to'rtburchak

E[αi] = 0 → mX(t) = 0.

E[αiαj] = δ(i − j) (33-dars): ikki karrali yig'indidan faqat i = j hadlar qoladi:

RX(t1, t2) = Σi r(t1 − iT)·r(t2 − iT)

r(t − iT) = 1 faqat i-bit oralig'ida [iT, (i + 1)T). Ko'paytma 1 bo'lishi uchun t1 va t2 bitta bit oralig'ida bo'lishi kerak:

RX(t1, t2) = 1, agar t1, t2 bitta oraliqda bo'lsa; aks holda 0

Ma'nosi: bitta bit ichida qiymat o'zgarmaydi — to'liq bog'liq; turli bitlar mustaqil — bog'liqlik yo'q.

Son bilan (T = 1): R(0,2; 0,7) = 1 (ikkalasi [0, 1) da); R(0,7; 1,2) = 0 (turli bitlarda). Ikkala holda ham t1 − t2 = −0,5, lekin R har xil! Demak bu jarayonda R faqat farqqa bog'liq emas.

PAM-4 (α ∈ {±1, ±3}): E[α] = 0, E[αi²] = 5 → R = 5 bitta oraliqda, 0 aks holda.

On-off (bit 1 → 1, bit 0 → 0): E[α] = ½ → mX(t) = ½·Σr(t − iT) = ½ (har bir t biror oraliqqa tushadi).

5. Qo'shimcha: statsionarlik, quvvat spektri, oq shovqin

Diqqat: bu bo'lim ma'ruza slaydlarida yo'q (ma'ruzada faqat "vaqt bo'yicha o'rtacha keyinroq ko'riladi" deyilgan). Imtihon ma'ruzalardan bo'lgani uchun bu — C darajadagi material: avval 1–4-bo'limlarni yaxshi o'zlashtiring. Lekin bu tushunchalar oldingi natijalarni bog'laydi va ma'ruzadagi "A jarayonning polosasi kengroq" savoliga javob beradi.

5.1. Keng ma'noda statsionar (WSS) jarayon

Jarayon keng ma'noda statsionar (wide-sense stationary, WSS) deyiladi, agar:

  1. o'rtachasi o'zgarmas: mX(t) = mX (t ga bog'liq emas);
  2. avtokorrelyatsiya faqat vaqt farqiga bog'liq: RX(t1, t2) = RX(τ), τ = t1 − t2.

O'xshatish: statsionar jarayon — "ob-havosi o'zgarmaydigan" joy: qaysi kuni o'lchasangiz ham statistikasi bir xil. (Qat'iy statsionarlik — barcha tartibdagi statistikalar vaqt siljishiga bog'liq emas; bu kuchliroq shart.)

Misollarimiz: tekis fazali sinusoida — WSS (m = 0, R = (A²/2)cos(2πf0τ)). Tasodifiy amplitudali sinusoida — yo'q (R da t1 + t2). Gauss tasodifiy sayr — yo'q (σ² = kt). Ikkilik uzatish — yo'q (R(0,2; 0,7) ≠ R(0,7; 1,2); statistikasi har T da takrorlanadi — "siklostatsionar").

RX(τ) xossalari: RX(0) = E[|X|²] — o'rtacha quvvat; |RX(τ)| ≤ RX(0); RX(−τ) = RX*(τ) (haqiqiy jarayonda juft).

5.2. Vaqt bo'yicha o'rtacha va ergodiklik

Ansambl o'rtachasi o'rniga bitta realizatsiya bo'ylab vaqt bo'yicha o'rtacha olish mumkin: ⟨x⟩ = limT→∞(1/T)∫−T/2T/2x(t)dt. Agar vaqt o'rtachalari ansambl o'rtachalariga teng bo'lsa, jarayon ergodik deyiladi — amalda bitta uzun yozuv yetarli. Tekis fazali sinusoida: har bir realizatsiyaning vaqt o'rtachasi 0 = mX, vaqt avtokorrelyatsiyasi (A²/2)cos(2πf0τ) = RX(τ) — ergodik. Tasodifiy amplitudali sinusoida — ergodik emas (vaqt o'rtacha quvvati A²/2 — har bir realizatsiyada har xil).

5.3. Quvvat spektral zichligi

SX(f) = F{RX(τ)} = ∫RX(τ)e−j2πfτdτ,    PX = RX(0) = ∫SX(f)df

WSS jarayonning quvvati chastotalar bo'yicha qanday taqsimlangani (Viner–Xinchin teoremasi; 17–18-darslardagi "avtokorrelyatsiya ↔ spektr" bog'liqligining tasodifiy varianti). Tekis fazali sinusoida: SX(f) = (A²/4)[δ(f − f0) + δ(f + f0)] — umumiy quvvat A²/2 ✓. Tez o'zgaruvchi jarayon (ma'ruzadagi A) — R(τ) tez so'nadi → S(f) keng → polosasi katta.

5.4. Oq shovqin va filtrlash

Oq shovqin: SX(f) = N0/2 barcha f da (oq yorug'lik kabi — barcha "ranglar" teng). Unda RX(τ) = (N0/2)δ(τ): ikki turli vaqtdagi qiymatlar korrelyatsiyalanmagan. Issiqlik shovqini juda yuqori chastotalargacha amalda oq va Gauss.

WSS X(t) → LTI h(t), H(f) → Y(t):   mY = mX·H(0),    SY(f) = |H(f)|²·SX(f)

Misol: oq shovqin ideal past chastotali filtrdan (polosa B, 15-dars) o'tdi: SY = N0/2, |f| < B. Quvvat PY = (N0/2)·2B = N0B; RY(τ) = N0B·sinc(2Bτ) — endi τ = 1/(2B) ga yaqin vaqtlardagi qiymatlar bog'liq. Son bilan: N0 = 10−8 V²/Hz, B = 10 kHz → PY = 10−4 V², σY = 10 mV.

RC filtr (13-dars, H = 1/(1 + j2πfRC)): PY = ∫(N0/2)/(1 + (2πfRC)²)df = N0/(4RC).

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (37-ma'ruza, 3-qism):

  1. Tasodifiy faza: m = A∫fφ(θ)cos(2πf0t + θ)dθ; R = (A²/2)E[cos(2πf0(t1 + t2) + 2φ)] + (A²/2)cos(2πf0(t1 − t2)).
  2. φ tekis [0, 2π]: fφ = 1/2π, m = 0, R = (A²/2)cos(2πf0(t1 − t2)) — faqat farqqa bog'liq; quvvat A²/2.
  3. Tekis taqsimot to'liq davrda bo'lmasa (masalan [0, π]) — o'rtacha vaqtga bog'liq.
  4. Deterministik: m = x(t), R = x(t1)x(t2), f = δ(x1 − x(t1)), 2-tartibli — deltalar ko'paytmasi; K = 0.
  5. Raqamli uzatish: m = ΣE[αi]r(t − iT); R = ΣΣE[αiαj*]r(t1 − iT)r*(t2 − jT); αi mustaqil.
  6. ±1 teng ehtimol: m = 0, E[αiαj] = δ(i − j), R = 1 bitta bit oralig'ida, 0 aks holda (PAM-4 da 5).
  7. (Qo'shimcha) WSS: m o'zgarmas, R = R(τ), τ = t1 − t2; R(0) — quvvat.
  8. (Qo'shimcha) SX(f) = F{RX(τ)}; oq shovqin: S = N0/2, R = (N0/2)δ(τ); SY = |H(f)|²SX, mY = mXH(0).
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
