18. Quvvat spektri, kesilgan signal, Gibbs effekti

O'qish vaqti: 50 daqiqa. Manba: 15-ma'ruza ("Power Spectrum (of periodic signals). Spectrum of Truncated Signals. The Gibbs' Effect"). Kerakli bilim: quvvat (4-dars), Furye qatori va Parseval (7-dars), davriy signal spektri (16-dars), energiya spektri va avtokorrelyatsiya (17-dars).

Bu B mavzu. Imtihonda: "Davriy signalning quvvat spektri?", "A·cos(2πf0t) ning quvvati / quvvat spektri?", "Rx(0) davriy signal uchun nimaga teng?", "Kesilgan signal spektri qanday?", "Gibbs effekti necha foiz?", "Kesish oynasi T qanday tanlanadi?".
Bu darsda nimani bilib olasiz: nega davriy signal uchun energiya spektri yaramaydi; quvvat spektri Gx(f) va davriy signal avtokorrelyatsiyasi; umumiy quvvat signali uchun periodogramma va chegara; filtrdan o'tgan quvvat; signalni kesish (oynalash) spektrga nima qiladi; Gibbs effekti va 9% qoidasi.

1. Davriy signalning quvvat spektri

16-darsdan: davriy signalning Furye almashtirishi bor (deltalar), lekin energiyasi cheksiz (4-dars) — demak 17-darsdagi energiya spektri |X(f)|² bu yerda ma'nosiz (δ² degan narsa yo'q). O'rtacha quvvati esa chekli. Shuning uchun yangi tushuncha kerak — quvvat spektri Gx(f), uning sharti:

∫−∞+∞ Gx(f) df = P(x)

Analogiya: energiya — bir umr ichilgan suv (cheksiz bo'lishi mumkin), quvvat — kuniga o'rtacha qancha suv. Abadiy oqayotgan buloq uchun "jami suv" cheksiz, lekin "kuniga" — aniq son. Quvvat spektri — shu o'rtacha qiymat chastotalar bo'yicha qanday taqsimlangani.

7-darsdagi Parseval (Furye qatori uchun): P(x) = Σi |μi|² — har bir garmonika o'z quvvatini beradi. Shuning uchun tabiiy ta'rif:

Gx(f) ≜ Σi |μi|²·δ(f − i/T)

Tekshiruv: ∫Gxdf = Σ|μi|²·∫δ(f − i/T)df = Σ|μi|²·1 = P(x) ✓.

Spektri X(f) = Σμiδ(f − i/T) bo'lsa, quvvat spektri — o'sha joylardagi chiziqlar, og'irligi |μi|².

Davriy signal avtokorrelyatsiyasi

Rx(τ) = (1/T)∫−T/2T/2 x(t + τ)x*(t) dt

17-darsdagidan farqi: integral faqat bitta davr bo'yicha va T ga bo'lingan (o'rtacha). Xossalar:

  • Rx(0) = (1/T)∫|x(t)|²dt = P(x) — nol nuqtadagi qiymat endi quvvat (energiya emas).
  • Gx(f) = F[Rx(τ)] — xuddi energiya holatidagidek.
  • Rx(τ) ham T davrli (so'nmaydi).

Misol 1: x(t) = A·cos(2πf0t)

μ±1 = A/2, qolganlari 0. Gx(f) = (A²/4)[δ(f − f0) + δ(f + f0)], P = 2·A²/4 = A²/2 (4-darsdagi bilan bir xil ✓).

Rx(τ) = (1/T)∫A²cos(2πf0(t + τ))cos(2πf0t)dt. cos a·cos b = ½[cos(a − b) + cos(a + b)]; ikkinchi had davr bo'yicha 0 ga integrallanadi:

Rx(τ) = (A²/2)·cos(2πf0τ)

Rx(0) = A²/2 = P ✓. F[Rx] = (A²/2)·½[δ(f − f0) + δ(f + f0)] = Gx ✓. Faza yo'qoldi: A·sin(2πf0t) ham aynan shu R va G ga ega.

Misol 2: to'rtburchak impulslar (τ = T/2, balandligi 1)

16-darsdan: μ0 = ½, μn = ½sinc(n/2): juft n ≠ 0 da 0, toq n da |μn| = 1/(π|n|).

Gx(f) = ¼δ(f) + Σn toq (1/(π²n²))δ(f − n/T).

P = ¼ + 2·(1/π²)(1 + 1/9 + 1/25 + …) = ¼ + 2·(1/π²)·(π²/8) = ¼ + ¼ = ½. Vaqtda: x² vaqtning yarmida 1, yarmida 0 → P = ½ ✓. O'zgarmas tashkil etuvchi (DC) quvvatning yarmini, garmonikalar qolgan yarmini olib yuradi.

2. Umumiy quvvat signali uchun quvvat spektri

Davriy bo'lmagan, lekin quvvati chekli signal uchun (masalan, shovqin) ta'rif murakkabroq. Signalni T uzunlikdagi oyna bilan kesamiz → xT(t), uning energiyasi chekli:

ST(f) = (1/T)·|XT(f)|²   — periodogramma (kesilgan signal energiya spektri, T ga normallangan)
Gx(f) ≜ limT→∞ (1/T)·|XT(f)|²
Φx(τ) ≜ F−1{Gx(f)} = limT→∞ (1/T)∫−T/2T/2 x(t + τ)x*(t) dt

Gx — oynadagi energiyani oyna uzunligiga bo'lib (o'rtacha quvvat), oynani cheksiz kengaytirish. Φx — o'rtacha avtokorrelyatsiya. Davriy signal uchun bu ta'riflar 1-bo'limdagilar bilan mos keladi.

Filtrdan o'tgan quvvat signali

Gy(f) = Gx(f)·|H(f)|²

Misol 3. x = A·cos(2πf0t) filtrdan o'tdi: Gy = (A²/4)|H(f0)|²[δ(f − f0) + δ(f + f0)] (|H| juft) → Py = (A²/2)|H(f0)|². Masalan, A = 2, RC filtr f0 = B3dB da (|H|² = ½, 15-dars): Py = 2·½ = 1 (kirishda 2 edi — quvvat yarmiga tushdi, "−3 dB").

Misol 4. O'zgarmas x(t) = A: μ0 = A → Gx = A²δ(f), P = A². HP filtrdan (H(0) = 0) keyin Py = 0.

3. Kesilgan signal spektri

Nega kerak? Spektrni kompyuterda (FFT bilan, 27-dars) hisoblaganda signalni har doim chekli T vaqt oynasida olamiz — cheksiz signalni xotiraga sig'dirib bo'lmaydi. Demak amalda doim kesilgan signal spektrini ko'ramiz. Kesish nimani buzadi?

xT(t) = x(t)·ΠT(t − θ) (θ atrofidagi T uzunlikdagi to'rtburchak oyna). Vaqtda ko'paytma → chastotada o'ram:

XT(f) = X(f) * F[ΠT(t − θ)] = X(f) * [T·sinc(fT)·e−j2πfθ]

θ = 0 (oyna markazi nolda): XT(f) = X(f) * T·sinc(fT).

  • Kesish spektrni jiddiy o'zgartirishi mumkin: har bir "ingichka" detal kengligi ~2/T bo'lgan sinc ga aylanadi.
  • x(t) polosasi chegaralangan (B) bo'lsa ham, kesilgan signal polosasi cheksiz bo'ladi: sinc ning yon "lob"lari o'ram integrali B dan tashqarida ham nolga teng bo'lmasligiga olib keladi.
  • Agar sinc ning asosiy lobi spektr detallariga nisbatan tor bo'lsa, o'ram deyarli δ bilan o'ramdek (lekin aynan emas): XT ≈ X.
Yaxshi yaqinlashish sharti (B — x(t) ning bir tomonlama polosasi):   1/T ≪ B   ⇒   T ≫ 1/B. Kesish oynasi signal polosasining teskarisidan ancha uzun bo'lishi kerak.

Misol 5. x(t) = cos(2πf0t), T uzunlikda kesildi. X = ½[δ(f − f0) + δ(f + f0)], δ ga o'ram — surish:

XT(f) = (T/2)·[sinc((f − f0)T) + sinc((f + f0)T)]

Ingichka chiziq o'rniga ±f0 atrofida kengligi 2/T (birinchi nollar orasi) bo'lgan "tepalik" va yon to'lqinlar — energiya qo'shni chastotalarga "oqib" ketadi (spectral leakage). Son bilan: f0 = 50 Hz, T = 0,1 s → asosiy lob 40…60 Hz. T = 1 s → 49…51 Hz — ancha aniq.

4. Gibbs effekti

Ma'ruza misoli: spektri ideal to'rtburchak bo'lgan signal (ma'ruzada ikki tomonlama polosa B ishlatiladi: −B/2 … B/2):

x(t) = B·sinc(Bt)   ↔   X(f) = ΠB(f)

Uni T uzunlikdagi oyna bilan kesamiz: xT(t) = x(t)·ΠT(t).

XT(f) = ∫X(a)·T·sinc((f − a)T)da = T·∫−B/2B/2 sinc((f − a)T)da

O'zgaruvchi almashtirish b = T(f − a), da = −db/T:

XT(f) = ∫T(f − B/2)T(f + B/2) sinc(b)db = Si(T(f + B/2)) − Si(T(f − B/2))

Bu yerda Si(x) = ∫0x sinc(b)db — "sinus integrali" maxsus funksiyasi (sinc = sin(πb)/(πb) bo'lgani uchun Si(∞) = ½). Uning xulqi: toq, x = 1 da maksimum ≈ 0,59, keyin ½ atrofida so'nuvchi tebranadi.

Natija: XT(f) asl to'rtburchakka o'xshaydi va T oshgan sari o'xshashlik ortadi (o'tish tikroq, tebranishlar zichroq — oralig'i ~1/T). Lekin uzilish (sakrash) nuqtalari yonida tebranish qoladi: maksimum ≈ 1,09, minimum ≈ −0,09.

Gibbs effekti: signal spektridagi uzilish nuqtalari atrofida tebranishlar paydo bo'ladi. O'ziga xosligi: T qanchalik katta bo'lmasin, sakrash balandligining taxminan 9% iga teng ortiqcha "oshib ketish" saqlanadi — u faqat torayadi, kamaymaydi. (Qayerdan 9%? Sakrash yonida bir had ≈ ½ ga teng, ikkinchisi Si ning maksimumi 0,59 ni beradi: ½ + 0,59 ≈ 1,09. Ortiqcha qism Si(1) − ½ ≈ 0,09.)

7-darsdagi to'rtburchak to'lqinning Furye qatori ham aynan shunday: garmonikalarni ko'paytirsak ham sakrash yonida ~9% "shox" qoladi. U yerda chastotada kesildi (garmonikalar soni chekli) — effekt vaqtda; bu yerda vaqtda kesildi — effekt chastotada. Duallik!

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (15-ma'ruza):

  1. Davriy signal: E = ∞, P chekli → quvvat spektri Gx, sharti ∫Gxdf = P.
  2. P = Σ|μi|²; Gx(f) = Σ|μi|²δ(f − i/T).
  3. Rx(τ) = (1/T)∫−T/2T/2x(t + τ)x*(t)dt; Rx(0) = P; Gx = F[Rx].
  4. A·cos(2πf0t): G = (A²/4)[δ(f ∓ f0)], P = A²/2, R = (A²/2)cos(2πf0τ).
  5. Umumiy: periodogramma ST = |XT|²/T; Gx = limT→∞|XT|²/T; Φx = F−1{Gx} = lim(1/T)∫x(t + τ)x*(t)dt.
  6. Filtr: Gy = |H|²Gx.
  7. Kesish: xT = x·ΠT(t − θ) → XT = X * T·sinc(fT)e−j2πfθ; polosa cheksizga aylanadi, yon loblar; shart T ≫ 1/B.
  8. Kesilgan cos: (T/2)[sinc((f − f0)T) + sinc((f + f0)T)], asosiy lob 2/T.
  9. Gibbs: B·sinc(Bt) kesilsa XT = Si(T(f + B/2)) − Si(T(f − B/2)); uzilish yonida 1,09 / −0,09 — ~9%, T ga bog'liq emas.
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
