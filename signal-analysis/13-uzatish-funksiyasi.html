13. Uzatish funksiyasi H(f), kauzallik, turg'unlik

O'qish vaqti: 45 daqiqa. Manba: 9-ma'ruza ("Linear Systems – transfer function"), imtihon jadvali.

Bu A mavzu. Imtihonda: "kirish cos(2πf₀t), chiqish qanday?", "bu h(t) kauzalmi, turg'unmi?", "ideal filtr fizik amalga oshiriladimi?" kabi savollar. Asosiy formula: Y(f) = H(f)·X(f).
Bu darsda nimani bilib olasiz: chastota javobi H(f); chiqishni chastotada hisoblash; sinusoida LTI tizimdan o'tganda nima bo'ladi; kauzallik, haqiqiylik, fizik amalga oshirish va BIBO turg'unlikni h(t) orqali tekshirish. 9 ta ishlangan misol.

1. Chastota javobi H(f)

H(f) = F{h(t)} = ∫h(t)e−j2πftdt

Ma'ruza: LTI tizimning chastota javobi (frequency response) — impuls javobining Furye almashtirishi. Uni ko'pincha uzatish funksiyasi (transfer function) ham deyishadi (aniqrog'i, uzatish funksiyasi — h(t) ning Laplas almashtirishi; ikkalasi yaqin bog'liq).

10-darsdagi o'ram xossasidan:

y(t) = x(t) * h(t)   ⇔   Y(f) = H(f)·X(f)      H(f) = Y(f)/X(f)

Ma'ruza buni "asosiy natija" deb ataydi. LTI tizim h(t) yoki H(f) bilan to'liq aniqlanadi; blok sxemada qutiga h(t) yoki H(f) yoziladi.

O'xshatish — ekvalayzer. Musiqa pleyeridagi ekvalayzerda har bir chastota uchun "tutqich" bor: past chastotalarni kuchaytirish, balandlarini pasaytirish. H(f) — xuddi shu tutqichlar holati: har bir f chastotadagi tarkibiy qism |H(f)| marta kuchayadi (yoki susayadi) va arg H(f) ga fazasi suriladi.

2. Sinusoida LTI tizimdan o'tganda

Aylanuvchi strelka

Kirish x(t) = ej2πf₀t → X(f) = δ(f − f₀). Y(f) = H(f)·δ(f − f₀) = H(f₀)·δ(f − f₀) (deltaning namuna olish xossasi, endi chastotada). Demak:

ej2πf₀t →   H(f₀)·ej2πf₀t

Kosinus (haqiqiy tizim, H(−f) = H*(f))

cos(2πf₀t) →   |H(f₀)|·cos(2πf₀t + arg H(f₀))
sin(2πf₀t) →   |H(f₀)|·sin(2πf₀t + arg H(f₀))

Ma'ruzaning asosiy xulosasi: LTI tizim sinusoidani xuddi shu chastotadagi sinusoidaga aylantiradi. Faqat amplituda (|H(f₀)| marta) va faza (arg H(f₀) ga) o'zgaradi. Yangi chastota paydo bo'lmaydi. Sinusoidalar LTI tizimning "xos funksiyalari" (auto-functions).

Amaliyotda (ma'ruza): spektr analizatori tizimga turli chastotali sinusoidalar beradi va har biri uchun chiqishning amplitudasi va fazasini o'lchaydi — shu yo'l bilan H(f) ni nuqtama-nuqta topadi.

1-misol: RC filtr

h(t) = a·e−atu(t), a > 0. H(f) = a/(a + j2πf) (8-dars). H(0) = 1.

Kirish cos(2πf₀t), f₀ = a/(2π): H(f₀) = a/(a + ja) = 1/(1 + j). |H| = 1/√2 ≈ 0,707, arg H = −π/4.

y(t) = (1/√2)·cos(2πf₀t − π/4). Bu chastota filtrning "kesish chastotasi" (amplituda √2 marta kamaydi, 15-dars).

2-misol: bir nechta sinusoida

Tizim — 0 dan T gacha quti (11-dars, sirpanuvchi integrator), T = 0,01 s. Kirish x(t) = 3 + 2cos(2π·50t).

H(f) = T·sinc(fT)·e−jπfT (quti T/2 ga surilgan).

Chiziqlilik bo'yicha har bir qismni alohida o'tkazamiz:

  • O'zgarmas qism (f = 0): H(0) = T = 0,01 → 3·0,01 = 0,03.
  • 50 Hz: fT = 0,5. sinc(0,5) = sin(π/2)/(π/2) = 2/π. e−jπ·0,5 = e−jπ/2. |H| = 0,01·2/π, arg H = −π/2.

y(t) = 0,03 + (0,04/π)·cos(2π·50t − π/2) = 0,03 + (0,04/π)·sin(2π·50t).

3-misol: H ni kirish va chiqishdan topish

x(t) = e−tu(t), y(t) = (e−t − e−2t)u(t). H(f) = ?

Y = 1/(1 + s) − 1/(2 + s) = 1/((1 + s)(2 + s)), X = 1/(1 + s), (s = j2πf).

H = Y/X = 1/(2 + j2πf) → h(t) = e−2tu(t). (10-darsdagi 3-misolning teskarisi.)

4-misol: aks-sado tizimi

y(t) = x(t) − x(t − T). h(t) = δ(t) − δ(t − T), H(f) = 1 − e−j2πfT.

e−jπfT ni qavsdan chiqaramiz: H = e−jπfT(ejπfT − e−jπfT) = 2j·sin(πfT)·e−jπfT. |H(f)| = 2|sin(πfT)|.

f = 0, 1/T, 2/T, … da |H| = 0: o'zgarmas signal va davri T ga karrali sinusoidalar butunlay o'chadi (bir xil qiymat ayriladi).

3. Kauzallik

O'ram integralini ikkiga ajratamiz (ma'ruza): y(t) = ∫−∞0 x(t − θ)h(θ)dθ + ∫0∞ x(t − θ)h(θ)dθ. Birinchi bo'lak (θ < 0) x ning kelajakdagi qiymatlariga bog'liq. Real vaqtda ishlaydigan tizim kelajakni bilmaydi, shuning uchun:

LTI tizim kauzal   ⇔   h(t) = 0, barcha t < 0 uchun

Mantiq oddiy: δ(t) t = 0 da keladi; kauzal tizim undan oldin javob bera olmaydi.

4. Haqiqiy tizim va fizik amalga oshirish

  • Haqiqiy tizim (haqiqiy kirish → haqiqiy chiqish) ⇔ h(t) haqiqiy ⇔ H(−f) = H*(f): Re H va |H| juft, Im H va arg H toq (9-darsdagi simmetriya).
  • Fizik amalga oshiriladigan (physically feasible) tizim = kauzal + haqiqiy: h(t) haqiqiy va t < 0 da nol.

5-misol: ideal past chastotali filtr fizik amalga oshirilmaydi

Ideal LPF: H(f) = 1, |f| < B da; 0, boshqa joyda (ya'ni p2B(f)). Kirish cos(2πf₁t) + cos(2πf₂t), f₁ < B < f₂ → chiqish faqat cos(2πf₁t).

Uning impuls javobi (duallik, 10-dars): h(t) = 2B·sinc(2Bt). sinc t < 0 da ham noldan farqli → kauzal emas → ideal filtrni real vaqtda qurib bo'lmaydi. Amalda unga faqat yaqinlashiladi (masalan, RC filtr yoki 31-darsdagi raqamli filtrlar).

5. BIBO turg'unlik

Ta'rif (ma'ruza): har qanday chegaralangan kirish (|x(t)| < ∞) chegaralangan chiqish beradi. Misol: mikrofon karnayga juda yaqin bo'lsa paydo bo'ladigan chiyillash (Larsen effekti) — turg'unmas tizim.

LTI tizim BIBO turg'un   ⇔   ∫−∞+∞ |h(t)| dt < ∞   (⇒ |H(f)| < ∞)

Isbot g'oyasi: |y(t)| = |∫x(t − τ)h(τ)dτ| ≤ max|x|·∫|h(τ)|dτ. Agar ∫|h| chekli bo'lsa, |y| ham chekli.

7-misol: eski imtihon savoli uslubida (chastotada)

8 va 11-darslardagi z(t) = δ(t) + e−1δ(t − T) ni h(t) — 0 dan T gacha quti bo'lgan tizimga beramiz. Chastotada:

Y(f) = Z(f)·H(f) = (1 + e−1e−j2πfT)·T·sinc(fT)·e−jπfT.

Vaqtga qaytsak: y(t) = h(t) + e−1h(t − T) — 11-darsdagi "zinapoya" ✓. Tizim kauzal (h = 0, t < 0) va turg'un (∫|h| = T).

O'zingizni tekshiring

1–6-savollar imtihondagi test shaklida.

1. LTI tizim kirishiga cos(2π·100t) berildi. Chiqishda qaysi chastotalar bo'lishi mumkin?
a) faqat 100 Hz   b) 100 va 200 Hz   c) istalgan   d) faqat 0 Hz
Javoba) LTI tizim yangi chastota hosil qilmaydi (H(100) = 0 bo'lsa chiqish 0 bo'lishi mumkin).
2. H(f₀) = 2e−jπ/3. Kirish cos(2πf₀t) uchun chiqish:
a) 2cos(2πf₀t − π/3)   b) cos(2πf₀t − 2π/3)   c) 2cos(2πf₀t)   d) 2cos(2πf₀t + π/3)
Javoba) |H(f₀)|cos(2πf₀t + arg H(f₀)).
3. LTI tizim kauzal bo'lishi sharti:
a) H(f) haqiqiy   b) h(t) = 0, t < 0   c) ∫|h| < ∞   d) h(t) juft
Javobb) c) — turg'unlik sharti.
4. h(t) = e−3|t|:
a) kauzal, turg'un   b) kauzal emas, turg'un   c) kauzal, turg'unmas   d) kauzal emas, turg'unmas
Javobb) t < 0 da noldan farqli; ∫ = 2/3.
5. Ideal past chastotali filtr:
a) kauzal   b) fizik amalga oshirilmaydi   c) h(t) quti   d) H(f) sinc
Javobb) h(t) = 2B·sinc(2Bt) — t < 0 da ham bor.
6. x(t) = e−tu(t) kirishda y(t) = e−tu(t) * e−tu(t) chiqdi. H(f) = ?
a) 1/(1 + j2πf)   b) 1/(1 + j2πf)²   c) 1   d) j2πf
Javoba) H = Y/X = X²/X = X.
7. Fizik amalga oshiriladigan tizim qanday ikki shartni bajaradi?
JavobKauzal (h = 0, t < 0) va haqiqiy (h haqiqiy).
8. y(t) = x(t) + x(t − 1) tizimida qaysi chastotali kosinus butunlay o'chadi?
JavobH = 1 + e−j2πf = 0 → e−j2πf = −1 → f = 1/2, 3/2, … Hz.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (9-ma'ruza):

  1. H(f) = F{h(t)} — chastota javobi; Y(f) = H(f)X(f), H = Y/X. LTI tizim h yoki H bilan to'liq aniqlanadi.
  2. ej2πf₀t → H(f₀)ej2πf₀t; haqiqiy tizimda cos(2πf₀t) → |H(f₀)|cos(2πf₀t + arg H(f₀)) (sin uchun xuddi shunday).
  3. LTI tizim yangi chastota yaratmaydi; sinusoidalar — xos funksiyalar. Bir nechta sinusoida — har birini alohida o'tkazing (chiziqlilik).
  4. Kauzal ⇔ h(t) = 0, t < 0.
  5. Haqiqiy ⇔ h haqiqiy ⇔ H(−f) = H*(f) (|H| juft, arg H toq).
  6. Fizik amalga oshiriladigan = kauzal + haqiqiy. Ideal filtr (h = sinc) — kauzal emas → amalga oshirilmaydi.
  7. BIBO turg'un ⇔ ∫|h(t)|dt < ∞ (⇒ |H(f)| chekli). e−atu(t) (a > 0) turg'un; e+atu(t), u(t) turg'unmas.
  8. Tayyor H: δ(t − T) → e−j2πfT; 0..T quti → T·sinc(fT)e−jπfT; a·e−atu(t) → a/(a + j2πf); δ(t) − δ(t − T) → |H| = 2|sin(πfT)|.
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
