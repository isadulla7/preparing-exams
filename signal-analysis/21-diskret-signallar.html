21. Diskret signallar va elementar ketma-ketliklar

O'qish vaqti: 45 daqiqa. Manba: 25-ma'ruza ("Introduction to discrete-time signals. Elementary sequences"), mashg'ulot: "Exercises 1 — Discrete signals, Elementary operations, Energy and power" (1a, 1e-masala).

Bu A mavzu — kursning ikkinchi yarmi (DTFT, Z-almashtirish, raqamli filtrlar) shu "alifbo" ustiga quriladi. Imtihonda tipik savollar: "bu ketma-ketlik davriymi, davri nechaga teng?", "kauzalmi?", "δ(n) va u(n) qanday bog'langan?", "cos(2πf0n) va cos(2π(f0+1)n) farqi bormi?".
Bu darsda nimani bilib olasiz: raqamli signalga ishlov berish (DSP) nima; diskret vaqtli signal; davomiylik, kauzallik, juftlik, davriylik, chegaralanganlik, yig'iluvchanlik; elementar ketma-ketliklar δ(n), u(n), sinc, uchburchak, aⁿu(n); diskret sinusoida va uning uchta "g'alati" xossasi.

1. Raqamli signalga ishlov berish (DSP)

DSP (Digital Signal Processing) — signalni ifodalovchi sonlar ketma-ketligiga arifmetik yoki mantiqiy amallar ketma-ketligini (algoritm) qo'llash. Maqsadlar (ma'ruza): signalni o'zgartirish, sifatini yaxshilash, undan ma'lumot ajratib olish. Misollar: MP3, mobil aloqa, nutqni tanish, seysmik va radar signallari, JPEG/MPEG, kosmik suratlar, tomografiya.

Real dunyo signallari analog bo'lgani uchun zanjir quyidagicha: analog signal → ADC → DSP (algoritm) → DAC → analog signal. ADC — diskretlash + kvantlash (19-dars).

2. Diskret vaqtli signal

Diskret vaqtli signal — mustaqil o'zgaruvchisi faqat butun qiymatlar qabul qiladigan signal. Bu o'zgaruvchi odatda n harfi bilan belgilanadi (n = …, −2, −1, 0, 1, 2, …). Signal — n bo'yicha raqamlangan sonlar ketma-ketligi; yozuvi: x(n), x[n] yoki xn. Agar amplitudalar ham faqat diskret qiymatlar olsa, signal raqamli (numeric, digital) deyiladi.

O'xshatish. Uzluksiz signal — tog' yo'lining profili (har bir nuqtada balandlik bor). Diskret signal — yo'l bo'yidagi kilometr ustunlaridagi balandlik yozuvlari: faqat 0, 1, 2, … km da qiymat bor. "1,5 km dagi qiymat" degan savolning o'zi yo'q — x(1,5) aniqlanmagan.

Ikki xil manba (ma'ruza):

  • Tabiatan diskret: birja kotirovkalari (har kuni bitta qiymat), lotereya raqamlari, har soatda o'lchangan harorat.
  • Diskretlash natijasi: CD dagi musiqa namunalari, internet orqali uzatilgan rasm namunalari.

Grafikda diskret signal "stem" (poyali) chizma bilan ko'rsatiladi: har bir n da vertikal chiziq va uchida nuqta. Nuqtalar orasida hech narsa yo'q.

3. Ketma-ketliklarning xossalari

Davomiylik

  • Chekli davomiylik: [n1, n2] oralig'idan tashqarida aynan nol. Vaqt tayanchi (support, namunalar soni): N = n2 − n1 + 1 (ikki uchi ham hisobga kiradi, shuning uchun "+1").
  • Cheksiz davomiylik: ikki tomonlama (−∞, +∞) yoki bir tomonlama [n1, +∞) yoki (−∞, n2].

Kauzallik

  • Kauzal: n < 0 da aynan nol (signal "0-lahzada boshlanadi").
  • Antikauzal: n ≥ 0 da aynan nol (faqat "o'tmishda" bor).
  • Ikki tomonlama (bilateral): musbat va manfiy n larda ham noldan farqli namunalar bor.

Juftlik (parity)

Haqiqiy ketma-ketlik uchun:

  • Juft (simmetrik): x(n) = x(−n) — n = 0 atrofida ko'zgudek.
  • Toq (antisimmetrik): x(n) = −x(−n). Bundan n = 0 da x(0) = −x(0), ya'ni toq ketma-ketlikda har doim x(0) = 0.

Kompleks ketma-ketlik uchun: qo'shma simmetrik x(n) = x*(−n), qo'shma antisimmetrik x(n) = −x*(−n) (* — kompleks qo'shma, 3-dars). Har qanday ketma-ketlikni ularning yig'indisiga ajratish mumkin:

xs(n) = ½[x(n) + x*(−n)],    xas(n) = ½[x(n) − x*(−n)],    x(n) = xs(n) + xas(n)

Haqiqiy signal uchun x* = x, shunda bu juft va toq qismlar: xp(n) = ½[x(n) + x(−n)], xd(n) = ½[x(n) − x(−n)].

Davriylik

x(n) davriy, agar shunday butun N topilsa: x(n) = x(n ± N) barcha n uchun. Davr — shu tenglik bajariladigan eng kichik musbat butun N. Davri N bo'lsa, kN (k — musbat butun) ham "davr" bo'ladi, lekin asosiy davr — eng kichigi.

4. Elementar ketma-ketliklar

Birlik pog'ona u(n)

u(n) = 0, n < 0;    u(n) = 1, n ≥ 0

Analog u(t) dan farqi: u(0) = 1 aniq belgilangan (analogda t = 0 dagi qiymat munozarali edi, ba'zan ½).

Kroneker deltasi (birlik impuls) δ(n)

δ(n) = 1, n = 0;    δ(n) = 0, n ≠ 0
Muhim farq (ma'ruza): Dirak deltasi δ(t) — t = 0 da "cheksiz baland", faqat integral orqali tushuniladigan g'alati funksiya. Kroneker deltasi δ(n) esa oddiy son: n = 0 da chekli amplituda 1. Diskret δ(n) va u(n) analog juftlaridagi "nozik" muammolarsiz aniqlangan.

δ(n) ning asosiy xossalari:

  • Namuna ajratish: x(n)·δ(n) = x(0)·δ(n),   x(n)·δ(n − i) = x(i)·δ(n − i).
  • Har qanday signal — deltalar yig'indisi: x(n) = Σi x(i)·δ(n − i). Ya'ni signal — har bir lahzadagi og'irligi x(i) bo'lgan "g'ishtchalar"dan qurilgan.
  • Pog'ona bilan bog'liqlik: u(n) = Σi≥0 δ(n − i) = δ(n) + δ(n−1) + δ(n−2) + …   va   δ(n) = u(n) − u(n − 1).

Oxirgi formula — analogdagi "δ(t) = du/dt" ning diskret varianti: hosila o'rniga ayirma, integral o'rniga yig'indi.

Sinc ketma-ketligi

sinc(n/N) = sin(πn/N) / (πn/N),   N — musbat butun

n = 0 da 1; n = ±N, ±2N, … da nol.

Uchburchak ketma-ketlik

t2N+1(n) = 1 − |n|/N, |n| ≤ N;    0, |n| > N

Indeks 2N+1 — n = −N … N dagi namunalar soni (ikki chetdagisi nolga teng). Ma'ruza misoli: N = 10, t21(n).

Eksponensial ketma-ketlik aⁿu(n)

x(n) = aⁿ·u(n), a — umuman kompleks son.

  • a haqiqiy, a > 0: ishora o'zgarmaydi (0 < a < 1 — so'nuvchi, a > 1 — o'suvchi).
  • a haqiqiy, a < 0: ishora navbatma-navbat almashadi (+, −, +, −, …), chunki (−1)ⁿ.
  • a kompleks, a = A·ejθ: x(n) = Aⁿ·ejnθ·u(n) — moduli Aⁿ bo'yicha o'zgaradi, fazasi har qadamda θ ga buriladi (aylana bo'ylab "spiral").

5. Diskret sinusoida va uning xossalari

x(n) = A·cos(2πf0n + θ) = A·cos(ω0n + θ),    x(n) = A·ej(2πf0n + θ)

A, θ — haqiqiy o'zgarmaslar; f0 — raqamli chastota (birligi: "namunadagi tebranishlar soni", o'lchovsiz); ω0 = 2πf0 — raqamli burchak chastota (rad/namuna). Eyler formulasi xuddi analogdagidek: A·cos(2πf0n + θ) = A·[ej(2πf0n+θ) + e−j(2πf0n+θ)]/2.

Diskretlash bilan bog'liqlik (19–20-darslar): analog cos(2πFt) ni fc bilan diskretlasak, x(n) = cos(2πF·nTc) = cos(2π(F/fc)n). Demak f0 = F / fc. Masalan, 1 kHz ni 8 kHz bilan diskretlasak, f0 = 1/8.

1-xossa: f0 va f0 + k — bir xil sinusoida

A·cos(2π(f0 + k)n + θ) = A·cos(2πf0n + 2πkn + θ) = A·cos(2πf0n + θ)

chunki k va n butun bo'lgani uchun 2πkn har doim 2π ga karrali. Xuddi shu kompleks eksponentaga ham tegishli. Natijalar (ma'ruza):

  • raqamli chastotalari butun songa farq qiladigan sinusoidalarni diskret vaqtda ajratib bo'lmaydi;
  • diskret signallarni chastotada tahlil qilishda uzunligi 1 bo'lgan oraliq yetarli: odatda (−½, ½] yoki [0, 1) (burchak chastotada (−π, π] yoki [0, 2π)).

Bu aslida 20-darsdagi aliasingning o'zi: F va F + kfc chastotali analog sinusoidalar bir xil namunalar beradi.

2-xossa: tebranish tezligi f0 = ½ gacha o'sadi, keyin kamayadi

Analog cos(2πf0t) da f0 qancha katta bo'lsa, shuncha tez tebranadi. Diskret sinusoidada esa tebranish f0 = ½ gacha tezlashadi (f0 = ½ da cos(πn) = (−1)ⁿ: +1, −1, +1, … — eng tez mumkin bo'lgan tebranish), keyin sekinlashadi va f0 = 1 da butunlay yo'qoladi (1-xossa bo'yicha f0 = 1 ≡ f0 = 0, o'zgarmas signal). Sababi: cos juft funksiya, shuning uchun cos(2π(1 − f0)n) = cos(2πf0n).

3-xossa: diskret sinusoida har doim ham davriy emas

x(n) = x(n + N) bo'lishi uchun cos(2πf0(n + N)) = cos(2πf0n), ya'ni 2πf0N — 2π ga karrali: N·f0 butun son bo'lishi kerak. Bu faqat f0 ratsional (kasr) bo'lganda mumkin.

Qoida: f0 ni qisqarmas kasr ko'rinishida yozing: f0 = k/N. Shunda davr — maxraj N. f0 irratsional bo'lsa (masalan, ω0 = 1 rad, ya'ni f0 = 1/(2π)), sinusoida davriy emas. Diskret sinusoida davri 1/f0 ga teng bo'lishi shart emas (1/f0 butun bo'lmasligi mumkin).

6. Yechilgan misollar

1-misol (Exercises 1, 1-masala signali)

x[n] = 0 (n < 0); n (0 ≤ n ≤ 10); 0 (n > 10). Davomiyligi, tayanchi, kauzalligi?

Noldan farqli qism 0 … 10 da → chekli davomiylik, n1 = 0, n2 = 10, N = 10 − 0 + 1 = 11 namuna (x[0] = 0 bo'lsa ham, oraliq ta'rifi bo'yicha). n < 0 da nol → kauzal. Chegaralangan (|x| ≤ 10), absolyut va kvadratik yig'iluvchi (chekli yig'indilar).

2-misol (Exercises 1, 1e-masala): juft va toq qismlarga ajratish

Xuddi shu x[n] ni juft va toq qismlar yig'indisiga ajrating.

x[−n] — x[n] ning ko'zgu aksi: −10 … 0 da qiymati |n|.

Juft qism: xp[n] = ½(x[n] + x[−n]). n > 0 da ½(n + 0) = n/2; n < 0 da ½(0 + |n|) = |n|/2; n = 0 da 0. Demak xp[n] = |n|/2, |n| ≤ 10 ("V" shakl, chetlarda 5).

Toq qism: xd[n] = ½(x[n] − x[−n]). n > 0 da n/2; n < 0 da ½(0 − |n|) = n/2. Demak xd[n] = n/2, |n| ≤ 10 (chiziq, −5 dan 5 gacha).

Tekshiruv: n = 4 da xp + xd = 2 + 2 = 4 = x[4] ✓; n = −4 da 2 + (−2) = 0 = x[−4] ✓.

3-misol: davrni topish

a) cos(2π·0,3n): f0 = 3/10 → N = 10.

b) cos(πn/4) = cos(2π·(1/8)n): f0 = 1/8 → N = 8.

c) sin(3πn/5) = sin(2π·(3/10)n): f0 = 3/10 → N = 10 (1/f0 = 3,33 — butun emas, lekin davr baribir 10).

d) cos(0,5n): ω0 = 0,5 → f0 = 0,5/(2π) = 1/(4π) — irratsional → davriy emas.

e) cos(2πn/6) + cos(2πn/4): davrlar 6 va 4 → yig'indining davri EKUK(6, 4) = 12.

4-misol: bir xil sinusoidalar (1 va 2-xossa)

cos(2π·1,2n) = cos(2π·0,2n + 2πn) = cos(2π·0,2n).

cos(2π·0,8n) = cos(2π·(1 − 0,2)n) = cos(2πn − 2π·0,2n) = cos(2π·0,2n) — 0,8 "tez" ko'rinadi, aslida 0,2 bilan bir xil sekin tebranadi.

Lekin sin uchun: sin(2π·0,8n) = −sin(2π·0,2n) (sin toq).

5-misol: deltalar orqali yozish

x(n) = {1, 2, 3} (n = 0, 1, 2 da; qolganida 0) → x(n) = δ(n) + 2δ(n − 1) + 3δ(n − 2).

u(n) − u(n − 3) = [δ(n) + δ(n−1) + δ(n−2) + δ(n−3) + …] − [δ(n−3) + δ(n−4) + …] = δ(n) + δ(n − 1) + δ(n − 2) — uzunligi 3 bo'lgan "quti".

x(n)·δ(n − 2) bu signal uchun = x(2)·δ(n − 2) = 3δ(n − 2).

6-misol: eksponensial ketma-ketlik

(0,5)ⁿu(n): 1; 0,5; 0,25; 0,125; … — so'nuvchi, musbat.

(−0,5)ⁿu(n): 1; −0,5; 0,25; −0,125; … — so'nuvchi, ishorasi almashadi.

(ejπ/2)ⁿu(n) = jⁿu(n): 1; j; −1; −j; 1; … — moduli 1, har qadamda 90° buriladi, davri 4.

7-misol: yig'iluvchanlik

a) (0,5)ⁿu(n): Σ|x| = 1 + 0,5 + 0,25 + … = 1/(1 − 0,5) = 2 — absolyut yig'iluvchi. Σ|x|² = 1/(1 − 0,25) = 4/3 — kvadratik yig'iluvchi. (Geometrik qator: Σn≥0 qⁿ = 1/(1 − q), |q| < 1.)

b) u(n): Σ|x| = 1 + 1 + 1 + … = ∞ — yig'iluvchi emas, lekin chegaralangan (|x| ≤ 1).

c) u(n)/(n + 1): Σ 1/(n+1) — garmonik qator, ∞ → absolyut yig'iluvchi emas; Σ 1/(n+1)² = π²/6 — kvadratik yig'iluvchi. Demak "chekli energiya" "absolyut yig'iluvchi" dan kuchsizroq shart.

8-misol: analog chastotadan raqamli chastotaga

x(t) = cos(2π·1500t), fc = 6 kHz. f0 = 1500/6000 = 1/4 → x(n) = cos(πn/2): 1, 0, −1, 0, 1, … — davri 4 namuna. Agar fc = 1 kHz bo'lsa, f0 = 1,5 ≡ 0,5 → (−1)ⁿ — aliasing (1500 Hz 500 Hz kabi ko'rinadi).

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (25-ma'ruza):

  1. DSP — sonlar ketma-ketligiga algoritm qo'llash (o'zgartirish, yaxshilash, ma'lumot ajratish). Zanjir: analog → ADC → DSP → DAC.
  2. Diskret signal x(n): n — butun. Amplitudasi ham diskret bo'lsa — raqamli.
  3. Chekli davomiylik [n1, n2]: tayanch N = n2 − n1 + 1.
  4. Kauzal: x(n) = 0, n < 0. Antikauzal: x(n) = 0, n ≥ 0. Ikki tomonlama — ikkalasida ham bor.
  5. Juft x(n) = x(−n); toq x(n) = −x(−n) (x(0) = 0). Ajratish: xp = ½[x(n) + x(−n)], xd = ½[x(n) − x(−n)] (kompleksda x*(−n)).
  6. Davriy: x(n) = x(n + N), N — eng kichik musbat butun.
  7. Chegaralangan |x| ≤ X0; absolyut yig'iluvchi Σ|x| < ∞; kvadratik yig'iluvchi Σ|x|² < ∞ (chekli energiya).
  8. δ(n): n = 0 da 1 (chekli!), aks holda 0. u(n): n ≥ 0 da 1. x(n) = Σx(i)δ(n − i); x(n)δ(n − i) = x(i)δ(n − i); u(n) = Σi≥0δ(n − i); δ(n) = u(n) − u(n − 1).
  9. sinc(n/N) = sin(πn/N)/(πn/N); uchburchak t2N+1(n) = 1 − |n|/N (|n| ≤ N).
  10. aⁿu(n): a > 0 — ishora o'zgarmas; a < 0 — almashadi; a = Aejθ → Aⁿejnθ.
  11. Diskret sinusoida A·cos(2πf0n + θ); f0 = F/fc — raqamli chastota.
  12. 1-xossa: f0 va f0 + k bir xil → (−½, ½] yoki [0, 1) oralig'i yetarli. 2-xossa: tebranish f0 = ½ gacha tezlashadi, f0 = 1 da yo'qoladi. 3-xossa: davriy ⇔ Nf0 butun ⇔ f0 ratsional; f0 = k/N (qisqarmas) → davr N.
