27. DFT amalda: DTFT ni baholash, zero-padding, tez o'ram

O'qish vaqti: 45 daqiqa. Manba: 31-ma'ruza ("Relationship between DFT and DTFT. Estimation of the Fourier Transform using the DFT. Use of DFT to compute Linear Convolution"). Kerakli bilim: DFT va davriy kengaytma (25-dars), aylanma o'ram (26-dars).

Bu B mavzu. Imtihonda: "DFT X(k) DTFT ning qaysi chastotalardagi namunasi?", "zero-padding nima beradi / nima bermaydi?", "N nuqtali to'rtburchakning N nuqtali DFT si?", "cheksiz ketma-ketlikni kesib DFT olsak, qanday xato bo'ladi?", "chiziqli o'ramni DFT bilan hisoblash uchun nechta nol qo'shish kerak?", "tez o'ram murakkabligi?".
Bu darsda nimani bilib olasiz: DFT namunalaridan butun DTFT ni tiklash (interpolyatsiya formulasi); zero-padding — DTFT ni zichroq ko'rish usuli; ma'ruzaning 2 ta misoli (to'rtburchak va aⁿu(n)) — son va rasm bilan; vaqtda aliasing; chiziqli o'ramni FFT orqali tez hisoblashning 4 qadami va qo'lda bajarilgan misol.

1. DFT va DTFT: eslatma

X(k) = Σn=0N−1 x(n)e−j2πnk/N = X(ej2πf)|f = fk,    fk = k/N, k = 0 … N − 1

Uzunligi N bo'lgan ketma-ketlikning DFT si — uning DTFT sidan (uzluksiz egri chiziq) bir davr [0, 1) da teng oraliqda olingan N ta namuna. O'xshatish: DTFT — tog' tizmasining to'liq surati, DFT — tizma bo'ylab har N-chi qadamda o'lchangan balandliklar.

2. DFT namunalaridan DTFT ni tiklash

Savol (ma'ruza): faqat N ta X(k) ni bilsak, butun X(ej2πf) ni topa olamizmi? Ha — agar x(n) aynan N ta namunadan iborat bo'lsa.

1-qadam. DTFT ta'rifiga x(n) ni IDFT ko'rinishida qo'yamiz va yig'indilar o'rnini almashtiramiz:

X(ej2πf) = Σn=0N−1 [(1/N)Σk=0N−1X(k)ej2πnk/N]e−j2πfn = (1/N)Σk=0N−1X(k)·Σn=0N−1e−j2πn(f − k/N)

2-qadam. Ichki yig'indi — geometrik qator (25-darsdagi to'rtburchak bilan bir xil hisob, θ = π(f − k/N)):

Σn=0N−1e−j2πn(f − k/N) = (1 − e−j2πN(f − k/N))/(1 − e−j2π(f − k/N)) = [sin(πNf − kπ)/sin(πf − πk/N)]·e−jπ(N−1)(f − k/N)

Natija — interpolyatsiya formulasi:

X(ej2πf) = (1/N)·Σk=0N−1 X(k)·[sin(πNf − kπ)/sin(πf − πk/N)]·e−jπ(N−1)(f − k/N)

(Ma'ruza slaydida bu yerda ichki yig'indi Σn=−∞+∞ deb yozilgan; x(n) faqat 0 … N − 1 da noldan farqli bo'lgani uchun aslida Σn=0N−1.)

Ma'nosi: DTFT = N ta DFT namunasining "silliq ulanishi" (interpolyatsiyasi). Har bir X(k) o'zining "do'ng" funksiyasini (sin(πNf)/sin(πf) ko'rinishidagi) chizadi, ularning yig'indisi butun egri chiziqni beradi. Tekshiruv: f = k0/N da kasr k = k0 uchun N ga (0/0 chegarasi), qolgan k larda 0 ga teng (surat sin(π(k0 − k)) = 0) → X(ej2πk0/N) = (1/N)·X(k0)·N = X(k0) ✓.

3. DFT — DTFT ni amalda hisoblash vositasi (zero-padding)

Real signallar chekli: bizda faqat N ta namuna bor. DTFT ni zichroq to'rda ko'rmoqchimiz: fk = k/N1, k = 0 … N1 − 1, bunda N1 ≫ N:

X(ej2πk/N1) = Σn=0N−1 x(n)e−j2πnk/N1

Bu hali DFT emas (yig'indi N gacha, maxrajda N1). Uni DFT ga aylantirish uchun x(n) oxiriga N1 − N ta nol qo'shamiz — zero-padding ("nol bilan to'ldirish"):

xz(n) = x(n), n = 0 … N − 1;   xz(n) = 0, n = N … N1 − 1

Nollar yig'indiga hech narsa qo'shmaydi, shuning uchun:

X(ej2πk/N1) = Σn=0N1−1 xz(n)e−j2πnk/N1 = xz ning N1 nuqtali DFT si

Zero-padding haqida 3 ta qoida (ma'ruza):
  1. Nollar yangi ma'lumot qo'shmaydi — DTFT o'zi o'zgarmaydi.
  2. Ular faqat DTFT ni zichroq namunalashga imkon beradi: f qadami 1/N dan 1/N1 ga kichrayadi — grafik uzluksiz egri chiziqqa yaqinlashadi (ma'ruzada: "spektr tasviridagi chastota ajratuvchanligi oshadi").
  3. MATLAB da: fft(x, N1) — x ga avtomatik ravishda N1 − N ta nol qo'shadi.

4. Ma'ruza misoli 2: N namunali to'rtburchak

x(n) = 1, n = 0 … N − 1 (N = 10). N nuqtali DFT (25-dars, misol 3):

X(k) = Σn=0N−1e−j2πnk/N = (1 − e−j2πk)/(1 − e−j2πk/N) = 0, k ≠ 0   ⇒   X(k) = N·δ(k)

Bitta chiziq (k = 0 da 10), qolgani nol. Lekin DTFT nol emas! Ma'ruza izohi: bu holda N nuqtali DFT ma'noli emas — "chastota ajratuvchanligi" yetarli emas: namunalar DTFT ning aynan nollariga tushib qolgan.

N ta nol qo'shamiz (N1 = 2N = 20):

Xz(k) = Σn=0N−1e−j2πnk/(2N) = (1 − e−jπk)/(1 − e−jπk/N) = [sin(πk/2)/sin(πk/(2N))]·e−jπ(k/2)(1 − 1/N)

(25-darsdagi "yarim fazani chiqarish" usuli: 1 − e−j2θ = e−jθ·2j·sin θ, surat va maxrajga alohida.)

Endi faqat juft k (k ≠ 0) larda nol (sin(πk/2) = 0); toq k larda nol emas: masalan k = 1: |Xz| = 1/sin(π/20) ≈ 6,39, k = 3: 1/sin(3π/20) ≈ 2,20. (Slaydda "juft n" deb yozilgan — juft k bo'lishi kerak.)

N1 = 1000 (990 ta nol): namunalar shunchalik zichki, grafik amalda uzluksiz DTFT ning o'zi:

|X(ej2πf)| = |sin(πfN)/sin(πf)|

MATLAB da [−½, ½] oraliqda ko'rsatish uchun fftshift ishlatiladi (spektrning ikkinchi yarmini [½, 1) → [−½, 0) ga ko'chiradi; davri 1 bo'lgani uchun bu to'g'ri).

5. Ma'ruza misoli 3: cheksiz ketma-ketlik DTFT sini baholash

x(n) = aⁿu(n), 0 < a < 1 — cheksiz davomli. Uning DTFT si aniq ma'lum (24-dars):

X(ej2πf) = Σn=0∞(ae−j2πf)ⁿ = 1/(1 − ae−j2πf)

A) DTFT ning aniq namunalari (f = k/N):

X(k) = 1/(1 − ae−j2πk/N)

B) Amalda qiladiganimiz: ketma-ketlikni N ta namunada kesamiz va DFT olamiz (geometrik yig'indi, e−j2πk = 1):

XN(k) = Σn=0N−1(ae−j2πk/N)ⁿ = (1 − aᴺe−j2πk)/(1 − ae−j2πk/N) = (1 − aᴺ)/(1 − ae−j2πk/N)

Taqqoslash: maxrajlar bir xil, farq faqat suratdagi (1 − aᴺ) ko'paytuvchida: XN(k) = (1 − aᴺ)·X(k).

Bu farq — vaqtda aliasing. DTFT ni N nuqtada namunalash vaqtda signalni N davr bilan takrorlaydi (25-dars). Cheksiz signalning nusxalari bir-birining ustiga tushadi: x̃(n) = Σm≥0x(n + mN) = aⁿ(1 + aᴺ + a2N + …) = aⁿ/(1 − aᴺ). Ya'ni aniq namunalar X(k) aslida ustma-ust tushgan x̃(n) ning DFT si; biz esa kesilgan aⁿ ning DFT sini olamiz — farqi 1/(1 − aᴺ) marta.

Xato qanchalik katta? a = 0,8 (ma'ruza grafiklari):

N = 5: aᴺ = 0,8⁵ ≈ 0,328 → XN aniq qiymatdan ~33% kichik.

N = 10: 0,8¹⁰ ≈ 0,107 → ~11%.   N = 20: 0,8²⁰ ≈ 0,012 → ~1%.

Xulosa: N oshgan sari aᴺ → 0 va aliasing xatosi yo'qoladi — chunki eksponensial signal ma'lum vaqtdan keyin amalda nolga teng. Qoida: kesish uzunligi N shunday tanlanadiki, signal "dumi" kichik bo'lsin.

6. Chiziqli o'ramni DFT bilan tez hisoblash

26-darsda ko'rdik: X(k)·Y(k) ning IDFT si — aylanma o'ram, va u odatda chiziqli o'ramdan farq qiladi. Lekin uzun ketma-ketliklarda chastota sohasiga o'tish (FFT bilan) juda tez. Ma'ruza g'oyasi: chiziqli o'ramni aylanma o'ram orqali hisoblash — buning uchun ikkala ketma-ketlikka yetarli nol qo'shish kerak.

Nega ishlaydi? x(n) (uzunligi Nx) va h(n) (uzunligi Nh) ning chiziqli o'rami y(n) uzunligi Ny = Nx + Nh − 1. Ikkalasini nol bilan Ny gacha uzaytiramiz: xz, hz. xz faqat [0, Ny − 1] da aniqlangan, shuning uchun

y(n) = Σm=−∞∞xz(m)hz(n − m) = Σm=0Ny−1xz(m)hz(n − m) = xz(n) ⊗ hz(n)

Aylanma o'ramda "boshiga qaytadigan" namuna qolmaydi (26-darsdagi vaqtda aliasing yo'q) → aylanma = chiziqli.

Tez o'ram: 4 qadam

  1. Nol qo'shish: xz(n), hz(n) — uzunligi Ny = Nx + Nh − 1.
  2. DFT: Ny nuqtali Xz(k) = DFT[xz], Hz(k) = DFT[hz].
  3. Ko'paytirish: Yz(k) = Xz(k)·Hz(k).
  4. IDFT: y(n) = IDFT[Yz(k)] (Ny nuqtali).
Murakkablik: Ny ni 2 ning darajasi qilib tanlab (kerak bo'lsa yana nol qo'shib), 3 ta DFT ni FFT bilan hisoblasak — ~Ny·log2Ny. To'g'ridan-to'g'ri (vaqtda) o'ram — ~Nx·Nh. Masalan Nx = Nh = 1000: vaqtda ~10⁶ ko'paytirish; FFT bilan Ny = 1999 → 2048, 3 ta FFT ≈ 3·2048·11 ≈ 68 000 amal — ~15 marta tez.

Qo'lda misol: x = {1, 2}, h = {3, 4}. Chiziqli o'ram (tekshirish uchun): y = {3, 4 + 6, 8} = {3, 10, 8}, Ny = 2 + 2 − 1 = 3.

1) N = 4 olamiz (≥ 3 va 2 ning darajasi): xz = {1, 2, 0, 0}, hz = {3, 4, 0, 0}.

2) 4 nuqtali DFT (e−j2πnk/4 = (−j)nk): Xz(k) = 1 + 2(−j)k = {3, 1 − 2j, −1, 1 + 2j};   Hz(k) = 3 + 4(−j)k = {7, 3 − 4j, −1, 3 + 4j}.

3) Ko'paytma: Y(0) = 21; Y(1) = (1 − 2j)(3 − 4j) = 3 − 4j − 6j + 8j² = −5 − 10j; Y(2) = 1; Y(3) = −5 + 10j (qo'shma).

4) IDFT: y(n) = (1/4)ΣY(k)jnk:

y(0) = (21 − 5 − 10j + 1 − 5 + 10j)/4 = 12/4 = 3

y(1) = (21 + (−5 − 10j)j − 1 + (−5 + 10j)(−j))/4 = (21 + 10 − 5j − 1 + 10 + 5j)/4 = 40/4 = 10

y(2) = (21 + 5 + 10j + 1 + 5 − 10j)/4 = 32/4 = 8

y(3) = (21 + (−5 − 10j)(−j) − 1 + (−5 + 10j)j)/4 = (21 − 10 + 5j − 1 − 10 − 5j)/4 = 0

Natija {3, 10, 8, 0} — chiziqli o'ram {3, 10, 8} ✓ (oxirgi 0 — qo'shimcha nol joyi).

Agar nol yetarli bo'lmasa (N = 2): {11, 10} chiqadi — 26-darsdagi 9-savol: 8 boshiga qo'shilib ketadi.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (31-ma'ruza):

  1. X(k) = X(ej2πf)|f=k/N — DFT = DTFT ning bir davrdagi N ta teng namunasi.
  2. Interpolyatsiya: X(ej2πf) = (1/N)ΣX(k)·sin(πNf − kπ)/sin(πf − πk/N)·e−jπ(N−1)(f−k/N) — N uzunlikdagi x uchun DFT DTFT ni to'liq belgilaydi.
  3. Zero-padding: N1 − N ta nol → N1 nuqtali DFT = DTFT ning f = k/N1 dagi namunalari; ma'lumot qo'shmaydi, faqat zichroq ko'rsatadi. fft(x,N1).
  4. To'rtburchak (N ta 1): N nuqtali DFT = Nδ(k); 2N nuqtada nollar faqat juft k ≠ 0 da; DTFT = sin(πfN)/sin(πf) (moduli).
  5. aⁿu(n): aniq namunalar 1/(1 − ae−j2πk/N), kesilgan DFT (1 − aᴺ)/(1 − ae−j2πk/N) — farq vaqtda aliasing; N ↑ → aᴺ → 0.
  6. Chastotada namunalash ⇔ vaqtda N davr bilan takrorlash: x̃(n) = Σx(n + mN).
  7. Chiziqli o'ram = aylanma o'ram, agar ikkalasi Ny ≥ Nx + Nh − 1 gacha nol bilan to'ldirilsa.
  8. Tez o'ram: nol qo'shish → 2 ta DFT → ko'paytirish → IDFT; ~Nylog2Ny (FFT) vs ~NxNh.
  9. fftshift — spektrni [−½, ½) ga markazlash.
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
