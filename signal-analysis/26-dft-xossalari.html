26. DFT xossalari va aylanma o'ram

O'qish vaqti: 50 daqiqa. Manba: 30-ma'ruza ("Properties of the Discrete Fourier Transform (DFT)"). Kerakli bilim: DFT ta'rifi va davriy kengaytma (25-dars), chiziqli o'ram (22-dars), DTFT xossalari (24-dars).

Bu B mavzu. Imtihonda: "⟨−3⟩8 = ?", "x(⟨n − N0⟩N) ning DFT si?", "aylanma o'ram DFT da nimaga teng?", "{…} va {…} ning aylanma o'rami?", "chiziqli / aylanma o'ram uzunligi?", "DFT uchun Parseval?", "haqiqiy x(n) da X(k) va X(N − k) bog'liqligi?".
Bu darsda nimani bilib olasiz: modul ⟨k⟩N va aylanma kechikish (soat misolida); DFT xossalari jadvali — har biri son bilan tekshirilgan; aylanma o'ram, uni qo'lda va matritsa bilan hisoblash; chiziqli va aylanma o'ram farqi (vaqtda aliasing); haqiqiy ketma-ketlik DFT sining simmetriyasi.

1. Nega yangi amallar kerak?

25-darsda ko'rdik: DFT ketma-ketlikni N davr bilan takrorlanadi deb hisoblaydi (davriy kengaytma x̃(n)). Shuning uchun DTFT xossalari DFT ga deyarli o'zgarishsiz o'tadi — faqat ikki narsani almashtirish kerak (ma'ruzadagi eslatmalar):

  • f o'rniga k/N yoziladi;
  • ketma-ketliklar (vaqtda ham, chastotada ham) davriy kengaytma sifatida qaraladi.

Xossalarni chekli N ta namunaga (n = 0 … N − 1) qaytarish uchun ikki yangi tushuncha kiritiladi: modul va aylanma kechikish. Uzunligi har xil ketma-ketliklarda esa qisqasi oxiriga nollar qo'shib uzaytiriladi (masalan, {1, 2, 2} → {1, 2, 2, 0}, N = 4).

Hayotiy o'xshatish: oddiy son o'qi — cheksiz to'g'ri chiziq; DFT ning "o'qi" esa aylana (soat siferblati kabi). Soatda 11 dan keyin 12 emas, yana 0 keladi. DFT da ham n = N − 1 dan keyin yana n = 0 keladi. Shuning uchun DFT dagi siljish va o'ram "aylanma" deyiladi.

2. Modul ⟨k⟩N

⟨k⟩N = k mod N — k ni N ga bo'lgandagi qoldiq, doim 0 … N − 1 oralig'idagi son

Amalda: k ga N ni qo'shib yoki ayirib boring, natija 0 … N − 1 oralig'iga tushguncha. Soat misolida: 12 soatli siferblatda "15 soat" — bu 3 (15 − 12); "−1 soat" — bu 11 (−1 + 12).

Ma'ruza misollari (N = 16):

⟨5⟩16 = 5 (allaqachon 0 … 15 da).

⟨21⟩16 = 21 − 16 = 5.

⟨−13⟩16 = −13 + 16 = 3. (Manfiy son uchun — N ni qo'shamiz. −13 mod 16 = −13 emas!)

N = 4 uchun: ⟨−1⟩4 = 3, ⟨−2⟩4 = 2, ⟨4⟩4 = 0, ⟨6⟩4 = 2, ⟨−5⟩4 = 3 (−5 + 8).

Eng ko'p ishlatiladigani: ⟨−k⟩N = N − k (k = 1 … N − 1 da), ⟨0⟩N = 0.

3. Aylanma kechikish

x(⟨n − N0⟩N) = x̃(n − N0),    n ∈ [0, N − 1]

Ma'ruzadagi 3 qadam:

  1. x(n) ning davriy kengaytmasini yasaymiz (N davr bilan takrorlaymiz);
  2. uni N0 namunaga kechiktiramiz (o'ngga suramiz);
  3. faqat [0, N − 1] oynani qoldiramiz.

Natija: oxiridan "chiqib ketgan" namunalar boshiga qaytib kiradi. Aylana ustidagi sonlarni bir qadam aylantirgandek.

Misol: x = {1, 0, 2, 3}, N = 4.

N0 = 1: y(n) = x(⟨n − 1⟩4): y(0) = x(⟨−1⟩4) = x(3) = 3, y(1) = x(0) = 1, y(2) = x(1) = 0, y(3) = x(2) = 2 → {3, 1, 0, 2}.

N0 = 2: {2, 3, 1, 0}.   N0 = −1 (oldinga surish): {0, 2, 3, 1}.   N0 = 4: yana {1, 0, 2, 3} (to'liq aylanish).

Taqqoslang: oddiy (chiziqli) kechikish x(n − 1) = {0, 1, 0, 2, 3} — uzunligi 5 ga oshadi. Aylanma kechikishda uzunlik 4 bo'lib qoladi, oxirgi "3" boshiga o'tadi.

4. DFT xossalari jadvali

x(n), y(n) — uzunligi N; X(k), Y(k) — ularning N nuqtali DFT si.

XossaVaqtdaDFT
Chiziqlilika1x(n) + a2y(n)a1X(k) + a2Y(k)
(Aylanma) kechikishx(⟨n − N0⟩N)X(k)·e−j2πkN0/N
Modulyatsiyaej2πk0n/N·x(n)X(⟨k − k0⟩N)

Bu jadval DTFT jadvalining (24-dars) aynan nusxasi: e−j2πfN0 → e−j2πkN0/N, oddiy siljish → aylanma siljish, oddiy o'ram → aylanma o'ram, ∫df → (1/N)Σ.

Quyidagi tekshiruvlarda bitta ketma-ketlikdan foydalanamiz: x = {1, 0, 2, 3}. Uning DFT si (e−j2πnk/4 = (−j)nk):

X(k) = 1 + 2(−1)k + 3·jk   (n = 3 da e−j3πk/2 = jk)

X(0) = 1 + 2 + 3 = 6;   X(1) = 1 − 2 + 3j = −1 + 3j;   X(2) = 1 + 2 − 3 = 0;   X(3) = 1 − 2 − 3j = −1 − 3j.

4.1. Chiziqlilik

Yig'indining DFT si = DFT lar yig'indisi (yig'indi belgisi chiziqli bo'lgani uchun). Faqat ikkala ketma-ketlik bir xil N ga keltirilgan bo'lishi kerak (qisqasiga nollar qo'shiladi).

4.2. Aylanma kechikish → faza ko'paytuvchisi

Isbot g'oyasi: y(n) = x(⟨n − N0⟩N). Y(k) = Σn x(⟨n − N0⟩N)e−j2πnk/N. m = ⟨n − N0⟩N deb belgilaymiz: n bir davrni aylanib chiqqanda m ham 0 … N − 1 ni bir martadan oladi; e−j2πnk/N davri N bo'lgani uchun n = m + N0 deb yozish mumkin:

Y(k) = Σm=0N−1 x(m)e−j2π(m + N0)k/N = e−j2πkN0/N·X(k) ✓

Son bilan tekshiruv: y = {3, 1, 0, 2} (N0 = 1). Y(1) = 3 + 1·(−j) + 0 + 2·j = 3 + j. Formula: X(1)·e−jπ/2 = (−1 + 3j)(−j) = j + 3 = 3 + j ✓.

Xulosa: |Y(k)| = |X(k)| — aylanma siljish faqat fazani o'zgartiradi, amplituda spektri o'zgarmaydi.

4.3. Modulyatsiya → spektrning aylanma siljishi

ej2πk0n/N ga ko'paytirish spektrni k0 qadam aylanma suradi (kechikishning "chastotadagi juftligi" — duallik).

Misol: k0 = 1, N = 4: ej2πn/4 = jn = {1, j, −1, −j}. y(n) = jnx(n) = {1, 0, −2, −3j}.

Kutilgan natija: Y(k) = X(⟨k − 1⟩4) = {X(3), X(0), X(1), X(2)} = {−1 − 3j, 6, −1 + 3j, 0}.

Tekshiruv: Y(0) = Σy = 1 + 0 − 2 − 3j = −1 − 3j ✓.

4.4. Ko'paytma

Vaqtda ko'paytirish → chastotada aylanma o'ram (1/N bilan). Bu aylanma o'ram xossasining "teskari tomoni" (duallik), xuddi analog Furyedagi kabi (10-dars).

4.5. Parseval (DFT uchun)

Σn=0N−1 |x(n)|² = (1/N)·Σk=0N−1 |X(k)|²

Tekshiruv 1: x = {1, 0, 2, 3}: chap tomon 1 + 0 + 4 + 9 = 14. O'ng tomon: |X|² = 36, 10, 0, 10 → (36 + 10 + 0 + 10)/4 = 56/4 = 14 ✓.

Tekshiruv 2: {1, 0, 3, −2} (25-dars): X = {2, −2 − 2j, 6, −2 + 2j}, |X|² = 4, 8, 36, 8 → 56/4 = 14 = 1 + 9 + 4 ✓.

Diqqat — tuzoq: 1/N ni unutmang! Σ|X(k)|² = 56 ≠ 14. (DTFT Parsevalida ∫−½½df edi, DFT da (1/N)Σ — N ta nuqta bo'yicha "o'rtacha".)

5. Aylanma o'ram

Ta'rif

zcc(n) = x(n) ⊗ y(n) = Σp=0N−1 x(p)·y(⟨n − p⟩N),    n ∈ [0, N − 1]

(cc — "circular convolution".) Chiziqli o'ramga (22-dars) o'xshaydi, lekin ikki farqi bor (ma'ruza):

  • natija aynan N ta namunadan iborat;
  • o'ram N davrli ikki davriy ketma-ketlikka qo'llangan deb qaraladi: zcc(n) = Σp=0N−1 x̃(p)ỹ(n − p).
O'xshatish: ikki halqa tasavvur qiling. Ichki halqada x ning N ta soni, tashqi halqada y ning sonlari teskari tartibda. Har bir n uchun tashqi halqani bir qadam buramiz, ro'para turgan sonlarni ko'paytirib qo'shamiz. Chiziqli o'ramda y to'g'ri chiziq bo'ylab "sirpanib o'tib ketadi"; aylanma o'ramda u chiqib ketmaydi — boshqa tomondan qaytib kiradi.

Davriylik (ma'ruza isboti): zcc(n + N) = Σp x(p)ỹ(n + N − p) = Σp x(p)ỹ(n − p) = zcc(n), chunki ỹ davri N. Shuning uchun faqat n ∈ [0, N − 1] qiymatlar kerak.

Kommutativlik: y ⊗ x = Σp y(p)x̃(n − p); k = ⟨n − p⟩N almashtirish bilan = Σk y(⟨n − k⟩N)x(k) = x ⊗ y ✓. Ya'ni qaysi birini "aylantirish" farqi yo'q.

DFT bilan bog'liqlik (eng muhim!): x ⊗ y ↔ X(k)·Y(k). Isbot g'oyasi: DFT[x ⊗ y] = Σpx(p)·DFT[y(⟨n − p⟩N)] = Σpx(p)·Y(k)e−j2πkp/N = X(k)Y(k) (4.2-xossa).

Ma'ruza misoli: chiziqli va aylanma o'ram

x(n) = {1, 0, 2, 3} (N1 = 4),   y(n) = {1, 2, 2} (N2 = 3).

A) Chiziqli o'ram z(n) = Σk x(k)y(n − k). Ma'ruza eslatmasi: chekli ketma-ketliklarda oldiga va orqasiga yetarlicha nol qo'shiladi. "Ag'darib, surib, ko'paytirib, qo'shish" (22-dars):

k−2−1012345
x(k)00102300
y(−k)22100000
y(1 − k)02210000
y(2 − k)00221000
y(3 − k)00022100

Har bir qatorda x(k) bilan ustma-ust ko'paytirib qo'shamiz:

z(0) = 1·1 = 1;   z(1) = 1·2 + 0·1 = 2;   z(2) = 1·2 + 0·2 + 2·1 = 4;   z(3) = 0·2 + 2·2 + 3·1 = 7;   z(4) = 2·2 + 3·2 = 10;   z(5) = 3·2 = 6.

z(n) = {1, 2, 4, 7, 10, 6} — uzunligi 4 + 3 − 1 = 6

B) Aylanma o'ram, N = 4. Avval y ni N = 4 gacha nol bilan to'ldiramiz: y = {1, 2, 2, 0}, ya'ni y(0) = 1, y(1) = 2, y(2) = 2, y(3) = 0. Indekslar mod 4 da: y(−1) → y(3), y(−2) → y(2), y(−3) → y(1).

zcc(0) = x(0)y(0) + x(1)y(3) + x(2)y(2) + x(3)y(1) = 1·1 + 0·0 + 2·2 + 3·2 = 1 + 0 + 4 + 6 = 11

zcc(1) = x(0)y(1) + x(1)y(0) + x(2)y(3) + x(3)y(2) = 2 + 0 + 0 + 6 = 8

zcc(2) = x(0)y(2) + x(1)y(1) + x(2)y(0) + x(3)y(3) = 2 + 0 + 2 + 0 = 4

zcc(3) = x(0)y(3) + x(1)y(2) + x(2)y(1) + x(3)y(0) = 0 + 0 + 4 + 3 = 7

zcc(n) = {11, 8, 4, 7} — chiziqli o'ramdan butunlay boshqacha!

Yodlash uchun qoida: zcc(n) da indekslar yig'indisi p + ⟨n − p⟩ har doim n (mod N) ga teng: zcc(0) da juftliklar (0,0), (1,3), (2,2), (3,1) — yig'indilar 0, 4, 4, 4 ≡ 0.

Matritsa ko'rinishi

Aylanma o'ramni "matritsa × vektor" ko'rinishida yozish mumkin (ma'ruza). Matritsa birinchi ustunni (y(0), y(1), y(2), y(3)) siklik aylantirib hosil qilinadi — har keyingi ustun pastga bir qadam surilgan (pastdan chiqqani tepaga o'tadi). Bunday matritsa sirkulyant deyiladi.

y(3)y(2)y(1)y(0)x(3)

Masalan, 1-qator: 1·1 + 0·0 + 2·2 + 2·3 = 11 ✓; 2-qator: 2·1 + 1·0 + 0·2 + 2·3 = 8 ✓.

DFT orqali tekshiruv

X = {6, −1 + 3j, 0, −1 − 3j} (yuqorida). y = {1, 2, 2, 0} ning DFT si: Y(k) = 1 + 2(−j)k + 2(−1)k:

Y(0) = 5,   Y(1) = 1 − 2j − 2 = −1 − 2j,   Y(2) = 1 − 2 + 2 = 1,   Y(3) = −1 + 2j.

X·Y: k = 0: 6·5 = 30; k = 1: (−1 + 3j)(−1 − 2j) = 1 + 2j − 3j + 6 = 7 − j; k = 2: 0; k = 3: 7 + j.

{11, 8, 4, 7} ning DFT si: k = 0: 11 + 8 + 4 + 7 = 30 ✓; k = 1: 11 − 8j − 4 + 7j = 7 − j ✓; k = 2: 11 − 8 + 4 − 7 = 0 ✓. Ya'ni DFT larni ko'paytirib IDFT qilsak — aylanma o'ram chiqadi (chiziqli emas!).

Uzunliklar va nega natija boshqacha

Chiziqli o'ram uzunligi: N = N1 + N2 − 1.   Aylanma o'ram uzunligi: N = max(N1, N2).

Chiziqli o'ram 6 ta namuna beradi, aylanma o'ramda esa faqat 4 ta "joy" bor. Ortiqcha namunalar (z(4) = 10, z(5) = 6) yo'qolmaydi — ular aylana bo'ylab boshiga qaytib, o'sha joydagi qiymatga qo'shiladi:

zcc(n) = Σm z(n + mN):   11 = 1 + 10,   8 = 2 + 6,   4 = 4,   7 = 7

Bu hodisa vaqtda aliasing (vaqtda ustma-ust tushish) — 19-darsdagi aliasingning "ko'zgu"dagi aksi: u yerda chastotada diskretlash spektrni takrorlab ustma-ust qo'yardi, bu yerda chastotada diskretlash (DFT) vaqtdagi signalni takrorlab ustma-ust qo'yadi.

Amaliy xulosa (27-darsga ko'prik): agar ikkala ketma-ketlikni nollar bilan N ≥ N1 + N2 − 1 gacha uzaytirsak, "boshiga qaytadigan" namuna qolmaydi va aylanma o'ram = chiziqli o'ram bo'ladi. Misolda N = 6: x = {1, 0, 2, 3, 0, 0}, y = {1, 2, 2, 0, 0, 0} → zcc = {1, 2, 4, 7, 10, 6} = z ✓. Shu yo'l bilan chiziqli o'ramni FFT yordamida tez hisoblash mumkin (27-dars).

6. Haqiqiy ketma-ketlik DFT sining simmetriyasi

x(n) haqiqiy bo'lsa (ma'ruza jadvali; DTFT dagi simmetriyalarning nusxasi, faqat "−k" o'rniga ⟨−k⟩N = N − k):

x(n) ∈ ℝDFT X(k)
umumiy holdaX(k) = XR(k) + jXI(k) (kompleks)
haqiqiyX(k) = X*(⟨−k⟩N), ya'ni X(N − k) = X*(k)
modul|X(k)| = |X(⟨−k⟩N)| — juft (mod N)
fazaφ(X(k)) = −φ(X(⟨−k⟩N)) — toq (mod N)
x(n) juftX(k) = XR(k) — haqiqiy
x(n) toqX(k) = jXI(k) — sof mavhum

Tekshiruv: x = {1, 0, 2, 3}: X(3) = −1 − 3j = (−1 + 3j)* = X*(1) ✓ (3 = 4 − 1). X(0) va X(N/2) = X(2) doim haqiqiy (6 va 0) — chunki ⟨−0⟩ = 0, ⟨−2⟩4 = 2, ular o'z-o'ziga juft.

Amaliy foyda: haqiqiy signalda X(k) ning yarmini bilsak, qolgan yarmi avtomatik (qo'shma). N = 8 da X(5), X(6), X(7) = X*(3), X*(2), X*(1).

"Juft" bu yerda aylanma ma'noda: x(n) = x(⟨−n⟩N), ya'ni x(N − n) = x(n) (x(0) ixtiyoriy). Masalan N = 4 da {a, b, c, b} ko'rinish. "Toq": x(N − n) = −x(n), bundan x(0) = 0 (juft N da x(N/2) = 0 ham).

Juft misol: x = {2, 1, 0, 1} (x(3) = x(1)). X(k) = 2 + (−j)k + jk = 2 + 2cos(πk/2) → {4, 2, 0, 2} — haqiqiy ✓.

Toq misol: x = {0, 1, 0, −1}. X(k) = (−j)k − jk = −2j·sin(πk/2) → {0, −2j, 0, 2j} — sof mavhum ✓.

Tuzoq: {1, 2, 1} (N = 3) ko'zga simmetrik ko'rinadi, lekin aylanma juft emas: x(1) = 2 ≠ x(2) = 1. Uning DFT si haqiqiy emas: X(1) = 1 + 2e−j2π/3 + e−j4π/3 = −0,5 − j0,87.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (30-ma'ruza):

  1. DFT xossalari = DTFT xossalari, f → k/N, ketma-ketliklar davriy kengaytma sifatida; uzunligi har xil bo'lsa — nol qo'shiladi.
  2. ⟨k⟩N = k mod N ∈ [0, N − 1]; manfiyga N qo'shiladi: ⟨−13⟩16 = 3, ⟨−k⟩N = N − k.
  3. Aylanma kechikish: davriy kengaytma → N0 ga surish → [0, N − 1] oyna. {1, 0, 2, 3} → {3, 1, 0, 2}.
  4. x(⟨n − N0⟩N) ↔ X(k)e−j2πkN0/N (|X| o'zgarmaydi).
  5. ej2πk0n/Nx(n) ↔ X(⟨k − k0⟩N).
  6. x ⊗ y = Σp=0N−1x(p)y(⟨n − p⟩N) ↔ X(k)Y(k); davri N, kommutativ.
  7. x(n)y(n) ↔ (1/N)ΣpX(p)Y(⟨k − p⟩N).
  8. Parseval: Σ|x(n)|² = (1/N)Σ|X(k)|².
  9. Uzunlik: chiziqli N1 + N2 − 1, aylanma max(N1, N2). Misol: {1,0,2,3}, {1,2,2}: chiziqli {1,2,4,7,10,6}, aylanma {11,8,4,7}.
  10. zcc(n) = Σmz(n + mN) (vaqtda aliasing); N ≥ N1 + N2 − 1 da aylanma = chiziqli.
  11. Aylanma o'ram = sirkulyant matritsa × vektor.
  12. Haqiqiy x: X(k) = X*(⟨−k⟩N) = X*(N − k); |X| juft, faza toq; aylanma juft x → X haqiqiy, toq x → X sof mavhum.
