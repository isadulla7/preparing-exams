17. Energiya spektri va korrelyatsiya

O'qish vaqti: 50 daqiqa. Manba: 14-ma'ruza ("Energy spectrum and correlation function"), mashg'ulot: Propedeutic Exercises, Fourier bo'limi 4-masala (avtokorrelyatsiya). Kerakli bilim: energiya (4-dars), Parseval va o'ram (10-dars), skalyar ko'paytma g'oyasi.

Bu B mavzu. Imtihonda: "Rx(0) nimaga teng?", "Avtokorrelyatsiyaning Furye almashtirishi?", "Haqiqiy signal avtokorrelyatsiyasi qanday xossalarga ega?", "Filtrdan keyin energiya?", "to'rtburchak impuls avtokorrelyatsiyasi?". Diskret varianti 23-darsda — formulalar bir xil, faqat integral o'rniga yig'indi.
Bu darsda nimani bilib olasiz: energiya spektri Sx(f) va uning fizik ma'nosi; LTI tizimdan o'tganda energiya spektri; avtokorrelyatsiya funksiyasi, uning Sx bilan bog'liqligi va 4 xossasi (isbotlari bilan); o'zaro korrelyatsiya va o'zaro energiya spektri; ikki signal yig'indisining energiyasi; korrelyatsiya amalda (o'xshashlik, kechikishni topish); 6 ta ishlangan misol.

1. Energiya spektri

Sx(f) = |X(f)|²

Energiya spektri — signal Furye almashtirishining modul kvadrati. Nega "energiya"? Parseval tengligi (10-dars):

E(x) = ∫−∞+∞ |x(t)|² dt = ∫−∞+∞ |X(f)|² df = ∫−∞+∞ Sx(f) df

Energiya spektrining integrali — signal energiyasi. O'lchov birligi: energiya / chastota birligi (masalan, J/Hz). Muhandislikda uni qisqacha "spektr" yoki "spektral tarkib" deyishadi.

Analogiya: aholi zichligi (kishi/km²) — bir km² da qancha odam yashashini ko'rsatadi; butun hudud bo'yicha integral olsak — umumiy aholi. Sx(f) ham shunday: har bir chastota atrofida "1 Hz ga qancha energiya to'g'ri keladi".

LTI tizimdan o'tganda

Y(f) = H(f)·X(f) → |Y(f)|² = |H(f)|²·|X(f)|²:

Sy(f) = |H(f)|²·Sx(f),    E(y) = ∫−∞+∞ |H(f)|²·Sx(f) df

Faza muhim emas — energiya spektriga faqat |H|² ta'sir qiladi.

Fizik ma'no

Kirishga ingichka polosali filtr qo'yamiz: |H(f)|² = 1 faqat f0 atrofidagi Δf kenglikdagi tor oraliqda. Chiqishdagi energiya deyarli hammasi f0 atrofida, u yerda Sx ≈ Sx(f0) — o'zgarmas:

E(y) = ∫Sy(f)df ≈ Sx(f0)·Δf

Demak Sx(f0) — f0 atrofidagi tor polosaga to'g'ri keladigan energiya, birlik kenglikka. (Haqiqiy signalda −f0 atrofida ham xuddi shunday polosa bo'lsa, natija ikki baravar.)

2. Avtokorrelyatsiya funksiyasi

Rx(τ) = ∫−∞+∞ x(t + τ)·x*(t) dt    (chekli energiyali signal uchun)

Signaldan yangi funksiya hosil qilinadi — o'zgaruvchisi τ (siljish, "lag"). Ma'nosi: signalni o'zining τ ga surilgan nusxasi bilan skalyar ko'paytirish — ular qanchalik o'xshash?

Analogiya: ikkita bir xil rasmli shaffof plyonkani ustma-ust qo'ying. Aniq ustma-ust tushganda (τ = 0) rasm eng yorqin. Birini sekin sura boshlasangiz, mos kelish kamayadi. Rx(τ) — har bir siljishdagi "mos kelish darajasi".

O'ram bilan bog'liqlik. O'ram: (a * b)(τ) = ∫a(t)b(τ − t)dt. b(t) = x*(−t) olsak: ∫x(t)x*(t − τ)dt = [t → t + τ] = ∫x(t + τ)x*(t)dt. Demak

Rx(τ) = x(τ) * x*(−τ)

— signalning o'zi bilan "o'rami" (faqat ikkinchisi teskari aylantirilgan va qo'shmasi olingan). "Avto" (o'zi bilan) korrelyatsiya nomi shundan.

Energiya spektri bilan bog'liqlik. Jadvaldan: x*(−t) ↔ X*(f). O'ram → ko'paytma:

F[Rx(τ)] = X(f)·X*(f) = |X(f)|² = Sx(f)

Energiya spektri — avtokorrelyatsiyaning Furye almashtirishi: Rx(τ) ↔ Sx(f). Teskarisi: Rx(τ) = ∫Sx(f)ej2πfτdf. τ = 0 da: Rx(0) = ∫Sxdf = ∫|x(t)|²dt = E(x) — avtokorrelyatsiyaning nol nuqtadagi qiymati signal energiyasi.

Xossalar

1) Ermit simmetriyasi: Rx(τ) = Rx*(−τ).

Isbot: Rx*(−τ) = [∫x(t − τ)x*(t)dt]* = ∫x*(t − τ)x(t)dt. t′ = t − τ almashtirish: = ∫x(t′ + τ)x*(t′)dt′ = Rx(τ). (Ma'ruzada t′ = t + τ bilan xuddi shunday.)

x(t) haqiqiy bo'lsa: Rx haqiqiy va juft: Rx(τ) = Rx(−τ).

2) Maksimum τ = 0 da: Shvars tengsizligi (|∫ab*|² ≤ ∫|a|²·∫|b|²):

|Rx(τ)|² = |∫x(t + τ)x*(t)dt|² ≤ ∫|x(t + τ)|²dt·∫|x(t)|²dt = E² = Rx²(0)

Ya'ni |Rx(τ)| ≤ Rx(0): signal hech qachon o'zining surilgan nusxasiga o'ziga o'xshaganidan ko'proq o'xshamaydi.

Haqiqiy x(t) uchun avtokorrelyatsiya: 1) haqiqiy; 2) juft; 3) maksimumi τ = 0 da; 4) maksimum = signal energiyasi E(x).

3. O'zaro korrelyatsiya

Ikki turli signal uchun xuddi shu g'oya:

Rxy(τ) = ∫−∞+∞ x(t + τ)·y*(t) dt = Ryx*(−τ)

O'zaro korrelyatsiya funksiyasi. Uning Furye almashtirishi — o'zaro energiya spektri: Sxy(f) = F[Rxy] = X(f)·Y*(f).

Ikki signal yig'indisining energiyasi

z(t) = x(t) + y(t) → Z = X + Y →

Sz = |X + Y|² = |X|² + |Y|² + XY* + X*Y = Sx + Sy + 2Re[Sxy(f)]

(XY* + (XY*)* = 2Re(XY*).) Vaqtda xuddi shunday: Rz = Rx + Ry + Rxy + Ryx = Rx + Ry + 2Re[Rxy(τ)] (haqiqiy signallar uchun yozilgan).

Xulosa: yig'indining energiyasi energiyalar yig'indisiga teng emas — o'zaro had bor. Faqat Rxy(0) = 0 bo'lsa (signallar ortogonal, masalan spektrlari ustma-ust tushmasa) E(z) = E(x) + E(y).

Amalda

O'zaro korrelyatsiya — signallar o'xshashligini o'lchash vositasi. Bir to'plam xi(t) ichidan namuna x(t) ga eng o'xshashini topish kerak bo'lsa, x(t) bilan o'zaro korrelyatsiyasi eng katta bo'lganini tanlaymiz. Qo'llanishi: nutqni tanish (ovozli yordamchilar), rasm bo'yicha qidiruv, sun'iy yo'ldosh navigatsiyasi (GPS — signal kechikishi orqali masofa).

4. Ishlangan misollar

Misol 1: to'rtburchak impuls x(t) = A·pT(t)

Vaqtda: x(t + τ)x(t) — ikki to'rtburchak ustma-ust tushgan qism, balandligi A², kengligi T − |τ| (|τ| < T). Rx(τ) = A²(T − |τ|) = A²T·tri(τ/T) — asosi −T…T, cho'qqisi A²T bo'lgan uchburchak.

Tekshiruv: Rx(0) = A²T = E ✓; juft ✓; maksimum 0 da ✓.

Chastotada: Sx = |A·T·sinc(fT)|² = A²T²·sinc²(fT). Jadval: T·tri(τ/T) ↔ T²·sinc²(fT) — bir xil ✓.

Misol 2: x(t) = e−atu(t), a > 0

τ ≥ 0: Rx(τ) = ∫0∞ e−a(t+τ)e−atdt = e−aτ·1/(2a). Juftlikdan: Rx(τ) = e−a|τ|/(2a).

Sx(f) = |1/(a + j2πf)|² = 1/(a² + 4π²f²). Tekshiruv: F[e−a|τ|] = 2a/(a² + 4π²f²), 2a ga bo'lsak — aynan Sx ✓. E = Rx(0) = 1/(2a).

Misol 3 (Propedeutic, 4-masala): x(t) = 2pT/2(t + T/4) + pT/2(t − T/4)

x(t): (−T/2, 0) da balandligi 2, (0, T/2) da balandligi 1 (9-darsdagi 3-misol). Rx(τ) ni toping.

Chastota usuli (yechimlar faylidagi kabi). 9-darsdan: X(f) = T·sinc(fT/2)·[ejπfT/2 + ½e−jπfT/2].

|ejθ + ½e−jθ|² = (ejθ + ½e−jθ)(e−jθ + ½ejθ) = 1 + ¼ + ½ej2θ + ½e−j2θ, θ = πfT/2:

Sx(f) = T²sinc²(fT/2)·[5/4 + ½ejπfT + ½e−jπfT]

Jadval: a·tri(τ/a) ↔ a²·sinc²(fa). a = T/2 da: (T/2)·tri(2τ/T) ↔ (T²/4)·sinc²(fT/2), demak T²sinc²(fT/2) ↔ 2T·tri(2τ/T) (asosi −T/2…T/2). e±jπfT = e±j2πf(T/2) — vaqtda ∓T/2 ga surish:

Rx(τ) = (5T/2)·tri(2τ/T) + T·tri(2(τ + T/2)/T) + T·tri(2(τ − T/2)/T)

Vaqt usuli bilan tekshiruv. τ = 0: R = ∫x² = 2²·(T/2) + 1²·(T/2) = 5T/2 = E ✓. τ = T/2: surilgan nusxaning "2" li bo'lagi asl "1" li bo'lak ustiga tushadi: 2·1·(T/2) = T ✓. |τ| ≥ T: ustma-ust tushish yo'q → 0 ✓. Oraliqlarda chiziqli (to'rtburchaklar korrelyatsiyasi chiziqli o'zgaradi).

Misol 4: kechikishni topish (GPS g'oyasi)

Qabul qilingan signal y(t) = x(t − t0) (x — ma'lum kod, t0 — noma'lum kechikish). O'zaro korrelyatsiya (haqiqiy signallar):

Ryx(τ) = ∫x(t + τ − t0)x(t)dt = Rx(τ − t0)

Rx ning maksimumi 0 da → Ryx ning maksimumi τ = t0 da. Cho'qqi joyi — kechikish. Signal tezligi c bo'lsa, masofa d = c·t0. (Lab 2 dagi xcorr misoli aynan shu.)

Misol 5: filtrdan keyingi energiya

x(t) = pT(t) (E = T) ideal LP filtrdan (|H| = 1, |f| < 1/T) o'tdi. E(y) = ∫−1/T1/T T²sinc²(fT)df = T·∫−11 sinc²(u)du ≈ 0,903·T. Ya'ni to'rtburchak impuls energiyasining ~90% i sinc ning asosiy "lob"ida (15-darsdagi "x% polosa" bilan bog'liq).

Misol 6: yig'indi energiyasi

x(t) = pT(t), y(t) = pT(t − T/2). E(x) = E(y) = T. Rxy(0) = ∫x(t)y(t)dt = ustma-ust qism = T/2. E(z) = T + T + 2·(T/2) = 3T. Tekshiruv: z — (−T/2, 0) da 1, (0, T/2) da 2, (T/2, T) da 1: 1·(T/2) + 4·(T/2) + 1·(T/2) = 3T ✓.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (14-ma'ruza):

  1. Sx(f) = |X(f)|²; E = ∫|x|²dt = ∫Sxdf; birligi — energiya/Hz.
  2. LTI: Sy = |H|²Sx, E(y) = ∫|H|²Sxdf. Tor filtr: E(y) ≈ Sx(f0)Δf.
  3. Rx(τ) = ∫x(t + τ)x*(t)dt = x(τ) * x*(−τ) — surilgan nusxa bilan skalyar ko'paytma.
  4. Rx(τ) ↔ Sx(f); Rx(0) = E(x).
  5. Rx(τ) = Rx*(−τ); |Rx(τ)| ≤ Rx(0) (Shvars). Haqiqiy x: haqiqiy, juft, maksimum 0 da = E.
  6. Rxy(τ) = ∫x(t + τ)y*(t)dt = Ryx*(−τ); Sxy = XY*.
  7. z = x + y: Sz = Sx + Sy + 2Re Sxy, Rz = Rx + Ry + 2Re Rxy.
  8. Misollar: A·pT → A²T·tri(τ/T); e−atu(t) → e−a|τ|/(2a) ↔ 1/(a² + 4π²f²); Propedeutic 4: R(0) = 5T/2, R(±T/2) = T, R(±T) = 0.
  9. y = x(t − t0) → Ryx(τ) = Rx(τ − t0), cho'qqi τ = t0 da (GPS, xcorr).
O'qib bo'ldingizmi? Chatga "tushundim" deb yozing. "Tushunmadim" bo'lsa, qaysi joy qiyin bo'lganini ayting, darsni soddaroq qilib qayta yozaman.
