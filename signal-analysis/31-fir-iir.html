31. Impuls javobi, chastota javobi, FIR va IIR

O'qish vaqti: 55 daqiqa. Manba: 35-ma'ruza ("Zero-state Discrete Time LTI Systems. Impulse Response & Frequency Response. Digital Filters and Block Schemes"), mashg'ulot: "Exercises 3 — Linear systems" (2, 3, 6-masalalar).

Bu A mavzu. Imtihonda: "h(n) = … tizimiga x(n) berilsa, y(n) = ?", "H(z) = … — FIR mi, IIR mi?", "cos(ω0n) kirishga chiqish?", "|H(ejω)| qaysi chastotada nol?", "Y(z) ning ROC i?". Bu 13-darsdagi uzluksiz uzatish funksiyasining diskret varianti.
Bu darsda nimani bilib olasiz: impuls javobi va y = x * h; kauzal tizim; chastota javobi H(ejω) va sinusoidaning LTI tizimdan o'tishi; uzatish funksiyasi H(z) va Y = XH; raqamli filtrlar: FIR va IIR; blok sxemalar; ma'ruza va mashg'ulotdagi barcha misollar.

1. Impuls javobi

Nol boshlang'ich holatdagi LTI tizim xulqi bitta funksiya — impuls javobi h(n) bilan to'liq aniqlanadi: h(n) = L[δ(n)], ya'ni kirish δ(n) bo'lganda chiqish.

Nega y = x * h? (ma'ruza isboti)

1) Har qanday signal — deltalar yig'indisi (21-dars): x(n) = Σi x(i)δ(n − i).

2) L ni qo'llaymiz. L va yig'indi — ikkalasi chiziqli, tartibini almashtirish mumkin; x(i) n ga bog'liq emas — L dan tashqariga chiqadi (chiziqlilik): y(n) = Σi x(i)·L[δ(n − i)].

3) Statsionarlik: L[δ(n − i)] = h(n − i). Demak:

y(n) = Σi=−∞+∞ x(i)·h(n − i) = x(n) * h(n)

Natija: har qanday LTI tizimni norekursiv ko'rinishda (o'ram sifatida) yozish mumkin. O'ramni ikkiga ajratsak (kommutativlik bilan):

y(n) = Σi=−∞−1 h(i)x(n − i)  +  Σi=0+∞ h(i)x(n − i)

Ikkinchi yig'indi — allaqachon kirgan (joriy va o'tgan) namunalar ta'siri; birinchisi — kelajakdagi namunalar ta'siri.

Kauzal tizim ⇔ h(n) = 0, n < 0. Shunda y(n) = Σi=0∞ h(i)x(n − i) — chiqish faqat joriy va o'tgan kirishlarga bog'liq.

Ma'ruza misoli: x(n) = u(n) − u(n − 3), h(n) = aⁿu(n), 0 < a < 1

y(n) = Σi=02 an−iu(n − i) = aⁿ·Σi a−iu(n − i); u(n − i) = 1 faqat i ≤ n da.

n = 0, 1, 2 (qisman kirish, i = 0 … n): y(n) = aⁿ·(1 − a−(n+1))/(1 − a−1) = (1 − an+1)/(1 − a).

n ≥ 2 (uchala namuna kirgan, i = 0 … 2): y(n) = aⁿ·(1 − a−3)/(1 − a−1) = an−2·(1 − a³)/(1 − a). (n = 2 da ikkala formula bir xil: 1 + a + a².)

a = 0,5 da: y = 1; 1,5; 1,75; 0,875; 0,4375; … (MATLAB: conv(ones(1,3), 0.5.^(0:10))).

2. Chastota javobi

x(n) va h(n) ning DTFT si mavjud bo'lsin. y = x * h ning DTFT sini hisoblaymiz (m = n − i almashtirish):

Y(ejω) = Σi h(i)e−jωi · Σm x(m)e−jωm = H(ejω)·X(ejω)

Bu yerda

H(ejω) = Σi=−∞+∞ h(i)·e−jωi = DTFT[h(n)] = Y(ejω)/X(ejω)

— tizimning chastota javobi: ω = 2πf ning kompleks funksiyasi, davri 2π (21-dars, 1-xossa). Uzluksizdagi kabi: vaqtda o'ram → chastotada ko'paytma.

Sinusoida LTI tizimdan o'tganda

Kirish x(n) = ejω0n: y(n) = Σh(i)ejω0(n−i) = ejω0n·Σh(i)e−jω0i = H(ejω0)·ejω0n = |H(ejω0)|·ej(ω0n + φH(ω0)).

Kompleks sinusoida — LTI tizimning xos funksiyasi (autofunction): tizimdan o'tib shaklini saqlaydi, faqat H(ejω0) songa ko'payadi. Muhimi — H ning faqat ω0 dagi qiymati.

Haqiqiy h(n) va kirish x(n) = cos(ω0n + θ) bo'lsa: Eyler bilan ikki eksponentaga ajratib, |H| juft, φ toq ekanidan (Furye simmetriyasi):

y(n) = |H(ejω0)|·cos(ω0n + θ + φH(ω0))

Chastota o'zgarmaydi; amplituda |H| ga ko'payadi, faza φH ga suriladi (13-darsdagi bilan aynan bir xil).

3. Uzatish funksiyasi H(z)

Nol holatdagi LTI tizim uchun y = h * x. Z-almashtirishning o'ram xossasi (29-dars):

Y(z) = X(z)·H(z),    H(z) = Z[h(n)] = Y(z)/X(z)

H(z) — uzatish funksiyasi. H(ejω) = H(z)|z=ejω (birlik aylanada, 28-dars). Y(z) ning ROC i — umumiy holda X va H ROC larining kesishmasi; lekin qutb-nol qisqarishi bo'lsa, kengayishi mumkin.

4. Raqamli filtrlar

Raqamli filtr — uzatish funksiyasi H(z) bo'lgan LTI tizim, ya'ni ayirmali tenglama (30-dars):

y(n) = −Σk=1M aky(n − k) + Σk=0N bkx(n − k)

Z ga o'tkazamiz (x(n − k) → z−kX): Y(z)[1 + Σakz−k] = X(z)·Σbkz−k, demak

H(z) = (b0 + b1z−1 + … + bNz−N) / (1 + a1z−1 + … + aMz−M) = HN(z)·HR(z)

HN — surat (norekursiv qism), HR = 1/maxraj (rekursiv qism).

Muhim yorliq: ayirmali tenglama koeffitsiyentlari ↔ H(z) koeffitsiyentlari. Tenglamada y(n − k) chap tomonda bo'lsa, maxrajda +ak; o'ng tomonda bo'lsa, ishorasi teskari. Masalan, y(n) = 0,5y(n − 1) + x(n) → H = 1/(1 − 0,5z−1).

Sof rekursiv tizim (ma'ruza): chiqish faqat joriy kirish va qayta aloqaga bog'liq: y(n) = x(n) − Σaky(n − k).

5. Blok sxemalar

Ayirmali tenglama uch xil elementdan tuzilgan sxema bilan ifodalanadi (ma'ruza): kechiktirish z−1 (bir namuna xotira), kuchaytirgich (koeffitsiyentga ko'paytirish) va qo'shuvchi. To'g'ridan-to'g'ri shakl: avval HN (chapda, kirishning kechikkan nusxalari bk bilan), keyin HR (o'ngda, chiqishning kechikkan nusxalari −ak bilan qaytariladi).

6. Ma'ruza misoli (= Exercises 3, 6-masala)

H(z) = (1 − z−1)/(1 + ¾z−1), |z| > ¾. Kirish x(n) = (⅓)ⁿu(n) + u(−n − 1). (a) h(n), (b) y(n), (c) turg'unmi?

(a) Ayirmali tenglama: (1 + ¾z−1)Y = (1 − z−1)X → y(n) = x(n) − x(n − 1) − ¾y(n − 1) — kauzal. H(z) = 1/(1 + ¾z−1) − z−1/(1 + ¾z−1) → h(n) = (−¾)ⁿu(n) − (−¾)n−1u(n − 1).

(b) Kirish Z si: (⅓)ⁿu(n) ↔ 1/(1 − ⅓z−1), |z| > ⅓; u(−n − 1) ↔ −1/(1 − z−1), |z| < 1 (28-dars jadvali). X(z) = 1/(1 − ⅓z−1) − 1/(1 − z−1) = −⅔z−1 / [(1 − ⅓z−1)(1 − z−1)], ⅓ < |z| < 1.

Y = X·H = −⅔z−1(1 − z−1) / [(1 − ⅓z−1)(1 − z−1)(1 + ¾z−1)] = −⅔z−1 / [(1 − ⅓z−1)(1 + ¾z−1)]. z = 1 dagi qutb qisqardi! U kirishning antikauzal qismidan edi — endi ROC |z| > ¾ (kesishma ¾ < |z| < 1 dan kengroq), y(n) — kauzal.

Qoldiqlar: R1 = −⅔z−1/(1 + ¾z−1)|z=⅓ = −2/(1 + 9/4) = −8/13; R2 = −⅔z−1/(1 − ⅓z−1)|z=−¾ = (8/9)/(13/9) = 8/13.

y(n) = −(8/13)(⅓)ⁿu(n) + (8/13)(−¾)ⁿu(n)

Tekshiruv: y(0) = 0 = lim Y(z) ✓ (surat z−1 bilan boshlanadi).

(c) ROC |z| > ¾ birlik aylanani o'z ichiga oladi → turg'un (32-dars).

7. Yechilgan misollar (Exercises 3)

2-masala: FIR filtr y[n] = x[n] − x[n − 4]

(1) Chastota javobining moduli va fazasi; (2) kirish x[n] = cos(πn/2) + cos(πn/4) da chiqish; (3) natijani (1) bilan tushuntiring.

(1) DTFT: Y = X − Xe−j4ω → H(ejω) = 1 − e−j4ω = 1 − cos 4ω + j·sin 4ω.

|H|² = (1 − cos 4ω)² + sin² 4ω = 2 − 2cos 4ω = 4sin² 2ω → |H| = 2|sin 2ω|.

Faza: arg H = arctg[sin 4ω/(1 − cos 4ω)]. Qulayroq ko'rinish: 1 − e−j4ω = e−j2ω(ej2ω − e−j2ω) = 2j·sin 2ω·e−j2ω → sin 2ω > 0 da φ = π/2 − 2ω (chiziqli faza).

(2) To'g'ridan: y = cos(πn/2) + cos(πn/4) − cos(π(n − 4)/2) − cos(π(n − 4)/4) = cos(πn/2) + cos(πn/4) − cos(πn/2 − 2π) − cos(πn/4 − π) = cos(πn/2) + cos(πn/4) − cos(πn/2) + cos(πn/4) = 2cos(πn/4).

(3) ω = π/2: |H| = 2|sin π| = 0 — bu chastota butunlay o'chirildi. ω = π/4: |H| = 2|sin(π/2)| = 2, φ = π/2 − π/2 = 0 — amplituda ikki baravar, faza o'zgarmadi. Ya'ni y = 0·cos(πn/2) + 2cos(πn/4) ✓.

3-masala (a, b): y[n] − ¼y[n − 1] = x[n] + x[n − 1] − 2x[n − 2]

Z: Y(1 − ¼z−1) = X(1 + z−1 − 2z−2) → H(z) = (1 + z−1 − 2z−2)/(1 − ¼z−1) = (z² + z − 2)/(z² − ¼z) (z² ga ko'paytirdik).

Nollar: z² + z − 2 = 0 → z = ½(−1 ± √9) → z = 1, z = −2. Qutblar: z(z − ¼) = 0 → z = 0, z = ¼.

Kauzal (chiqish faqat joriy/o'tgan qiymatlarga bog'liq) → ROC |z| > ¼. Tenglama rekursiv (a1 = −¼ ≠ 0), qutb z = ¼ ≠ 0 → IIR. ((c) — minimal faza — 32-darsda.)

Qo'shimcha: FIR va IIR ni solishtirish

FIR — 3 nuqtali o'rtacha: y(n) = ⅓[x(n) + x(n − 1) + x(n − 2)]. h = {⅓, ⅓, ⅓}, H(z) = ⅓(1 + z−1 + z−2). H(ejω) = ⅓e−jω(ejω + 1 + e−jω) = ⅓e−jω(1 + 2cos ω) → |H| = |1 + 2cos ω|/3: ω = 0 da 1, ω = 2π/3 da 0 — past chastotali filtr.

IIR — birinchi tartibli: y(n) = 0,5y(n − 1) + x(n). H(z) = 1/(1 − 0,5z−1), h(n) = (0,5)ⁿu(n) — cheksiz. |H(ejω)|² = 1/|1 − 0,5e−jω|² = 1/[(1 − 0,5cos ω)² + (0,5sin ω)²] = 1/(1,25 − cos ω): ω = 0 da |H| = 2, ω = π da |H| = 2/3 — ham past chastotali.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (35-ma'ruza):

  1. h(n) = L[δ(n)] (nol holat). Chiziqlilik + statsionarlik → y(n) = Σx(i)h(n − i) = x * h. Har qanday LTI — o'ram (norekursiv ko'rinish).
  2. Kauzal ⇔ h(n) = 0, n < 0; y(n) = Σi≥0h(i)x(n − i).
  3. Chastota javobi: H(ejω) = Σh(i)e−jωi = DTFT[h]; Y(ejω) = H·X.
  4. ejω0n → H(ejω0)ejω0n (xos funksiya). Haqiqiy h: cos(ω0n + θ) → |H(ejω0)|cos(ω0n + θ + φH(ω0)).
  5. Y(z) = X(z)H(z); ROC — kesishma (qisqarish bo'lsa kengroq).
  6. Raqamli filtr: H(z) = Σbkz−k / (1 + Σakz−k) = HN·HR.
  7. FIR: faqat b, h = {b0, …, bN}, H — z−1 ko'phadi, norekursiv. IIR: qayta aloqa (ak ≠ 0), h cheksiz, rekursiv.
  8. Blok sxema: z−1 (kechiktirish), kuchaytirgich, qo'shuvchi; avval HN, keyin HR.
  9. Ma'ruza: rect3 * aⁿu(n) → (1 − an+1)/(1 − a) (n ≤ 2), an−2(1 − a³)/(1 − a) (n ≥ 2). (1 − z−1)/(1 + ¾z−1) misoli → y = (8/13)[(−¾)ⁿ − (⅓)ⁿ]u(n).
  10. Mashg'ulot: x[n] − x[n−4] → |H| = 2|sin 2ω|; cos(πn/2) o'chadi, cos(πn/4) ikki baravar.
