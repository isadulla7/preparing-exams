24. DTFT va uning xossalari

O'qish vaqti: 50 daqiqa. Manba: 28-ma'ruza ("Discrete-Time Fourier Transform (DTFT)"). Kerakli bilim: Furye almashtirishi (8–10-darslar), diskretlash (19-dars), deltalar qatori (16-dars), diskret signallar (21–22-darslar).

Bu B mavzu. Imtihonda: "{1, 0, 3, −2} ning DTFT si?", "aⁿu(n) ning DTFT si?", "DTFT davri nechaga teng?", "DTFT mavjudlik sharti?", "x(n − N) / x(−n) / ej2πf0nx(n) ning DTFT si?", "Haqiqiy juft signal DTFT si qanday?". 31-darsdagi chastota javobi H(ejω) — aynan impuls javobining DTFT si.
Bu darsda nimani bilib olasiz: DTFT qayerdan keladi (diskretlangan analog signaldan); ta'rif, raqamli chastota f va ω; davriylik; teskari DTFT va uning isboti; mavjudlik sharti; 6 ta xossa isbotlari bilan; haqiqiy signal simmetriyalari; ma'ruzadagi 3 misol va qo'shimcha misollar.

1. DTFT qayerdan keladi?

Analog signal x(t) ni fc = 1/Tc chastota bilan diskretlaymiz (19-dars, 16-dars):

xc(t) = x(t)·Σk δ(t − kTc) = Σk x(kTc)·δ(t − kTc)

Uning Furye almashtirishini ikki yo'l bilan hisoblash mumkin:

1) Ko'paytma → o'ram (16-dars): Xc(f) = X(f) * (1/Tc)Σδ(f − k/Tc) = (1/Tc)Σk X(f − k/Tc) — fc davr bilan takrorlangan spektr.

2) Har bir deltani alohida almashtiramiz: F{δ(t − kTc)} = e−j2πkTcf, shuning uchun Xc(f) = Σk x(kTc)·e−j2πkTcf.

Ikkinchi ifodada faqat namunalar x(kTc) qatnashadi. Lekin hamma diskret signal ham analog signaldan olinmagan (masalan, kunlik narxlar ro'yxati) — u holda Tc ning amaliy ma'nosi yo'q. Shuning uchun Tc = 1 deb olamiz.

2. Ta'rif

X(ej2πf) = Σk=−∞+∞ x(k)·e−j2πfk   (DTFT)

Bu yerda x(k) — istalgan diskret ketma-ketlik, f — raqamli (normallangan) chastota, birligi "tsikl / namuna". Ko'pincha raqamli burchak chastota ω = 2πf ishlatiladi:

X(ejω) = Σk x(k)·e−jωk

Analogiya: DTFT — signalni turli "aylanish tezligi"dagi strelkalar ej2πfk bilan solishtirish (skalyar ko'paytma). Har bir f uchun javob — signal shu tezlikdagi aylanishga qanchalik o'xshashi.

Muhim kuzatishlar:
  1. Signal diskret bo'lsa ham, DTFT uzluksiz o'zgaruvchi f ning funksiyasi.
  2. DTFT f bo'yicha davri 1 (ω bo'yicha davri 2π) bo'lgan funksiya.
  3. Analog signal bilan bog'liqlik: raqamli chastota f = (fizik chastota)/fc. f = ½ — Nyquist chastotasi fc/2. Shuning uchun faqat −½ < f ≤ ½ (yoki −π < ω ≤ π) oraliq ko'rib chiqiladi.

Davriylik isboti: i — butun son. X(ej2π(f + i)) = Σx(k)e−j2πfk·e−j2πik. ik butun bo'lgani uchun e−j2πik = 1 → = X(ej2πf) ✓.

Sabab: n butun bo'lganda ej2π(f+1)n = ej2πfn — f va f + 1 chastotali diskret sinusoidalar bir xil (21-dars, diskret sinus davriyligi). Shuning uchun "f ning nomi bu" deyish ma'nosiz — DTFT ham buni "eslaydi".

Z bilan bog'liqlik (28-dars): X(ejω) = X(z)|z=ejω — Z-almashtirish birlik aylanada (ROC birlik aylanani o'z ichiga olsa).

3. Teskari DTFT

X(ejω) davriy funksiya, Σx(k)e−jωk esa — uning Furye qatori (7-dars)! Koeffitsiyentlar x(k) — X ning eksponentalar bazisiga proyeksiyasi:

x(k) = (1/2π)∫−π+π X(ejω)·ejωk dω   =   ∫−½+½ X(ej2πf)·ej2πfk df   (IDTFT)

Ya'ni bitta davr (−π, π] bo'yicha skalyar ko'paytma, davr uzunligi 2π ga bo'lingan. (ω = 2πf almashtirish bilan ikkinchi ko'rinish.)

Isbot: X ni ta'rifdan qo'yamiz, yig'indi va integralni almashtiramiz:

∫−½½ Σnx(n)e−j2πfnej2πfkdf = Σnx(n)∫−½½e−j2πf(n−k)df

Integral: [e−j2πf(n−k)/(−j2π(n − k))]−½½ = (ejπ(n−k) − e−jπ(n−k))/(j2π(n − k)) = sin(π(n − k))/(π(n − k)) = sinc(n − k).

Butun sonlarda sinc(m) = 1 (m = 0), 0 (m ≠ 0) — ya'ni δ(n − k). Demak Σx(n)sinc(n − k) = x(k) ✓.

4. Mavjudlik sharti

Σk=−∞+∞ |x(k)| < ∞   (modul bo'yicha yig'iladi)   ⇒   |X(ejω)| < ∞ ∀ω

Isbot: |X(ejω)| = |Σx(k)e−jωk| ≤ Σ|x(k)|·|e−jωk| = Σ|x(k)| < ∞ (|e−jωk| = 1).

Shart yetarli, lekin zarur emas. Modul bo'yicha yig'iladigan ketma-ketlik energiyasi ham chekli: E = Σ|x|² ≤ (Σ|x|)² < ∞. Teskarisi to'g'ri emas: x(n) = (1/n)u(n − 1) uchun Σ|x| = 1 + ½ + ⅓ + … = ∞, lekin E = Σ1/n² = π²/6 < ∞.

Taqqoslang: 32-darsdagi BIBO sharti Σ|h(n)| < ∞ — xuddi shu shart. Turg'un tizimning chastota javobi doim mavjud.

5. Ma'ruza misollari

1-misol: x(n) = aⁿu(n), |a| < 1

Mavjudlik: Σ|a|k = 1/(1 − |a|) < ∞ ✓ (geometrik qator: Σk≥0 rk = 1/(1 − r), |r| < 1).

X(ejω) = Σk=0∞ aᵏe−jωk = Σ(ae−jω)ᵏ = 1/(1 − ae−jω)

(|ae−jω| = |a| < 1, shuning uchun qator yaqinlashadi.)

2-misol: x(n) = {1, 0, 3, −2} (n = 0, 1, 2, 3)

Deltalar bilan: x(n) = δ(n) + 3δ(n − 2) − 2δ(n − 3). Ta'rifga qo'yamiz — har bir δ(n − m) faqat k = m da "ishlaydi":

X(ej2πf) = 1 + 3e−j4πf − 2e−j6πf

Tekshiruv: X(ej0) = 1 + 3 − 2 = 2 = Σx(n) ✓ (f = 0 da DTFT = namunalar yig'indisi). f = ½: 1 + 3e−j2π − 2e−j3π = 1 + 3 + 2 = 6 = Σ(−1)ⁿx(n) ✓.

3-misol: x(n) = (⅓)ⁿu(n)

1-misoldan a = ⅓: X(ejω) = 1/(1 − ⅓e−jω).

Modul: |1 − ⅓e−jω|² = (1 − ⅓cos ω)² + (⅓sin ω)² = 10/9 − ⅔cos ω → |X| = 1/√(10/9 − ⅔cos ω): ω = 0 da 3/2, ω = π da 3/4.

Faza: φ(ω) = −arctg[⅓sin ω/(1 − ⅓cos ω)].

x(n) haqiqiy → modul juft, faza toq (6-bo'lim).

Teskari aylantirish: z(n) = x(−n): Σx(−k)e−j2πfk, i = −k: Σx(i)e+j2πfi = X(e−j2πf).

Kechikish: Σx(k − N)e−j2πfk, n = k − N: Σx(n)e−j2πf(n + N) = e−j2πfNX(ej2πf). Modul o'zgarmaydi, fazaga −2πfN qo'shiladi.

Modulyatsiya: Σej2πf0kx(k)e−j2πfk = Σx(k)e−j2π(f − f0)k = X(ej2π(f − f0)) — spektr f0 ga suriladi.

Hosila: dX/df = Σx(k)(−j2πk)e−j2πfk = −j2π·DTFT[n·x(n)] → DTFT[n·x(n)] = (j/2π)dX/df.

O'ram: ΣΣx(k)y(n − k)e−j2πfn; i = n − k: Σx(k)e−j2πfk·Σy(i)e−j2πfi = X·Y. (31-darsdagi Y = H·X aynan shu.)

Ko'paytma: x(k) ni IDTFT bilan yozamiz, yig'indi va integralni almashtiramiz: ∫X(ej2πη)[Σy(k)e−j2π(f−η)k]dη = ∫−½½X(ej2πη)Y(ej2π(f−η))dη. Integral faqat bitta davr bo'yicha — davriy (aylanma) o'ram.

Xossalardan foydalanish misollari

a) x(n) = aⁿu(n − 2) = a²·an−2u(n − 2): kechikish N = 2 → X = a²e−j2ω/(1 − ae−jω).

b) x(n) = n·aⁿu(n): hosila xossasi (ω bo'yicha yozsak DTFT[n·x] = j·dX/dω): d/dω[1/(1 − ae−jω)] = −jae−jω/(1 − ae−jω)² → X = ae−jω/(1 − ae−jω)² (29-darsdagi Z juftligi bilan mos).

c) x(n) = cos(ω0n)·aⁿu(n) = ½(ejω0n + e−jω0n)aⁿu(n): modulyatsiya → X = ½[1/(1 − ae−j(ω−ω0)) + 1/(1 − ae−j(ω+ω0))].

d) To'rtburchak ketma-ketlik x(n) = u(n) − u(n − N) (N ta 1): geometrik yig'indi Σk=0N−1e−jωk = (1 − e−jωN)/(1 − e−jω) = e−jω(N−1)/2·sin(ωN/2)/sin(ω/2) — "diskret sinc" (Dirixle yadrosi). ω = 0 da N, birinchi nol ω = 2π/N da. N = 3 da |X| = |1 + 2cos ω| (31-darsdagi o'rtacha filtr).

7. Haqiqiy signal simmetriyalari

X(ej2πf) = XR + jXI (haqiqiy va mavhum qism). x(n) haqiqiy bo'lsa:

x(n) haqiqiyDTFT
Ermit simmetriyasiX(ej2πf) = X*(e−j2πf)
Modul|X(ej2πf)| = |X(e−j2πf)| — juft
Fazaφ(X(ej2πf)) = −φ(X(e−j2πf)) — toq
x(n) juftX = XR — haqiqiy (va juft)
x(n) toqX = jXI — sof mavhum (va toq)

Davriylik tufayli f = 0 ga nisbatan simmetrik funksiya f = ½ ga nisbatan ham simmetrik (umuman f = k/2). Shuning uchun haqiqiy signal uchun 0 ≤ f ≤ ½ oraliqni chizish yetarli.

Juft misol: x = {1, 2, 1} (markaz n = 0): X = ej2πf + 2 + e−j2πf = 2 + 2cos(2πf) — haqiqiy, juft ✓.

Toq misol: x = δ(n + 1) − δ(n − 1): X = ej2πf − e−j2πf = 2j·sin(2πf) — sof mavhum, toq ✓.

Oddiy juftliklar: δ(n) ↔ 1; δ(n − N) ↔ e−j2πfN; 1 (barcha n) ↔ Σδ(f − i) (har butun f da delta — davriy!); ej2πf0n ↔ Σδ(f − f0 − i).

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (28-ma'ruza):

  1. Diskretlangan analog: Xc(f) = (1/Tc)ΣX(f − k/Tc) = Σx(kTc)e−j2πkTcf; Tc = 1 → DTFT.
  2. X(ej2πf) = Σx(k)e−j2πfk, ω = 2πf; f uzluksiz, davri 1 (ω da 2π); f = ½ ↔ fc/2.
  3. IDTFT: x(k) = ∫−½½X(ej2πf)ej2πfkdf = (1/2π)∫−ππX(ejω)ejωkdω (isbot: ∫ = sinc(n − k)).
  4. Mavjudlik: Σ|x(k)| < ∞ (yetarli, zarur emas) ⇒ chekli energiya (teskarisi emas).
  5. aⁿu(n) ↔ 1/(1 − ae−jω), |a| < 1; {1, 0, 3, −2} ↔ 1 + 3e−j4πf − 2e−j6πf; X(ej0) = Σx(n).
  6. Xossalar: x(−n) ↔ X(e−j2πf); x(n − N) ↔ Xe−j2πfN; ej2πf0nx ↔ X(ej2π(f−f0)); nx(n) ↔ (j/2π)dX/df; x * y ↔ XY; xy ↔ davriy o'ram.
  7. Haqiqiy x: X(ej2πf) = X*(e−j2πf), |X| juft, faza toq; juft x → X haqiqiy; toq x → X sof mavhum; f = ½ ga nisbatan ham simmetrik.
  8. N ta 1: e−jω(N−1)/2sin(ωN/2)/sin(ω/2).
  9. DTFT = Z birlik aylanada; turg'un tizim (Σ|h| < ∞) chastota javobi doim mavjud.
