5. Signallar vektor sifatida

O'qish vaqti: 45 daqiqa. Manba: 03-ma'ruza ("Vectorial representation of signals"), 1-qism. Kerakli bilim: energiya (4-dars), kompleks son va qo'shmasi (3-dars), maktab geometriyasidagi vektorlar.

Bu C mavzu, lekin juda "toza" test savollari chiqadi: "ikki signal ortogonal qachon?", "signal normasi kvadrati = ?", "Evklid masofasining kvadrati nimaning energiyasi?", "Shvars tengsizligida tenglik qachon?", "skalyar ko'paytma ta'rifi?". Ular Furye qatori (7-dars) va ortonormal bazis (6-dars) uchun asos.
Bu darsda nimani bilib olasiz: nega signallarni vektor deb qarash foydali; masofa, metrika, vektor fazo, chiziqli bog'liqlik, bazis; skalyar ko'paytma, norma, energiya; ortogonallik va "burchak"; Shvars tengsizligi; ma'ruzadagi ortogonallik misoli; vektor ↔ signal jadvali.

1. Nega signallarni vektor deb qaraymiz?

Signalni "vaqt funksiyasi" deb ta'riflash ba'zi muhandislik masalalarida yetarli emas: real fizik signal (masalan, ovoz yozuvi) ma'lum matematik funksiyalarning (eksponenta, logarifm, sinusoida…) birortasiga ham o'xshamaydi. Shuning uchun istalgan signalni samarali tasvirlaydigan vosita kerak.

Yechim (ma'ruza): signallarni vektor deb qarash mumkin — ular oddiy "elementar" signallar to'plamidan yig'iladi. O'xshatish: tekislikdagi istalgan nuqtaga "3 qadam sharqqa, 2 qadam shimolga" deb borish mumkin — ikki yo'nalish (bazis) va ikki son (koeffitsientlar) yetarli. Signal ham "shuncha bu elementar signal + shuncha u elementar signal" ko'rinishida yoziladi.

2. Eslatma: tekislikdagi vektorlar

x = (x1, x2) — ikki son, tekislikdagi strelka. Amallar:

  • Yig'indi: (x1 + y1, x2 + y2) — parallelogramm qoidasi. Songa ko'paytma: αx = (αx1, αx2) — strelka cho'ziladi/qisqaradi (α < 0 da teskari tomonga).
  • Uzunlik (norma): ‖x‖ = √(x1² + x2²) (Pifagor).
  • Skalyar ko'paytma: ⟨x, y⟩ = x1y1 + x2y2 = ‖x‖·‖y‖·cos θ (θ — orasidagi burchak).
  • Perpendikulyar (θ = 90°) ⇔ ⟨x, y⟩ = 0.

Son misol: x = (3, 4), y = (4, −3). ‖x‖ = √(9 + 16) = 5, ‖y‖ = 5. ⟨x, y⟩ = 12 − 12 = 0 → perpendikulyar. Masofa ‖x − y‖ = ‖(−1, 7)‖ = √50 ≈ 7,07.

3. Ikki signal orasidagi masofa

Vektorlar kabi, ikki signal qanchalik "uzoq" (farqli) ekanini o'lchamoqchimiz. Bir nechta ta'rif mumkin (ma'ruza):

d(x, y) = ∫−∞+∞ |x(t) − y(t)| dt    yoki    d(x, y) = √(∫−∞+∞ |x(t) − y(t)|² dt)

Kursda ikkinchisi — Evklid masofasi ishlatiladi. U vektorlardagi d(x, y) = ‖x − y‖ = √((x1 − y1)² + … + (xn − yn)²) ning signal varianti: yig'indi → integral.

Muhim: Evklid masofasining kvadrati d²(x, y) = ∫|x(t) − y(t)|²dt — bu farq signalining energiyasi. Masofa ikki signalni solishtirish, ular qanchalik o'xshashligini o'lchash uchun kerak: nutqni tanish (ovozni namuna bilan solishtirish), shovqinli kanal orqali uzatish (qabul qilingan signal qaysi yuborilgan signalga eng yaqin?), ma'lumotlarni qayta ishlash.

Misol: x(t) = 1, y(t) = t, ikkalasi [0, 1] da (tashqarida 0). d² = ∫01(1 − t)²dt = [−(1 − t)³/3]01 = 1/3, d = 1/√3 ≈ 0,577.

4. Chiziqli algebradan eslatmalar

4.1. Metrik fazo

Metrika — to'plamning ikki elementiga son (masofa) mos qo'yuvchi funksiya, quyidagi xossalar bilan:

  1. d(x, y) ≥ 0 — manfiy emas;
  2. d(x, y) = d(y, x) — simmetrik;
  3. d(x, y) = 0 ⇔ x = y;
  4. d(x, z) ≤ d(x, y) + d(y, z) — uchburchak tengsizligi (to'g'ri yo'l eng qisqa).

Evklid masofasi — mumkin bo'lgan metrikalardan biri.

4.2. Vektor fazo

Vektor fazo — elementlari (vektorlar) uchun ikki amal aniqlangan to'plam: vektorlar yig'indisi va songa ko'paytma, quyidagi xossalar bilan:

Yig'indi xossalariKo'paytma xossalari
x + y = y + xαx — shu fazoning vektori
x + (y + z) = (x + y) + z1·x = x, 0·x = 0
x + 0 = xα(βx) = (αβ)x
har bir x uchun −x bor: x + (−x) = 0α(x + y) = αx + αy; (α + β)x = αx + βx

Vektorlar — n ta haqiqiy sonning tartiblangan to'plami x = (x1, …, xn); yig'indi va ko'paytma koordinatalar bo'yicha bajariladi.

4.3. Chiziqli kombinatsiya, bog'liqlik, bazis

  • Chiziqli kombinatsiya: x = α1w1 + α2w2 + … + αnwn.
  • Chiziqli bog'liq: vektorlardan biri qolganlarining chiziqli kombinatsiyasi sifatida yozilsa: wk = Σi≠kαiwi.
  • Chiziqli erkli (bog'liqmas): Σαixi = 0 faqat barcha αi = 0 bo'lganda.
  • Bazis: fazoning barcha elementlarini chiziqli kombinatsiya orqali hosil qilish uchun yetarli bo'lgan minimal {wi} to'plam: x = Σαiwi.
  • Bazis yagona emas (bitta fazo uchun ko'p bazis bor), lekin undagi elementlar soni n yagona — u fazoning o'lchami (dimensionality).

Ma'ruzadagi 2D misol (FIG1): z va y chiziqli erkli → (z, y) — ℝ² uchun bazis; t = z + y. x = αy — x va y chiziqli bog'liq (bir chiziqda). z va p — ortogonal, skalyar ko'paytmasi nol.

5. Skalyar ko'paytma, norma, energiya

⟨x, y⟩ = Σi=1n xi·yi*    (n o'lchamli Evklid fazosi — asosiy ta'rif)

Ikki vektorga kompleks son mos qo'yadi. Xossalari: ⟨x, y⟩ = ⟨y, x⟩*;   ⟨x + z, y⟩ = ⟨x, y⟩ + ⟨z, y⟩;   ⟨αx, y⟩ = α⟨x, y⟩. Ikki vektor ortogonal, agar ⟨x, y⟩ = 0.

Norma ‖x‖ — har bir vektorga haqiqiy son mos qo'yadi, xossalari: (1) ‖x‖ ≥ 0; (2) ‖x‖ = 0 ⇔ x = 0; (3) ‖x + y‖ ≤ ‖x‖ + ‖y‖; (4) ‖αx‖ = |α|·‖x‖. Skalyar ko'paytmadan:

‖x‖² = ⟨x, x⟩ = Σ|xi|²,    d(x, y) = ‖x − y‖,    E(x) = ‖x‖²

Vektor energiyasi — normasining kvadrati. (Kompleks holda |xi|² = xixi*.)

Shvars tengsizligi

|⟨x, y⟩|² ≤ ‖x‖²·‖y‖²    (skalyar ko'paytma modulining kvadrati ≤ energiyalar ko'paytmasi)

Tenglik faqat vektorlar (signallar) proporsional bo'lganda: x = αy. Geometrik ma'nosi: |cos θ| ≤ 1.

Tekshiruv: x = (1, 2), y = (3, 1): ⟨x, y⟩ = 5, |⟨x, y⟩|² = 25 ≤ ‖x‖²‖y‖² = 5·10 = 50 ✓. y = (2, 4) = 2x bo'lsa: ⟨x, y⟩ = 10, 100 = 5·20 ✓ — tenglik.

6. Endi signallar: xuddi shu tushunchalar

Uzluksiz signallar ham odatiy yig'indi va songa ko'paytma bilan vektor fazo hosil qiladi: x + y ≡ x(t) + y(t), αx ≡ αx(t). Muhim (ma'ruza): Evklid fazosidagi vektorlar uchun barcha tushunchalar signallarga ham qo'llanadi — yig'indi Σi o'rniga integral ∫dt.

⟨x(t), y(t)⟩ ≜ ∫−∞+∞ x(t)·y*(t) dt
‖x(t)‖ = √(∫−∞+∞|x(t)|²dt) = √⟨x(t), x(t)⟩,    Ex = ‖x(t)‖²

Signal energiyasi (4-dars) — uning normasining kvadrati!

Ortogonallik va "burchak"

Vektorlardagi cos θ = ⟨x, y⟩/(‖x‖‖y‖) formulasi signallar orasidagi "burchak"ni ham aniqlaydi. Ikki signal ortogonal, agar:

⟨x, y⟩ = ∫−∞+∞ x(t)·y*(t) dt = 0

Ya'ni ko'paytma x(t)y*(t) ning musbat va manfiy yuzalari bir-birini to'liq yo'qotadi.

7. Ma'ruza misoli: ortogonallikni tekshirish

a(t) = 1, t ∈ [0, TS] (tashqarida 0);   b(t) = (2/TS)(t − TS/2), t ∈ [0, TS] (−1 dan +1 gacha chiziqli o'suvchi; tashqarida 0).

⟨a, b⟩ = ∫0TS 1·(2/TS)(t − TS/2)dt = (2/TS)[t²/2 − TSt/2]0TS = (2/TS)(TS²/2 − TS²/2) = 0

→ a va b ortogonal. Grafik ma'nosi: b(t) TS/2 atrofida toq simmetrik — chap yarmidagi manfiy yuza o'ng yarmidagi musbat yuzaga teng.

Qo'shimcha: energiyalar Ea = TS; Eb = (4/TS²)∫0TS(t − TS/2)²dt = (4/TS²)·(TS³/12) = TS/3. Ortogonal bo'lgani uchun Pifagor: ‖a + b‖² = Ea + Eb = 4TS/3.

Yana bir misol — burchak: x(t) = 1, y(t) = t, [0, 1] da. ⟨x, y⟩ = ∫01t dt = ½; Ex = 1, Ey = ∫t²dt = 1/3. Shvars: (½)² = ¼ ≤ 1·(1/3) ✓. cos θ = (½)/√(1/3) = √3/2 → θ = 30°. Tekshiruv: d² = Ex + Ey − 2⟨x, y⟩ = 1 + 1/3 − 1 = 1/3 ✓ (3-bo'lim).

Sinus va kosinus bitta davrda ortogonal: ∫0Tsin(2πt/T)cos(2πt/T)dt = ½∫0Tsin(4πt/T)dt = 0 — Furye qatorining (7-dars) asosi.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (03-ma'ruza, 1-qism):

  1. Signallar vektor kabi: elementar signallardan yig'iladi; odatiy yig'indi va songa ko'paytma bilan vektor fazo.
  2. Evklid masofasi: d(x, y) = √∫|x(t) − y(t)|²dt; d² — farq signali energiyasi.
  3. Metrika: d ≥ 0; simmetrik; d = 0 ⇔ x = y; uchburchak tengsizligi.
  4. Chiziqli erkli: Σαixi = 0 ⇒ barcha αi = 0. Bazis — minimal hosil qiluvchi to'plam; yagona emas, o'lchami yagona.
  5. Skalyar ko'paytma: vektor Σxiyi*, signal ∫x(t)y*(t)dt; ⟨x, y⟩ = ⟨y, x⟩*, chiziqli.
  6. Norma: ‖x‖ ≥ 0, ‖x‖ = 0 ⇔ x = 0, ‖x + y‖ ≤ ‖x‖ + ‖y‖, ‖αx‖ = |α|‖x‖; ‖x‖² = ⟨x, x⟩.
  7. E = ‖x‖²; d(x, y) = ‖x − y‖.
  8. Ortogonal: ⟨x, y⟩ = 0; "burchak": cos θ = ⟨x, y⟩/(‖x‖‖y‖).
  9. Shvars: |⟨x, y⟩|² ≤ ‖x‖²‖y‖², tenglik ⇔ x = αy.
  10. Ma'ruza misoli: 1 va (2/TS)(t − TS/2) [0, TS] da — ortogonal.
