16. Davriy signallar spektri va delta qatori

O'qish vaqti: 50 daqiqa. Manba: 12-ma'ruza ("Periodic signals") va 13-ma'ruza ("Periodic Signals — Train of Deltas and Examples"). Kerakli bilim: Furye qatori μn (7-dars), Furye almashtirishi va δ(t) (8-dars), o'ram ↔ ko'paytma (10-dars).

Bu B mavzu. Bu dars 19-darsdagi diskretlash teoremasining "poydevori". Imtihonda: "Davriy signal spektri qanday ko'rinadi?", "Σδ(t − nT) ning Furye almashtirishi?", "Chiziqlar orasidagi masofa?", "x(t)·cT(t) va x(t) * cT(t) spektri?".
Bu darsda nimani bilib olasiz: davriy va siklik signal; davriy signalning Furye almashtirishi — "chiziqli spektr" (ikki formula); to'rtburchak impulslar ketma-ketligi; deltalar qatori cT(t) va uning spektri; deltalar qatori bilan ko'paytma (diskretlash) va o'ram (davriylashtirish); davriy signalni turlicha tasvirlash; ma'ruzadagi ikki misol.

1. Davriy va siklik signallar

Davriy signal (davri T): x(t) = x(t + T) barcha t ∈ (−∞, +∞) uchun. Uni bitta davrdagi bo'lagi xT(t) ni (kesilgan signal, [−T/2, T/2] yoki [0, T] da x ga teng, tashqarida 0) cheksiz takrorlab hosil qilish mumkin:

x(t) = Σn=−∞+∞ xT(t − nT)

Hayotiy misol: devor soatining mayatnigi, yurak urishi (EKG), kompyuterdagi takt signali (clock) — hammasi deyarli davriy.

Siklik signal — chekli sondagi davrlar: xc(t) = Σn=n1n2 xT(t − nT). U davriy emas (xc(t) ≠ xc(t + T) chetlarida), u — "kesilgan davriy signal". Real hayotda hamma narsa siklik (yurak abadiy urmaydi), lekin davriy signal bilan hisoblash ancha oson — shuning uchun muhandislikda ular davriy deb olinadi.

2. Davriy signalning Furye almashtirishi

Muammo: davriy signal energiyasi cheksiz (4-dars) — oddiy ma'noda Furye integrali yaqinlashmaydi. Lekin δ funksiya yordamida almashtirish mavjud.

1-usul: Furye qatori orqali

7-darsdan: x(t) = Σn μnej2πnt/T,   μn = (1/T)∫−T/2T/2 xT(t)e−j2πnt/Tdt.

Furye almashtirishini olamiz (yig'indi va integralni almashtiramiz):

X(f) = Σn μn·∫ej2πnt/Te−j2πftdt = Σn μn·∫e−j2π(f − n/T)tdt

8-darsdagi asosiy juftlik: ∫e−j2πftdt = δ(f), demak ∫e−j2π(f − n/T)tdt = δ(f − n/T):

X(f) = Σn=−∞+∞ μn·δ(f − n/T)

2-usul: kesilgan signal spektri orqali

μn integrali — aslida xT ning Furye almashtirishi f = n/T nuqtada (xT davrdan tashqarida 0, chegaralarni ±∞ ga kengaytirish mumkin):

μn = (1/T)∫−∞+∞ xT(t)e−j2π(n/T)tdt = (1/T)·XT(n/T)

Shuning uchun:

X(f) = (1/T)·Σn=−∞+∞ XT(n/T)·δ(f − n/T)

Davriy signal spektri — "chiziqli" (striped, line spectrum): bir-biridan 1/T masofadagi deltalar (fn = n/T). Har bir deltaning og'irligi = kesilgan signal spektrining shu nuqtadagi qiymati XT(n/T), 1/T ga ko'paytirilgan. XT(f) — "o'rovchi" (qobiq): deltalarning uchlari shu egri chiziq ustida yotadi. (Umumiy holda koeffitsiyentlar kompleks.)

Analogiya: XT(f) — tog' tizmasi, davriy signal spektri esa shu tog' ustiga har 1/T metrda qoqilgan qoziqlar: faqat qoziqlar bor, orasi bo'sh. Davr T qancha katta bo'lsa, qoziqlar shuncha zich.

Ma'ruza misoli: to'rtburchak impulslar ketma-ketligi

Kesilgan signal: balandligi 1, kengligi τ < T bo'lgan impuls (markazi 0 da), davr T. Jadvaldan: XT(f) = sin(πfτ)/(πf) = τ·sinc(fτ) — nollari ±1/τ, ±2/τ, …

X(f) = (1/T)Σn τ·sinc(nτ/T)·δ(f − n/T) = (τ/T)·Σn sinc(nτ/T)·δ(f − n/T)

τ < T bo'lgani uchun 1/τ > 1/T: sinc ning birinchi noli birinchi chiziqdan uzoqroqda — asosiy "lob" ichida bir nechta chiziq bor.

Son bilan (τ = T/2, "meander"): og'irliklar ½·sinc(n/2): n = 0 → ½ (o'rtacha qiymat); n = ±1 → 1/π ≈ 0,318; n = ±2 → 0 (sinc noli); n = ±3 → −1/(3π) ≈ −0,106; n = ±5 → 1/(5π) ≈ 0,064. Juft garmonikalar yo'q!

3. Deltalar qatori cT(t)

Deltalar qatori (impulslar poyezdi, "diskretlovchi signal", sampler):

cT(t) = Σn=−∞+∞ δ(t − nT)

Bu signal diskretlash teoremasi va butun raqamli signallar nazariyasining asosi.

Bu davriy signal; kesilgan signali xT(t) = δ(t) → XT(f) = 1 (8-dars). 2-usul bo'yicha:

CT(f) = (1/T)·Σn=−∞+∞ δ(f − n/T)

Deltalar qatorining spektri — yana deltalar qatori: oralig'i 1/T, og'irligi 1/T.

1-usul bo'yicha: μn = 1/T, x(t) = Σ(1/T)ej2πnt/T. Bevosita ta'rifdan esa δ(t − nT) ↔ e−j2πfnT → muqobil ifoda: CT(f) = Σn e−j2πnfT. Ikkalasini tenglashtirib (Puasson formulasi):

Σn e−j2πnfT = (1/T)·Σn δ(f − n/T)

(Ma'ruza slaydida o'ng tomonda δ(t − n/T) deb yozilgan — bu xato, chap tomon f ning funksiyasi, demak δ(f − n/T).)

Vaqtda siyrak ⇔ chastotada zich. T katta (deltalar vaqtda uzoq-uzoq) → spektrdagi deltalar zich (1/T kichik) va past (og'irligi 1/T kichik). T kichik → aksincha.

4. Deltalar qatori bilan ko'paytma va o'ram

Ko'paytma → diskretlash

δ ning "elakdan o'tkazish" xossasi: x(t)δ(t − nT) = x(nT)δ(t − nT). Shuning uchun

y(t) = x(t)·cT(t) = Σn x(nT)·δ(t − nT)

— signalning bir xil oraliqdagi namunalari (cT "diskretlovchi" deyilishi shundan). Chastotada ko'paytma → o'ram (10-dars), deltaga o'ram → surish:

Y(f) = X(f) * (1/T)Σδ(f − n/T) = (1/T)·Σn X(f − n/T)

Spektr 1/T davr bilan davriy bo'lib qoldi — X(f) ning nusxalari har 1/T da. (19-darsdagi diskretlash teoremasi aynan shu formuladan chiqadi.)

O'ram → davriylashtirish

Deltaga o'ram — surish: x(t) * δ(t − nT) = x(t − nT). Shuning uchun

y(t) = x(t) * cT(t) = Σn x(t − nT)

— davri T bo'lgan davriy signal. Chastotada o'ram → ko'paytma:

Y(f) = X(f)·(1/T)Σδ(f − n/T) = (1/T)·Σn X(n/T)·δ(f − n/T)

— chiziqli spektr (2-bo'limdagi formula, endi istalgan x(t) uchun).

VaqtdaChastotada
cT(t) ga ko'paytirish → namunalar (diskret)(1/T)·Σ X(f − n/T) — davriy spektr
cT(t) bilan o'ram → davriy signal(1/T)·Σ X(n/T)δ(f − n/T) — diskret (chiziqli) spektr

Qoida: bir sohada diskret ⇔ ikkinchisida davriy.

5. Davriylashtirilgan signallar

Istalgan signal z(t) dan (u [0, T] ga sig'ishi shart emas, ustma-ust tushishi ham mumkin) davriy signal yasash mumkin:

x(t) = Σn=−∞+∞ z(t − nT) = z(t) * cT(t)

Isbot (davriyligi): x(t + T) = Σn z(t − (n − 1)T) = [m = n − 1] = Σm z(t − mT) = x(t).

Spektr (4-bo'limdagi o'ram): X(f) = (1/T)·Σn Z(n/T)·δ(f − n/T).

Tasvirlash yagona emas. Bitta davriy x(t) ni turli z(t) lar bilan yozish mumkin — faqat [0, T] da Σz(t − nT) = xT(t) bo'lsa bas. Spektr chastotalarda bu esa shunday ko'rinadi: Z(f) va XT(f) — turli funksiyalar, lekin f = n/T nuqtalarda bir xil qiymat oladi. Davriy signal spektri uchun faqat shu nuqtalar muhim.

Ma'ruza misoli 1: o'zgarmas signal x(t) = 1

1 = Σn ΠT(t − nT) (kengligi T bo'lgan to'rtburchaklar yonma-yon) = Σn ΛT(t − nT) (asosi 2T bo'lgan uchburchaklar, qo'shnilari ustma-ust tushib yig'indisi 1). ΠT — 8-darsdagi pT.

To'rtburchak bilan: F[ΠT] = T·sinc(fT) → f = n/T da T·sin(πn)/(πn): n = 0 da T, qolganlarida 0.

Uchburchak bilan: F[ΛT] = T·sinc²(fT) → f = n/T da T·sin²(πn)/(πn)²: yana n = 0 da T, qolganlari 0.

Ikkalasida ham: X(f) = (1/T)·T·δ(f) = δ(f) ✓ (8-darsdagi 1 ↔ δ(f) bilan mos). sinc va sinc² turli egri chiziqlar, lekin n/T nuqtalarda bir xil.

Ma'ruza misoli 2: davri 2T bo'lgan meander (to'rtburchak to'lqin)

x(t): (−T, 0) da +1, (0, T) da −1, davri 2T.

1-tasvir: x2T(t) = ΠT(t + T/2) − ΠT(t − T/2). Surish xossasi (9-dars): X2T(f) = T·sinc(fT)·(ejπfT − e−jπfT).

2-tasvir: z(t) = ΠT(t + T/2) − ΠT(t − 5T/2) (manfiy bo'lak bir davr o'ngga surilgan). Z(f) = T·sinc(fT)·(ejπfT − e−j5πfT). Bular turli funksiyalar.

f = n/2T nuqtalarda (davr 2T!): e−j5πn/2 = e−jπn/2·e−j2πn = e−jπn/2, shuning uchun

X2T(n/2T) = Z(n/2T) = T·sinc(n/2)·(ejπn/2 − e−jπn/2) = 2jT·sinc(n/2)·sin(πn/2)

(ejθ − e−jθ = 2j·sin θ. Ma'ruza slaydida "jT" — 2 ko'paytuvchi tushib qolgan. 17-slayddagi "ΠT/2" ham xato: rasmda kengligi T.)

Spektr: X(f) = (1/2T)Σ X2T(n/2T)δ(f − n/2T) = Σ j·sinc(n/2)·sin(πn/2)·δ(f − n/2T).

n juft (n = 0 ham): sin(πn/2) = 0 → chiziq yo'q (o'rtacha qiymat 0 — musbat va manfiy yarimlar teng). n toq: sinc(n/2) = sin(πn/2)/(πn/2), sin²(πn/2) = 1 →

X(f) = Σn toq (2j/(πn))·δ(f − n/2T)

Chiziqlar ±1/2T, ±3/2T, … da, og'irligi 1/n kabi kamayadi, sof mavhum (signal toq funksiya: x(−t) = −x(t) → spektr sof mavhum, 10-dars simmetriyalari).

6. Qo'shimcha misollar (imtihon uslubida)

a) cos(2πf0t), T = 1/f0: Eyler bo'yicha μ±1 = ½, qolganlari 0 → X(f) = ½δ(f − f0) + ½δ(f + f0) — ikkita chiziq (8-darsdagi bilan mos).

b) Σn δ(t − 2n) (T = 2 s): spektr (1/2)Σδ(f − n/2) — chiziqlar har 0,5 Hz da, og'irligi 0,5.

c) Σn p1(t − 4n) (kengligi 1, davri 4): XT = sinc(f), X(f) = ¼Σ sinc(n/4)δ(f − n/4). n = 4, 8, … chiziqlar yo'q (sinc nollari).

d) Davriy signal o'rtacha qiymati = n = 0 chiziq og'irligi μ0 = XT(0)/T = (bir davrdagi yuza)/T.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (12–13-ma'ruzalar):

  1. Davriy: x(t) = x(t + T) = ΣxT(t − nT). Siklik — chekli sondagi davrlar.
  2. X(f) = Σμnδ(f − n/T), chunki ∫e−j2π(f − n/T)tdt = δ(f − n/T).
  3. μn = (1/T)XT(n/T) → X(f) = (1/T)ΣXT(n/T)δ(f − n/T): chiziqli spektr, oraliq 1/T, o'rovchi XT(f).
  4. To'rtburchak (τ, T): X(f) = (τ/T)Σsinc(nτ/T)δ(f − n/T); τ = T/2 da juft garmonikalar yo'q.
  5. cT(t) = Σδ(t − nT) ↔ (1/T)Σδ(f − n/T) = Σe−j2πnfT. Vaqtda siyrak ⇔ chastotada zich.
  6. x·cT = Σx(nT)δ(t − nT) ↔ (1/T)ΣX(f − n/T) (diskretlash → davriy spektr).
  7. x * cT = Σx(t − nT) ↔ (1/T)ΣX(n/T)δ(f − n/T) (davriylashtirish → chiziqli spektr).
  8. Bir sohada diskret ⇔ ikkinchisida davriy.
  9. Davriy signalni turli z(t) bilan yozish mumkin; Z(n/T) = XT(n/T) — faqat shu nuqtalar muhim.
  10. Misollar: 1 = ΣΠT(t − nT) = ΣΛT(t − nT) ↔ δ(f); meander (davr 2T, ±1): X(f) = Σn toq(2j/πn)δ(f − n/2T).
