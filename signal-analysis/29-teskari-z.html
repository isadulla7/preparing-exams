29. Z xossalari va teskari Z-almashtirish

O'qish vaqti: 60 daqiqa. Manba: 33-ma'ruza ("Properties of the z-Transform. Inverse of the Z-Transform"), mashg'ulot: "Exercises 2 — Z-Transform" (3, 4, 5-masalalar) va qo'lyozma qo'shimcha misollar ("Additional Ex. with solutions").

Bu A mavzu. Imtihonda: "X(z) = … , ROC |z| > …; x(n) = ?" (oddiy kasrlarga ajratish), "x(n − 5) ning Z-almashtirishi?", "x(0) = ?" (boshlang'ich qiymat teoremasi), "kauzal va antikauzal ketma-ketliklarni toping". Bu darsdagi usul 30–32-darslarda tizimlar uchun ham ishlatiladi.
Bu darsda nimani bilib olasiz: Z-almashtirishning barcha xossalari (chiziqlilik, surish, teskari aylantirish, masshtab, n ga ko'paytirish, o'ram, modulyatsiya); boshlang'ich qiymat teoremasi; teskari Z-almashtirish: integral formula, bevosita usul, oddiy kasrlarga ajratish (qoldiqlar); ROC bo'yicha kauzal/antikauzal javobni tanlash; 14 ta yechilgan misol.

Eng ko'p ishlatiladiganlari qalin harf bilan. Imtihonda jadval beriladi, lekin xossani qaysi masalada qo'llashni tanib olish sizdan.

Nega ROC "o'z ichiga oladi", "teng" emas?

Qo'shganda qutblar qisqarib ketishi mumkin. Ma'ruza misoli: X1(z) = 1/(1 − ½z−1), X2(z) = −1/(1 − ½z−1), ikkalasi |z| > ½. Yig'indi Y(z) = 0 — butun tekislikda yaqinlashadi, R1 ∩ R2 dan ancha keng.

Asosiy xossalarning isboti (qisqa)

Surish: Z[x(n − k)] = Σx(n − k)z−n; m = n − k almashtirish: Σx(m)z−m−k = z−kX(z). Ya'ni "k namuna kechikish = z−k ga ko'paytirish" — raqamli filtrlardagi "z−1 bloki" (31-dars) shu.

Teskari aylantirish: Σx(−n)z−n; m = −n: Σx(m)zm = Σx(m)(z−1)−m = X(z−1). ROC chegaralari teskari bo'ladi: R1 < |z| < R2 → 1/R2 < |z| < 1/R1.

Masshtab: X(z/α) = Σx(n)(z/α)−n = Σ[αⁿx(n)]z−n → αⁿx(n). ROC |α| marta kengayadi: |α|R1 < |z| < |α|R2.

n ga ko'paytirish: dX/dz = Σx(n)(−n)z−n−1, −z ga ko'paytirsak: Σn·x(n)z−n = Z[n·x(n)]. ROC o'zgarmaydi.

O'ram: W(z) = ΣΣx(k)y(n − k)z−n; m = n − k: Σx(k)z−k·Σy(m)z−m = X(z)·Y(z). 22-darsdagi "o'ram = ko'phadlar ko'paytmasi" ning isboti.

2. Boshlang'ich qiymat teoremasi

x(n) kauzal bo'lsa:

x(0) = limz→∞ X(z)

Sababi: X(z) = x(0) + x(1)z−1 + x(2)z−2 + …, z → ∞ da barcha z−k hadlar nolga intiladi, faqat x(0) qoladi. Ma'ruza misollari:

x(n) = αⁿu(n), X(z) = z/(z − α): limz→∞ z/(z − α) = 1 = α0 ✓.

x(n) = nαⁿu(n), X(z) = αz/(z − α)²: surat darajasi 1, maxraj 2 → lim = 0 = 0·α0 ✓.

Tezkor tekshiruv: teskari almashtirishni topgach, x(0) ni lim X(z) bilan solishtiring — xato bo'lsa darhol ko'rinadi.

3. Teskari Z-almashtirish

Integral formula (nazariya)

Koshi teoremasiga asoslanib (ma'ruza): (1/2πj)∮γ zn−1dz = δ(n), γ — koordinata boshini o'rab, soat strelkasiga teskari aylanadigan yopiq chiziq. X(z) ni zn−1 ga ko'paytirib integrallasak:

x(n) = Z−1[X(z)] = (1/2πj)·∮γ X(z)·zn−1 dz = Σγ ichidagi qutblar Res[X(z)zn−1]

γ ROC ichida yotadi. Integral qoldiqlar teoremasi bo'yicha γ ichidagi qutblardagi qoldiqlar yig'indisiga teng. Amalda bu formula bilan kamdan-kam hisoblanadi — quyidagi ikki usul ancha oson.

1-usul: bevosita (ko'zdan kechirish)

Agar X(z) ko'phad bo'lsa yoki jadvaldagi elementar juftliklar chiziqli kombinatsiyasiga ajratilsa, javob darhol yoziladi.

Ma'ruza 1-misoli: X(z) = z4 + 3z−1 + 4z−10. Chiziqlilik va Z[δ(n − N)] = z−N bo'yicha: x(n) = δ(n + 4) + 3δ(n − 1) + 4δ(n − 10).

Ma'ruza 2-misoli: X(z) = z²/(z − α)², |z| > |α|. Ajratamiz: z²/(z − α)² = αz/(z − α)² + z/(z − α) (tekshiring: suratlar yig'indisi αz + z(z − α) = z²). Juftliklar: z/(z − α) ↔ αⁿu(n), αz/(z − α)² ↔ nαⁿu(n). x(n) = (n + 1)αⁿu(n).

2-usul: oddiy kasrlarga ajratish (asosiy usul)

X(z) — z−1 bo'yicha ratsional, (1) maxraj darajasi suratnikidan katta, (2) qutblar oddiy (takrorlanmaydi). Shunda:

X(z) = Σi Ri/(1 − diz−1),    Ri = X(z)·(1 − diz−1)|z=di

di — qutblar, Ri — qoldiqlar (residuals): X(z) ni shu qutb ko'paytuvchisiga ko'paytirib (ya'ni uni "o'chirib"), qolganini z = di da hisoblaymiz. Keyin har bir kasrni ROC bo'yicha teskari almashtiramiz:

Qutb di ROC ga nisbatanRi/(1 − diz−1) ning teskarisi
ROC |z| > |di| (qutb ROC ning ichki tomonida)Ri·diⁿ·u(n) — kauzal
ROC |z| < |di| (qutb ROC ning tashqi tomonida)−Ri·diⁿ·u(−n − 1) — antikauzal
Ma'ruza eslatmalari. (1) Butun ROC |z| < ρ bo'lsa, javob to'liq antikauzal: x(n) = −u(−n − 1)ΣRidiⁿ. (2) Surat darajasi maxrajnikidan kichik bo'lmasa, avval ko'phadlarni bo'lamiz: X(z) = P(z) + N'(z)/D(z), P(z) = Σcnz−n — ko'phad qismi (deltalar beradi), qolgani — to'g'ri kasr.

Ma'ruza misoli (oson — surat 1, oddiy qutblar)

X(z) = 1/[(1 − ½z−1)(1 − ⅓z−1)]. Kauzal va antikauzal ketma-ketliklarni toping.

Qutblar: d1 = ½, d2 = ⅓.

R1 = 1/(1 − ⅓z−1)|z=½ = 1/(1 − ⅓·2) = 1/(⅓) = 3.   R2 = 1/(1 − ½z−1)|z=⅓ = 1/(1 − ½·3) = −2.

X(z) = 3/(1 − ½z−1) − 2/(1 − ⅓z−1).

Kauzal (ROC |z| > ½): x(n) = [3(½)ⁿ − 2(⅓)ⁿ]u(n). Tekshiruv: x(0) = 3 − 2 = 1 = lim X(z) ✓.

Antikauzal (ROC |z| < ⅓): x(n) = −[3(½)ⁿ − 2(⅓)ⁿ]u(−n − 1).

(Uchinchi variant — ⅓ < |z| < ½ halqa: ⅓ qutb kauzal, ½ qutb antikauzal: x(n) = −3(½)ⁿu(−n − 1) − 2(⅓)ⁿu(n).)

Ma'ruza misoli (o'rta — z ning musbat darajalarida)

X(z) = 2z/[(z − 1)(z − 2)], ROC |z| > 2 (kauzal).

Ko'rinishni X(z) = Az/(z − 1) + Bz/(z − 2) deb izlaymiz (z/(z − a) ↔ aⁿu(n) juftligi uchun qulay). Maxrajga ko'paytirib, z ga bo'lamiz: 2 = A(z − 2) + B(z − 1) = (A + B)z − (2A + B).

Koeffitsiyentlar: A + B = 0, −2A − B = 2 → B = −A, −A = 2 → A = −2, B = 2.

X(z) = −2z/(z − 1) + 2z/(z − 2) → x(n) = −2u(n) + 2·2ⁿu(n) = 2(2ⁿ − 1)u(n). Tekshiruv: x(0) = 0 = lim 2z/z² ✓.

(Xuddi shu natija qoldiqlar bilan: X = 2z−1/[(1 − z−1)(1 − 2z−1)], R(1) = 2·1/(1 − 2) = −2, R(2) = 2·½/(1 − ½) = 2.)

4. Yechilgan misollar (Exercises 2 va qo'lyozmalar)

3.1-masala: x(n) = [(½)ⁿ + (¾)ⁿ]u(n − 10)

u(n − 10) bor — surish xossasidan foydalanish uchun signalni x(n) = y(n − 10) ko'rinishiga keltiramiz: (½)ⁿ = (½)10(½)n−10, (¾)ⁿ = (¾)10(¾)n−10. Demak y(n) = (½)10(½)ⁿu(n) + (¾)10(¾)ⁿu(n).

Chiziqlilik: Y(z) = (½)10·z/(z − ½) + (¾)10·z/(z − ¾), |z| > ¾.

Surish (×z−10): X(z) = (½)10·z−9/(z − ½) + (¾)10·z−9/(z − ¾), ROC |z| > ¾.

3.2-masala: x(n) = 1, −10 ≤ n ≤ 10

x(n) = y(n + 10), y — 0 ≤ n ≤ 20 dagi quti (21 namuna). 28-darsdagi 2.2 bo'yicha Y(z) = (1 − z−21)/(1 − z−1). Oldinga surish (×z10): X(z) = z10(1 − z−21)/(1 − z−1), ROC 0 < |z| < ∞ (endi n < 0 namunalar ham bor → ∞ chiqariladi).

Qo'lyozma: y(n) = (½)n−5u(n − 5)

Bu aynan (½)ⁿu(n) ning 5 ga kechikkani: Y(z) = z−5·z/(z − ½) = z−4/(z − ½), |z| > ½. (3.1 dan farqi: bu yerda daraja ham n − 5, shuning uchun (½)5 ko'paytuvchi kerak emas.)

Qo'lyozma: o'ram xossasi

x(n) = x1(n) * x2(n), x1 = 3δ(n) + 2δ(n − 1), x2 = 2δ(n) − δ(n − 1).

X1 = 3 + 2z−1, X2 = 2 − z−1. X = X1X2 = 6 − 3z−1 + 4z−1 − 2z−2 = 6 + z−1 − 2z−2 → x(n) = {6, 1, −2}. (22-darsdagi jadval usuli bilan ham: {3, 2} * {2, −1} = {6, 1, −2} ✓.)

4.1-masala: Xa(z) = 1/(1 − ½z−1) — kauzal va antikauzal

Xa = z/(z − ½), qutb ½. Kauzal (|z| > ½): xa[n] = (½)ⁿu[n]. Antikauzal (|z| < ½): xa[n] = −(½)ⁿu[−n − 1].

4.2-masala: Xb(z) = 1/[(1 − ½z−1)(1 − z−1)]

Qutblar d1 = ½, d2 = 1. R1 = 1/(1 − z−1)|z=½ = 1/(1 − 2) = −1; R2 = 1/(1 − ½z−1)|z=1 = 1/(½) = 2.

Xb = 2/(1 − z−1) − 1/(1 − ½z−1).

Kauzal (|z| > 1): x[n] = 2u[n] − (½)ⁿu[n] = [2 − (½)ⁿ]u[n]. Antikauzal (|z| < ½): x[n] = −[2 − (½)ⁿ]u[−n − 1].

4.3-masala: Xc(z) = (1 − ½z−1)/(1 + ½z−1)

Surat va maxraj darajasi teng — to'g'ridan qoldiq usuli ishlamaydi. Mashg'ulot usuli: X = Y − ½z−1Y, Y = 1/(1 + ½z−1) → x(n) = y(n) − ½y(n − 1) (surish xossasi).

Kauzal: y(n) = (−½)ⁿu(n). x(n) = (−½)ⁿu(n) − ½(−½)n−1u(n − 1) = (−½)ⁿu(n) + (−½)ⁿu(n − 1) = (−½)ⁿ[u(n) + u(n − 1)]. u(n − 1) = u(n) − δ(n) va (−½)ⁿδ(n) = δ(n) bo'lgani uchun: x(n) = 2(−½)ⁿu(n) − δ(n).

Antikauzal: y(n) = −(−½)ⁿu(−n − 1); xuddi shunday hisob: x(n) = −2(−½)ⁿu(−n − 1) − δ(n).

Muqobil (ma'ruza 2-eslatmasi — bo'lish): (1 − ½z−1)/(1 + ½z−1) = −1 + 2/(1 + ½z−1) → kauzal: −δ(n) + 2(−½)ⁿu(n) ✓ — bir xil. Tekshiruv: x(0) = 2 − 1 = 1 = lim X(z) ✓.

5.1-masala: X(z) = (1 + 2z)(1 + 3z−1)(1 − z−1)

Ko'phad — qavslarni ochamiz: (1 + 3z−1 + 2z + 6)(1 − z−1) = 1 + 3z−1 + 2z + 6 − z−1 − 3z−2 − 2 − 6z−1 = 2z + 5 − 4z−1 − 3z−2. Bevosita usul: x(n) = 2δ(n + 1) + 5δ(n) − 4δ(n − 1) − 3δ(n − 2).

5.2-masala: X(z) = 3z/[(z − ½)(z + ¼)], |z| > ½

Surat va maxrajni z−2 ga ko'paytirib, z−1 ko'rinishiga o'tamiz: X = 3z−1/[(1 − ½z−1)(1 + ¼z−1)]. Qutblar ½ va −¼.

R1 = 3z−1/(1 + ¼z−1)|z=½ = 6/(1 + ½) = 4; R2 = 3z−1/(1 − ½z−1)|z=−¼ = −12/(1 + 2) = −4.

X = 4/(1 − ½z−1) − 4/(1 + ¼z−1), ROC |z| > ½ — ikkala qutb ichkarida → kauzal: x(n) = 4[(½)ⁿ − (−¼)ⁿ]u(n). Tekshiruv: x(0) = 0 = lim 3z/z² ✓.

5.3-masala: X(z) = (2z³ + z²)/[(z + 3)(z − 1)], |z| > 3

Surat darajasi (3) maxrajnikidan (2) katta. Mashg'ulot hiylasi: surat va maxrajni z−3 ga ko'paytiramiz: X = (2 + z−1)/[z−1(1 + 3z−1)(1 − z−1)] = z·Y(z), Y = (2 + z−1)/[(1 + 3z−1)(1 − z−1)]. Demak x(n) = y(n + 1).

Y ning qutblari −3 va 1. R1 = (2 + z−1)/(1 − z−1)|z=−3 = (2 − ⅓)/(1 + ⅓) = (5/3)/(4/3) = 5/4; R2 = (2 + z−1)/(1 + 3z−1)|z=1 = 3/4.

|z| > 3 → kauzal: y(n) = [¾ + (5/4)(−3)ⁿ]u(n). x(n) = y(n + 1) = ¼[3 + 5(−3)n+1]u(n + 1).

(x(−1) = ¼(3 + 5) = 2 — ha, X(z) da z1 hadi bor: z → ∞ da X ≈ 2z, shuning uchun x(−1) = 2 ✓.)

Qo'lyozma: ayirmali tenglama

x(n + 2) − 3x(n + 1) + 2x(n) = δ(n), boshlang'ich shartlar nol. x(n) = ?

Ikki tomonni Z ga o'tkazamiz (oldinga surish: x(n + k) → zkX(z), boshlang'ich shartlar nol bo'lgani uchun qo'shimcha had yo'q): z²X − 3zX + 2X = 1 → X(z) = 1/(z² − 3z + 2) = 1/[(z − 2)(z − 1)].

Oddiy kasrlar: 1/[(z − 2)(z − 1)] = 1/(z − 2) − 1/(z − 1). Har birini z−1·z/(z − a) ko'rinishida yozamiz: z−1·z/(z − 2) ↔ 2n−1u(n − 1).

x(n) = (2n−1 − 1)u(n − 1). Tekshiruv: x(0) = 0, x(1) = 0, x(2) = 1; tenglama n = 0 da: x(2) − 3x(1) + 2x(0) = 1 = δ(0) ✓.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (33-ma'ruza):

  1. Chiziqlilik: αX + βY, ROC ⊇ Rx ∩ Ry (qutblar qisqarsa kengayadi).
  2. Surish: x(n − N) ↔ z−NX(z). Teskari: x(−n) ↔ X(z−1), ROC 1/R. Masshtab: αⁿx(n) ↔ X(z/α), ROC |α|R. n·x(n) ↔ −z·dX/dz. O'ram: x * y ↔ X·Y.
  3. Boshlang'ich qiymat (kauzal): x(0) = limz→∞X(z).
  4. Teskari Z: x(n) = (1/2πj)∮X(z)zn−1dz = γ ichidagi qoldiqlar yig'indisi (γ ROC da).
  5. Bevosita usul: ko'phad → deltalar (z−N ↔ δ(n − N)); jadval juftliklari. z²/(z − α)² ↔ (n + 1)αⁿu(n).
  6. Oddiy kasrlar: X = ΣRi/(1 − diz−1), Ri = X(z)(1 − diz−1)|z=di.
  7. ROC bo'yicha: qutb ROC ichki chegarasida yoki undan ichkarida (|z| > |di|) → Ridiⁿu(n); tashqarida (|z| < |di|) → −Ridiⁿu(−n − 1).
  8. Surat darajasi ≥ maxraj: avval bo'lish (ko'phad qismi → deltalar) yoki zk ko'paytuvchini ajratib surish xossasini qo'llash.
  9. Ma'ruza: 1/[(1 − ½z−1)(1 − ⅓z−1)] → R = 3, −2 → [3(½)ⁿ − 2(⅓)ⁿ]u(n); 2z/[(z − 1)(z − 2)] → 2(2ⁿ − 1)u(n).
