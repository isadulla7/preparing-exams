33. Ehtimollik asoslari

O'qish vaqti: 50 daqiqa. Bu dars — 37-ma'ruzaga ("Introduction to stochastic processes") tayyorgarlik. Ma'ruza ehtimollik nazariyasini "allaqachon ma'lum" deb hisoblaydi (tasodifiy miqdor, zichlik funksiyasi, o'rtacha, dispersiya, Gauss taqsimoti). Shu tushunchalarni noldan, sodda tushuntiramiz — 34–36-darslarda ular har qadamda kerak bo'ladi.

Nega kerak? 37-ma'ruzadagi har bir formula shu darsdagi tushunchalardan qurilgan: mX(t) = ∫x·fX(x; t)dx — bu "kutilgan qiymat"; σX²(t) = σA²cos²(…) — bu "dispersiya"; "φ tekis taqsimlangan [0, 2π] da" — bu "tekis taqsimot". Imtihonda bu tushunchalarsiz tasodifiy jarayon savollarini yechib bo'lmaydi.
Bu darsda nimani bilib olasiz: ehtimollik, tasodifiy miqdor (diskret va uzluksiz); taqsimot funksiyasi (CDF) va zichlik funksiyasi (PDF); kutilgan qiymat E[·] va uning xossalari; dispersiya; tekis va Gauss taqsimotlari; ikki tasodifiy miqdor: birgalikdagi zichlik, mustaqillik, korrelyatsiya, kovariatsiya, korrelyatsiya koeffitsienti ρ. Har biri son misol bilan.

1. Ehtimollik nima?

Tajriba — natijasini oldindan aniq bilib bo'lmaydigan harakat: tanga tashlash, o'yin soqqasini (kubik) tashlash, rezistordagi shovqin kuchlanishini o'lchash. Natija — tajribaning bitta mumkin bo'lgan oqibati (masalan, soqqada "4"). Hodisa — natijalar to'plami (masalan, "juft son tushdi" = {2, 4, 6}).

Ehtimollik P(hodisa) — hodisa qanchalik tez-tez ro'y berishini ko'rsatuvchi 0 dan 1 gacha son. Tajribani juda ko'p marta takrorlasak: P ≈ (hodisa ro'y bergan marta)/(jami tajribalar).

  • P = 0 — hech qachon; P = 1 — har doim; P = 0,5 — yarim hollarda.
  • Barcha mumkin natijalar ehtimolliklari yig'indisi = 1.
  • Soqqa: P("4") = 1/6; P(juft) = 3/6 = ½.

2. Tasodifiy miqdor

Tasodifiy miqdor (random variable) X — har bir natijaga son mos qo'yuvchi qoida. Odatda katta harf bilan (X, A, φ), uning aniq qabul qilgan qiymati esa kichik harf bilan (x, a, θ) yoziladi.

O'xshatish: tasodifiy miqdor — "hali ochilmagan konvert ichidagi son". Konvertni ochmaguncha sonni bilmaymiz, lekin qaysi sonlar qanchalik tez-tez chiqishini (taqsimotini) bilamiz.
  • Diskret — sanoqli qiymatlar oladi: soqqa (1 … 6); bit uzatishdagi α = ±1 (37-ma'ruza); PAM-4 dagi α ∈ {−3, −1, +1, +3}.
  • Uzluksiz — oraliqdagi istalgan haqiqiy qiymat: rezistordagi shovqin kuchlanishi, sinusoida fazasi φ ∈ [0, 2π).

Diskret miqdor to'liq tavsifi — har bir qiymat ehtimolligi P(X = xi) = pi, Σpi = 1.

3. Taqsimot funksiyasi (CDF) va zichlik funksiyasi (PDF)

Uzluksiz miqdorda aniq bitta qiymatning ehtimolligi 0 (masalan, shovqin aynan 0,123456… V bo'lishi). Shuning uchun oraliqlar bilan ishlaymiz.

FX(x) = P(X ≤ x)    — kumulyativ taqsimot funksiyasi (CDF)

"X ning x dan oshmaslik ehtimolligi". Xossalari: F(−∞) = 0, F(+∞) = 1, hech qachon kamaymaydi. (Ma'ruzada P(X < x) deb ham yozilgan — uzluksiz miqdorda farqi yo'q.)

fX(x) = dFX(x)/dx    — ehtimollik zichligi funksiyasi (PDF)
  • fX(x) ≥ 0,   ∫−∞+∞ fX(x)dx = 1 (umumiy yuza 1).
  • P(a < X ≤ b) = ∫ab fX(x)dx = F(b) − F(a) — egri chiziq ostidagi yuza.
  • f(x) ning o'zi ehtimollik emas (1 dan katta ham bo'lishi mumkin), u "ehtimollikning zichligi": x atrofidagi kichik Δx oraliq ehtimolligi ≈ f(x)·Δx.
O'xshatish: stol ustiga 1 kg qum sepilgan deb tasavvur qiling. f(x) — har bir joydagi qum qalinligi, oraliq ustidagi qum og'irligi — shu oraliq ehtimolligi. Jami qum 1 kg = umumiy ehtimollik 1. F(x) — chap chetdan x gacha bo'lgan qum miqdori.

Diskret miqdorda PDF deltalardan iborat: fX(x) = Σpiδ(x − xi) (6-darsdagi Dirak deltasi). Masalan α = ±1 teng ehtimol: f(x) = ½δ(x − 1) + ½δ(x + 1). Aniq (deterministik) son x0 ham "tasodifiy miqdor" sifatida yozilishi mumkin: f(x) = δ(x − x0) — ehtimollik 1 bilan x0 (37-ma'ruzada deterministik signal shu tarzda ko'rsatilgan).

4. Kutilgan qiymat (o'rtacha) E[X]

mX = E[X] = ∫−∞+∞ x·fX(x)dx    (diskret: E[X] = Σxipi)

Juda ko'p tajriba natijalarining o'rtacha arifmetigi. "Qum" o'xshatishida — qumning og'irlik markazi.

Soqqa: E[X] = (1 + 2 + 3 + 4 + 5 + 6)/6 = 21/6 = 3,5 (hech qachon tushmaydigan qiymat — bu normal!).

Bit α = ±1 (p = ½ dan): E[α] = (+1)·½ + (−1)·½ = 0.

PAM-4 α ∈ {−3, −1, 1, 3} (har biri ¼): E[α] = (−3 − 1 + 1 + 3)/4 = 0.

Funksiyaning kutilgan qiymati — eng ko'p ishlatiladigan formula

E[g(X)] = ∫−∞+∞ g(x)·fX(x)dx

Y = g(X) ning PDF sini topish shart emas — to'g'ridan-to'g'ri X ning PDF si bilan integrallaymiz. 37-ma'ruzada aynan shunday: E[cos(2πf0t + φ)] = ∫fφ(θ)cos(2πf0t + θ)dθ.

Xossalar (yodlang!)

  • Chiziqlilik: E[aX + b] = aE[X] + b;   E[X + Y] = E[X] + E[Y].
  • Aniq (deterministik) ko'paytuvchi tashqariga chiqadi: E[c·X] = c·E[X]. Ma'ruza: "kutilgan qiymat operatori faqat tasodifiy qismga ta'sir qiladi". Masalan, A tasodifiy, t esa oddiy vaqt: E[A·cos(2πf0t)] = cos(2πf0t)·E[A].
  • Aniq sonning kutilgan qiymati — o'zi: E[c] = c.
  • E[X²] — "o'rtacha kvadrat" (o'rtacha quvvat). PAM-4: E[α²] = (9 + 1 + 1 + 9)/4 = 5; bit ±1: E[α²] = 1.

5. Dispersiya va standart og'ish

σX² = Var[X] = E[(X − mX)²] = E[X²] − mX²

Qiymatlar o'rtacha atrofida qanchalik sochilganini o'lchaydi. Standart og'ish σX = √σX² — X bilan bir xil birlikda (masalan, voltda). Ma'ruza: "rezistor shovqini — o'rtachasi nol, dispersiyasi haroratga bog'liq".

Soqqa: E[X²] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6. σ² = 91/6 − 3,5² = 15,17 − 12,25 = 35/12 ≈ 2,92, σ ≈ 1,71.

Bit ±1: σ² = E[α²] − 0² = 1.   PAM-4: σ² = 5 − 0 = 5.

Masshtab qoidasi: Var[cX] = c²·Var[X] (c ning kvadrati!), Var[X + b] = Var[X] (siljish sochilishni o'zgartirmaydi). 37-ma'ruzadagi σX²(t) = σA²·cos²(2πf0t + φ) aynan shu qoidadan: X(t) = A·c, c = cos(…).

6. Ikki muhim taqsimot

6.1. Tekis (uniform) taqsimot

fX(x) = 1/(b − a),   a ≤ x ≤ b;   boshqa joyda 0

Oraliqdagi barcha qiymatlar teng ehtimolli. Balandlik 1/(b − a) — yuza 1 bo'lishi uchun. m = (a + b)/2, σ² = (b − a)²/12.

Tasodifiy faza (37-ma'ruza): φ tekis [0, 2π] da → fφ(θ) = 1/(2π).

E[cos(c + φ)] = (1/2π)∫02πcos(c + θ)dθ = (1/2π)[sin(c + θ)]02π = (1/2π)(sin(c + 2π) − sin c) = 0 — istalgan c uchun (bitta to'liq davr bo'yicha kosinus integrali nol).

E[cos(c + 2φ)] = 0 ham (ikki to'liq davr). E[cos²φ] = E[(1 + cos 2φ)/2] = ½.

6.2. Gauss (normal) taqsimoti

fX(x) = (1/√(2πσ²))·e−(x − m)²/(2σ²)

"Qo'ng'iroq" shaklidagi egri chiziq: markazi m, kengligi σ. Ko'p kichik tasodifiy ta'sirlar yig'indisi deyarli doim Gauss taqsimotiga ega bo'ladi — shuning uchun issiqlik shovqini Gauss taqsimotli (elektronlarning millionlab tasodifiy harakati yig'indisi).

  • P(|X − m| < σ) ≈ 68%, P(|X − m| < 2σ) ≈ 95%, P(|X − m| < 3σ) ≈ 99,7%.
  • m = 0 da CDF ni ma'ruzada erfc funksiyasi orqali yozilgan: FX(x) = 1 − ½·erfc(x/(√2·σ)). Uning qiymatlarini yodlash shart emas — g'oya muhim: F ni hisoblab, f = dF/dx bilan PDF topiladi.
  • Muhim xossa: X Gauss bo'lsa, Y = cX ham Gauss: o'rtachasi c·m, dispersiyasi c²σ². (37-ma'ruzadagi uzun erfc hisoblari natijasi aynan shu — 36-dars.)

7. Ikki tasodifiy miqdor

Tasodifiy jarayonda ikki vaqtdagi qiymatlar X(t1) va X(t2) — ikki tasodifiy miqdor. Ularning birgalikdagi xulqini tavsiflash kerak.

FX,Y(x, y) = P(X ≤ x, Y ≤ y),    fX,Y(x, y) = ∂²FX,Y/∂x∂y

"X ≤ x va Y ≤ y bir vaqtda" ehtimolligi; birgalikdagi zichlik — tekislik ustidagi "qum tepaligi" (jami hajm 1).

  • Mustaqillik: biri ikkinchisi haqida hech narsa aytmaydi: fX,Y(x, y) = fX(x)·fY(y). Masalan, ketma-ket uzatilgan bitlar (ma'ruza: "αi statistik mustaqil").
  • Korrelyatsiya: E[XY] = ∬xy·fX,Y(x, y)dxdy — ikkalasi "bir tomonga" o'zgarishga moyilmi?
  • Kovariatsiya: Cov[X, Y] = E[(X − mX)(Y − mY)] = E[XY] − mXmY — o'rtachalari olib tashlangan korrelyatsiya.
  • Korrelyatsiya koeffitsienti (Pirson): ρ = Cov[X, Y]/(σXσY), doim −1 ≤ ρ ≤ 1. ρ = 1 — to'liq musbat bog'liq (Y = aX + b, a > 0), ρ = 0 — chiziqli bog'liqlik yo'q, ρ = −1 — to'liq teskari bog'liq.
  • Mustaqil ⇒ korrelyatsiyasiz: E[XY] = E[X]·E[Y], Cov = 0, ρ = 0. (Teskarisi har doim ham to'g'ri emas.)

Misol (bitlar): αi, αj = ±1, mustaqil, o'rtachasi 0. i ≠ j: E[αiαj] = E[αi]E[αj] = 0·0 = 0. i = j: E[αi²] = 1. Qisqasi: E[αiαj] = δ(i − j) (Kroneker deltasi). Bu natija 36-darsda raqamli uzatish jarayonining avtokorrelyatsiyasini hisoblashda ishlatiladi.

Misol (to'liq bog'liq): Y = 2X, σX = 1, mX = 0. Cov = E[X·2X] = 2E[X²] = 2, σY = 2 → ρ = 2/(1·2) = 1. Y = −2X bo'lsa ρ = −1.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (37-ma'ruza uchun zarur asos):

  1. Ehtimollik 0 … 1; barcha natijalar yig'indisi 1. Tasodifiy miqdor — natijaga mos son (diskret / uzluksiz).
  2. CDF: FX(x) = P(X ≤ x) (0 dan 1 gacha, kamaymaydi). PDF: fX = dFX/dx, ∫f = 1, P(a < X ≤ b) = ∫abf dx.
  3. Diskret: f(x) = Σpiδ(x − xi); aniq son x0: f = δ(x − x0).
  4. E[X] = ∫x f(x)dx; E[g(X)] = ∫g(x)f(x)dx; E[aX + b] = aE[X] + b; deterministik ko'paytuvchi E dan tashqariga chiqadi.
  5. σ² = E[(X − m)²] = E[X²] − m²; Var[cX] = c²Var[X].
  6. Tekis [a, b]: f = 1/(b − a), m = (a + b)/2, σ² = (b − a)²/12. Tekis faza [0, 2π]: f = 1/2π, E[cos(c + φ)] = 0, E[cos²φ] = ½.
  7. Gauss: f = e−(x−m)²/2σ²/√(2πσ²); 68–95–99,7% (±σ, ±2σ, ±3σ); cX ham Gauss, dispersiyasi c²σ².
  8. Ikki miqdor: FXY = P(X ≤ x, Y ≤ y); mustaqil: fXY = fXfY.
  9. Cov = E[XY] − mXmY; ρ = Cov/(σXσY) ∈ [−1, 1]; mustaqil ⇒ ρ = 0.
  10. Mustaqil bitlar ±1: E[αiαj] = δ(i − j); PAM-4: E[α²] = 5.
