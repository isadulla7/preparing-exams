32. Turg'unlik va fizik amalga oshirish

O'qish vaqti: 55 daqiqa. Manba: 36-ma'ruza ("Stability of Discrete Time LTI systems. Physical feasibility of Discrete Time LTI systems"), mashg'ulot: "Exercises 3 — Linear systems" (3c, 4, 5, 6c-masalalar).

Bu A mavzu. Imtihonda deyarli har doim: "Tizim turg'unmi?", "Qaysi ROC turg'un tizimga mos?", "Teskari tizim turg'unmi?", "Minimal fazalimi?", "Ketma-ket / parallel / qayta aloqali ulanishning H(z) i?". Hammasi bitta qoidaga tayanadi: ROC birlik aylanani o'z ichiga oladimi?
Bu darsda nimani bilib olasiz: BIBO turg'unlik va Σ|h(n)| < ∞ teoremasi (isboti bilan); turg'unlik va qutblar (kauzal, antikauzal, ikki tomonlama); fizik amalga oshirish (haqiqiy koeffitsiyentlar, qo'shma juftlar); teskari tizim (ekvalayzer); minimal fazali tizim; ketma-ket, parallel va qayta aloqali ulanishlar; ma'ruza va mashg'ulotdagi barcha misollar.

1. Turg'unlik nima?

Hayotiy misol. Mikrofonni karnayga yaqin olib borsangiz, kichkina shovqin ham kuchayib, kuchayib, quloqni yorgudek chiyillashga aylanadi. Kirish (gapirish) chegaralangan edi, chiqish esa cheksiz o'sdi. Bu — turg'un emas tizim. Oddiy kuchaytirgich (mikrofon uzoqda) esa ovozni kuchaytiradi, lekin ma'lum chegaradan oshirmaydi — turg'un.

Ma'ruzadagi eng keng tarqalgan ta'rif — BIBO turg'unlik (Bounded-Input Bounded-Output, "chegaralangan kirish → chegaralangan chiqish"):

har qanday |x(n)| ≤ X0 < ∞ uchun   |y(n)| ≤ Y0 < ∞

Bu yerda X0, Y0 — haqiqiy, musbat, chekli o'zgarmaslar. Ya'ni "qanchalik katta bo'lmasin, lekin chekli" kirish berilsa, chiqish ham chekli qolishi kerak. Birorta chegaralangan kirish chiqishni cheksizlikka olib ketsa — tizim turg'un emas.

Teorema: LTI tizim BIBO turg'un ⇔ h(n) modul bo'yicha yig'iladi

hs = Σn=−∞+∞ |h(n)| < ∞

"Modul bo'yicha yig'iladi" — impuls javobining barcha namunalari modullari yig'indisi chekli son.

Yetarlilik (hs < ∞ ⇒ turg'un). |x(n)| ≤ X0 bo'lsin. y(n) = Σh(k)x(n − k) (31-dars). Yig'indining moduli modullar yig'indisidan katta emas (uchburchak tengsizligi):

|y(n)| ≤ Σ|h(k)|·|x(n − k)| ≤ X0·Σ|h(k)| = X0·hs < ∞

Zaruriylik (hs = ∞ ⇒ turg'un emas). Shunday chegaralangan kirish topamizki, chiqish portlaydi. Ma'ruzadagi tanlov: x(n) = h*(−n)/|h(−n)| (h(−n) ≠ 0 da), aks holda 0. Bu kirishning moduli har doim 1 yoki 0 — chegaralangan. n = 0 dagi chiqish:

y(0) = Σh(k)x(−k) = Σh(k)·h*(k)/|h(k)| = Σ|h(k)|²/|h(k)| = Σ|h(k)| = hs = ∞

Demak shart zarur ham, yetarli ham.

Uchta oddiy misol

h(n) = (0,8)ⁿu(n): Σ|h| = 1 + 0,8 + 0,64 + … = 1/(1 − 0,8) = 5 < ∞ → turg'un. Umuman aⁿu(n): Σ|a|ⁿ = 1/(1 − |a|) faqat |a| < 1 da chekli.

h(n) = u(n) — akkumulyator y(n) = y(n − 1) + x(n) (kirishlarni to'plab boradi): Σ|h| = 1 + 1 + 1 + … = ∞ → turg'un emas. Tekshiruv: chegaralangan kirish x = u(n) berilsa, y(n) = n + 1 — cheksiz o'sadi. Diqqat: h(n) ning o'zi chegaralangan (doim 1), lekin bu yetarli emas — yig'indi chekli bo'lishi kerak.

h(n) = (1,2)ⁿu(n): o'zi ham o'sadi → turg'un emas. (30-darsdagi Exercises 3, 1-masala ham shunday: h(n) da (3/2)ⁿ bor.)

FIR filtr har doim turg'un: h = {b0, …, bN} — chekli sondagi chekli sonlar yig'indisi chekli.

2. Turg'unlik va qutblar (Z-almashtirish orqali)

Σ|h(n)| ni har safar hisoblash noqulay. Z-almashtirish bilan javob bir qarashda chiqadi.

Kauzal tizim

H(z) ning qutblari d1, …, dp oddiy (takrorlanmaydigan) bo'lsin va pn < pd. Sodda kasrlarga yoyamiz (29-dars):

H(z) = Σi Ri/(1 − diz−1)   →   h(n) = Σi Ri·diⁿ·u(n)

Σ|h(n)| ≤ Σi|Ri|·Σn≥0|di|ⁿ. Agar hamma |di| < 1 bo'lsa, har bir geometrik qator chekli → turg'un.

Teskarisi: turg'un bo'lsa, Σ|h| < ∞, demak h(n) → 0, ya'ni har bir diⁿ → 0 → |di| < 1.

Kauzal tizim turg'un ⇔ H(z) ning barcha qutblari birlik aylana ICHIDA (|di| < 1). ROC: Rh < |z|, bunda Rh (eng tashqi qutb moduli) < 1.

Antikauzal (ma'ruzada "non-causal") va ikki tomonlama tizimlar

Antikauzal (h(n) = 0, n > 0 — faqat chap tomonli) tizim: ROC — doira ichi |z| < Rh. Turg'un bo'lishi uchun barcha qutblar birlik aylanadan TASHQARIDA: Rh > 1.

Ikki tomonlama tizim: ROC — halqa Rh,1 < |z| < Rh,2. Turg'un ⇔ Rh,1 < 1 < Rh,2 (birlik aylana halqa ichida).

Yagona qoida (ma'ruza xulosasi): LTI tizim turg'un ⇔ H(z) ning ROC i birlik aylanani |z| = 1 o'z ichiga oladi — kauzallikdan qat'i nazar. Shuning uchun turg'un tizimda chastota javobi H(ej2πf) (DTFT) har doim mavjud (28-dars: DTFT = Z birlik aylanada).
Tizim turiROC shakliTurg'unlik sharti
Kauzal (o'ng tomonli)|z| > Rh (eng tashqi qutbdan tashqari)Rh < 1 — qutblar aylana ichida
Antikauzal (chap tomonli)|z| < Rh (eng ichki qutbdan ichkari)Rh > 1 — qutblar aylanadan tashqarida
Ikki tomonlamaRh,1 < |z| < Rh,2Rh,1 < 1 < Rh,2
Chekli (FIR)butun tekislik, ehtimol z = 0, ∞ dan tashqarihar doim turg'un

Ma'ruza misoli: α ning qaysi qiymatlarida tizim kauzal va turg'un?

y(n) = −2αy(n − 1) − α²y(n − 2) + x(n).

Z: Y = −2αz−1Y − α²z−2Y + X → H(z) = 1/(1 + 2αz−1 + α²z−2) = 1/(1 + αz−1)² — z = −α da ikki karrali qutb.

Tizim kauzal (chiqish faqat o'tgan qiymatlarga bog'liq) → turg'unlik uchun qutb aylana ichida: |α| < 1. (Slaydda "|a| < 1" deb yozilgan — bu o'sha α.)

3. Fizik amalga oshirish (physical feasibility)

Haqiqiy apparatda (yoki real vaqtda ishlaydigan dasturda) qurish mumkin bo'lgan tizim — fizik amalga oshiriladigan tizim. Ma'ruza ta'rifi:

Fizik amalga oshiriladi ⇔ h(n) haqiqiy va kauzal. Teng kuchli: ayirmali tenglama kauzal va barcha ak, bk — haqiqiy sonlar. Demak H(z) ham haqiqiy koeffitsiyentli, ROC esa barcha qutblarni o'z ichiga olgan aylanadan tashqari.

Nega "kauzal"? Kelajakdagi kirishni hali hech kim bilmaydi — undan foydalana olmaymiz. Nega "haqiqiy"? Simdagi kuchlanish, xotiradagi son — haqiqiy kattaliklar.

Muhim natija: haqiqiy koeffitsiyentli ko'phadning ildizlari yo haqiqiy, yo qo'shma juft bo'lib keladi. Demak H(z) koeffitsiyentlari haqiqiy ⇔ har bir kompleks qutb (nol) bilan birga uning qo'shmasi ham qutb (nol). Masalan, nol 0,5 + 0,5j bo'lsa, 0,5 − 0,5j ham nol bo'lishi shart.

Ma'ruza misoli (oxirgi slayd): FIR filtrni topish

Shart: tizim fizik amalga oshiriladi, FIR; H(z) ning nollari z = ejkπ/2, k = 1, 2; H(z)|z=1 = 1; impuls javobi koeffitsiyentlari soni 5 dan kam.

1) Nollar: k = 1 → ejπ/2 = j; k = 2 → ejπ = −1.

2) Qo'shma juft: koeffitsiyentlar haqiqiy bo'lishi uchun j bilan birga −j ham nol bo'lishi shart. Jami 3 ta nol → 3-darajali ko'phad → 4 ta koeffitsiyent (< 5 ✓).

3) Ko'paytma: H(z) = K(1 − jz−1)(1 + jz−1)(1 + z−1) = K(1 + z−2)(1 + z−1) = K(1 + z−1 + z−2 + z−3).

4) K: H(1) = 4K = 1 → K = ¼.

H(z) = ¼(1 + z−1 + z−2 + z−3),   h(n) = {¼, ¼, ¼, ¼}

Bu — 4 nuqtali o'rtacha filtr (31-darsdagi 3 nuqtalining "katta akasi"). H(1) = 1 — o'zgarmas signal o'zgarishsiz o'tadi.

4. Teskari tizim (ekvalayzer)

Hayotiy misol. Telefon liniyasi signalni buzadi (ba'zi chastotalarni susaytiradi). Qabul qilgichda bu buzilishni "orqaga qaytaradigan" tizim qo'yiladi — ekvalayzer (tenglashtirgich). Ikkalasi ketma-ket ulansa, signal o'zgarishsiz o'tadi: H(z)·HI(z) = 1 (ayniyat tizimi).

HI(z) = H−1(z) = 1/H(z)

H(z) kasr ko'rinishida bo'lsa: H(z) = b0Π(1 − ciz−1) / [a0Π(1 − diz−1)], u holda

HI(z) = a0Π(1 − diz−1) / [b0Π(1 − ciz−1)]

Nollar va qutblar o'rin almashadi: H ning nollari ci — HI ning qutblari, H ning qutblari di — HI ning nollari.

HI kauzal bo'lsa, ROC: |z| > max|ci|. Turg'un bo'lishi uchun ROC birlik aylanani o'z ichiga olishi kerak → asl tizimning barcha nollari ci birlik aylana ichida bo'lishi shart. Ya'ni: qutblari ham, nollari ham aylana ichidagi kauzal turg'un tizimning kauzal turg'un teskarisi bor.

Ma'ruza misoli 1: teskari tizim turg'un EMAS

y(n) = x(n) + 2x(n − 1) + (2/5)y(n − 1). Z: Y = X + 2z−1X + (2/5)z−1Y →

H(z) = (1 + 2z−1)/(1 − (2/5)z−1), |z| > 2/5   →   HI(z) = (1 − (2/5)z−1)/(1 + 2z−1), |z| > 2

H — kauzal va turg'un (qutb 2/5 aylana ichida). Lekin uning noli z = −2 aylanadan tashqarida → HI ning qutbi z = −2 → kauzal HI turg'un emas.

Ma'ruza misoli 2: teskari tizim turg'un

y(n) = x(n) − ½x(n − 1) + (9/10)y(n − 1) →

H(z) = (1 − ½z−1)/(1 − (9/10)z−1), |z| > 9/10   →   HI(z) = (1 − (9/10)z−1)/(1 − ½z−1), |z| > ½

H ning noli ½ va qutbi 9/10 — ikkalasi aylana ichida → HI ham turg'un. Bunday H — minimal fazali.

5. Minimal fazali tizim

Ta'rif: LTI tizim minimal fazali — uzatish funksiyasining barcha qutblari va barcha nollari birlik aylana ichida.
  • Bir xil amplituda javobi |H| ga ega bo'lgan barcha kauzal turg'un tizimlar orasida minimal fazali tizim fazani eng kam buzadi (nomi shundan).
  • Kauzal tizimning turg'un teskari tizimini qurish faqat u minimal fazali bo'lsagina mumkin.

Tekshirish tartibi: (1) nollarni toping; (2) qutblarni toping; (3) hammasi |·| < 1 mi? Bitta nol aylanada yoki tashqarida bo'lsa ham — minimal fazali emas.

6. LTI tizimlarni ulash

Katta tizim kichik bloklardan yig'iladi. Uch xil ulanish bor (ma'ruza):

Ketma-ket (series): birining chiqishi — keyingisining kirishi. Y1 = H1X, Y2 = H2Y1, … → He = H1·H2·…·HN (vaqtda: h1 * h2 * …).

Parallel: hammasiga bir xil kirish, chiqishlar qo'shiladi: Y = ΣYi = XΣHi → He = H1 + H2 + … + HN.

Qayta aloqa (feedback): chiqish h2 orqali qaytib, kirishdan ayiriladi: y = [x − y * h2] * h1. Z: Y = [X − YH2]H1 → Y(1 + H1H2) = XH1 →

He(z) = H1(z) / [1 + H1(z)H2(z)]

Agar qaytgan signal qo'shilsa (qo'shuvchida "−" belgisi yo'q), ishora almashadi: He = H1/(1 − H1H2).

7. Ma'ruza misoli: qayta aloqali tizim

(1) H(z) va h(n); (2) ayirmali tenglama; (3) x(n) = (−⅓)ⁿu(n) − ⅔δ(n) kirishga chiqish y(n).

(1) Bitta zveno: w(n) = x(n) + ⅔w(n − 1) → H1(z) = 1/(1 − ⅔z−1) (qo'shiluvchi qayta aloqa: H1 = 1/(1 − 1·⅔z−1)). Ikkinchi zveno aynan shunday, ikkalasi ketma-ket → ko'paytiriladi:

H(z) = 1/(1 − ⅔z−1)²,   |z| > ⅔

Ikki karrali qutb: 1/(1 − az−1)² ↔ (n + 1)aⁿu(n) (29-darsdagi "n ga ko'paytirish" xossasi). Shuning uchun h(n) = (n + 1)(⅔)ⁿu(n). Qutb ⅔ aylana ichida → kauzal va turg'un.

(2) (1 − ⅔z−1)² = 1 − (4/3)z−1 + (4/9)z−2 → y(n) = x(n) + (4/3)y(n − 1) − (4/9)y(n − 2).

(3) X(z) = 1/(1 + ⅓z−1) − ⅔ = [1 − ⅔ − (2/9)z−1]/(1 + ⅓z−1) = ⅓(1 − ⅔z−1)/(1 + ⅓z−1), |z| > ⅓.

Y = XH = ⅓(1 − ⅔z−1) / [(1 + ⅓z−1)(1 − ⅔z−1)²] = ⅓ / [(1 + ⅓z−1)(1 − ⅔z−1)] — bitta (1 − ⅔z−1) qisqardi.

Qoldiqlar: A = ⅓/(1 − ⅔z−1)|z=−⅓ = ⅓/(1 + 2) = 1/9; B = ⅓/(1 + ⅓z−1)|z=⅔ = ⅓/(1 + ½) = 2/9.

y(n) = (1/9)(−⅓)ⁿu(n) + (2/9)(⅔)ⁿu(n)

Tekshiruv: tenglama bo'yicha x(0) = 1 − ⅔ = ⅓, x(1) = −⅓ → y(0) = ⅓, y(1) = −⅓ + (4/3)(⅓) = 1/9. Formula: y(0) = 1/9 + 2/9 = ⅓ ✓, y(1) = −1/27 + 4/27 = 1/9 ✓.

8. Yechilgan misollar (Exercises 3)

3c-masala: y[n] − ¼y[n − 1] = x[n] + x[n − 1] − 2x[n − 2] minimal fazalimi?

31-darsda topdik: nollar z = 1, z = −2; qutblar z = 0, z = ¼. Qutblar aylana ichida → turg'un. Lekin nol z = −2 aylanadan tashqarida (z = 1 esa aylananing ustida) → minimal fazali emas. Shuning uchun uning kauzal teskarisi turg'un bo'lmaydi.

4-masala: FIR filtr va uning teskarisi

H(z) = (1 − 0,9ej0,6πz−1)(1 − 0,9e−j0,6πz−1)(1 − 1,25ej0,8πz−1)(1 − 1,25e−j0,8πz−1). (a) Qutb va nollar; (b) 1/H(z) turg'unmi?

(a) Har bir qavs (1 − pz−1) z = p da nolga aylanadi. Nollar: p1 = 0,9ej0,6π, p1*, p2 = 1,25ej0,8π, p2* (qo'shma juftlar → koeffitsiyentlar haqiqiy). z4 ga ko'paytirsak, maxrajda z4 → z = 0 da to'rt karrali qutb. FIR → turg'un. (Mashg'ulot yechimida ikkinchisi ham "p1" deb yozilgan — bu p2.)

(b) 1/H(z): nollar ↔ qutblar. Qutblar p1, p1*, p2, p2*, z = 0 da to'rt karrali nol — endi bu IIR. H(z) z−1 darajalarida yozilgan → kauzal → ROC: |z| > max|pi| = 1,25. Bu ROC birlik aylanani o'z ichiga olmaydi → turg'un emas. Sababi: H minimal fazali emas (nollar p2, p2* tashqarida).

5-masala: H(z) = (z−1 − ⅓)/(1 − ⅓z−1)

(a) Nollar, qutblar, turg'unlik; (b) |H(ej2πf)|.

Ayirmali tenglama: (1 − ⅓z−1)Y = (z−1 − ⅓)X → y(n) = −⅓x(n) + x(n − 1) + ⅓y(n − 1) — kauzal.

(a) Surat va maxrajni z ga ko'paytiramiz: H(z) = (1 − ⅓z)/(z − ⅓). Nol: 1 − ⅓z = 0 → z = 3. Qutb: z = ⅓. Kauzal, qutb aylana ichida → turg'un. (Nol z = 3 tashqarida → minimal fazali emas.)

Impuls javobi: h(n) = −⅓(⅓)ⁿu(n) + (⅓)n−1u(n − 1) → h(0) = −⅓, n ≥ 1 da h(n) = (8/9)(⅓)n−1: 0,89; 0,30; 0,10; …

(b) z = ejω: H = (e−jω − ⅓)/(1 − ⅓e−jω).

|surat|² = (cos ω − ⅓)² + sin²ω = 1 + 1/9 − ⅔cos ω;   |maxraj|² = (1 − ⅓cos ω)² + (⅓sin ω)² = 1 + 1/9 − ⅔cos ω.

|H(ejω)|² = (1 + 1/9 − ⅔cos ω)/(1 + 1/9 − ⅔cos ω) = 1   →   |H| = 1 (0 dB) har qanday ω da

Bunday tizim — hammasini o'tkazuvchi (all-pass): amplitudani o'zgartirmaydi, faqat fazani buradi: arg H = arg(cos ω − ⅓ − j sin ω) − arctg[⅓sin ω/(1 − ⅓cos ω)]. Belgi: nol (3) va qutb (⅓) — o'zaro teskari sonlar.

6c-masala

H(z) = (1 − z−1)/(1 + ¾z−1), |z| > ¾ (31-dars, 6-bo'lim). Qutb −¾ aylana ichida, ROC birlik aylanani o'z ichiga oladi → turg'un.

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (36-ma'ruza):

  1. BIBO: har qanday chegaralangan kirish → chegaralangan chiqish.
  2. Teorema: LTI turg'un ⇔ Σ|h(n)| < ∞. Yetarlilik: |y| ≤ X0Σ|h|. Zaruriylik: x(n) = h*(−n)/|h(−n)| → y(0) = Σ|h|.
  3. aⁿu(n) turg'un ⇔ |a| < 1; u(n) (akkumulyator) — turg'un emas; FIR — har doim turg'un.
  4. Kauzal: turg'un ⇔ barcha qutblar |di| < 1 (ROC |z| > Rh, Rh < 1). Antikauzal: qutblar tashqarida (|z| < Rh, Rh > 1). Ikki tomonlama: R1 < 1 < R2.
  5. Yagona qoida: turg'un ⇔ ROC birlik aylanani o'z ichiga oladi; shunda DTFT mavjud.
  6. Fizik amalga oshirish: h(n) haqiqiy va kauzal ⇔ ak, bk haqiqiy, tenglama kauzal. Kompleks qutb/nollar — qo'shma juft.
  7. Teskari tizim: HI = 1/H, nollar ↔ qutblar. Kauzal HI turg'un ⇔ H ning barcha nollari aylana ichida.
  8. Minimal fazali: barcha qutblar va nollar aylana ichida; faqat shunday kauzal tizimning turg'un teskarisi bor; fazani eng kam buzadi.
  9. Ulanishlar: ketma-ket H1H2…; parallel H1 + H2 + …; qayta aloqa (ayiruvchi) H1/(1 + H1H2).
  10. Ma'ruza: 1/(1 + αz−1)² → |α| < 1. (1 + 2z−1)/(1 − 0,4z−1) teskarisi turg'un emas; (1 − 0,5z−1)/(1 − 0,9z−1) — minimal fazali. Nollar j, −1 → H = ¼(1 + z−1 + z−2 + z−3). Qayta aloqa misoli: H = 1/(1 − ⅔z−1)², h = (n + 1)(⅔)ⁿu(n).
  11. Mashg'ulot: 3c — nol −2 → minimal fazali emas; 4 — 1/H ROC |z| > 1,25 → turg'un emas; 5 — nol 3, qutb ⅓, |H| = 1 (all-pass), turg'un.
