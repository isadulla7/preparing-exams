30. Diskret tizimlar xossalari, ayirmali tenglama

O'qish vaqti: 50 daqiqa. Manba: 34-ma'ruza ("Introduction to discrete-time LTI systems. Systems classification and examples"), mashg'ulot: "Exercises 3 — Linear systems" (1-masala).

Bu A mavzu. Imtihonda tipik savol: "y(n) = … tizimi chiziqlimi? statsionarmi? kauzalmi? xotirasi bormi?" — 4 ta variantdan to'g'ri xossalar to'plamini tanlash. Shuningdek "ayirmali tenglama rekursivmi?", "ZSR va ZIR nima?". 11-darsdagi uzluksiz tizimlar g'oyasi — faqat t o'rniga n.
Bu darsda nimani bilib olasiz: kirish-chiqish munosabati; chiziqlilik, statsionarlik, kauzallik, xotira, passivlik va ularni tekshirish retsepti; ma'ruzadagi barcha misollar; 10 ta tizimning tayyor jadvali; ayirmali tenglama, rekursiv/norekursiv; nol holat javobi (ZSR) va nol kirish javobi (ZIR).

1. Kirish-chiqish munosabati

Diskret tizim — kirish ketma-ketligi x(n) ni chiqish y(n) ga aylantiruvchi qoida (operator) L[·]:

y(n) = L[x(n)]

Tizimlar L[·] ning matematik ko'rinishiga qarab tasniflanadi (ma'ruza).

O'xshatish — oshxona retsepti. Kirish — mahsulotlar, chiqish — taom, L — retsept. "Chiziqli" retsept: ikki baravar mahsulot → ikki baravar taom. "Statsionar": dushanba ham, juma ham bir xil retsept. "Kauzal": oshpaz ertaga keladigan mahsulotdan bugun ovqat qila olmaydi. "Xotirasiz": har likopcha faqat hozir berilgan mahsulotdan.

2. Chiziqlilik

L[α1x1(n) + α2x2(n)] = α1L[x1(n)] + α2L[x2(n)]    (istalgan α1, α2 uchun)

Tekshirish retsepti: (1) chap tomon — kombinatsiyani tizimga bering; (2) o'ng tomon — har birini alohida berib, kombinatsiya qiling; (3) solishtiring.

Tezkor belgilar. Chiziqli emas, agar formulada: x ning kvadrati, ildizi, moduli, cos(x), ex kabi funksiyasi; yoki x ga bog'liq bo'lmagan qo'shiluvchi (y = x + 2: x = 0 da y ≠ 0) bo'lsa. n ga ko'paytirish (n·x(n)) yoki argumentni o'zgartirish (x(2n), x(−n)) chiziqlilikni buzmaydi.

3. Statsionarlik (vaqtga invariantlik)

Chiqish faqat kirish signalining shakliga bog'liq, uni qaysi lahzada berganimizga emas:

L[x(n)] = y(n)  ⇒  L[x(n − k)] = y(n − k)    barcha k uchun

Kirish k ga kechiksa (yoki oldinga surilsa), chiqish ham aynan k ga kechikadi. Ya'ni tizim har qanday vaqtda bir xil ishlaydi.

Tekshirish retsepti: (1) L[x(n − k)] — formulada faqat x ning argumentidagi n ni n − k bilan almashtiring; (2) y(n − k) — formuladagi hamma n ni n − k bilan almashtiring; (3) solishtiring.

Tezkor belgilar. Statsionar emas, agar formulada x dan tashqarida n bor (n·x(n), cos(n)·x(n)) yoki x ning argumenti n ning "cho'ziq" funksiyasi (x(2n), x(−n), x(n²)).

Ma'ruza misollari

1-misol: y(n) = x(n) + x(n − 1). Chiziqlilik: L[α1x1 + α2x2] = α1x1(n) + α2x2(n) + α1x1(n−1) + α2x2(n−1) = α1[x1(n) + x1(n−1)] + α2[x2(n) + x2(n−1)] — teng → chiziqli. Statsionarlik: L[x(n − k)] = x(n − k) + x(n − k − 1) = y(n − k) → statsionar.

2-misol: y(n) = √x(n). √(α1x1 + α2x2) ≠ α1√x1 + α2√x2 → chiziqli emas. L[x(n − n0)] = √x(n − n0) = y(n − n0) → statsionar.

3-misol: y(n) = n·x(n). [α1x1 + α2x2]·n = α1x1n + α2x2n → chiziqli. Lekin L[x(n − n0)] = x(n − n0)·n, y(n − n0) = x(n − n0)·(n − n0) — farqli → statsionar emas ("kuchaytirish" vaqt o'tishi bilan o'zgaradi).

4. Kauzallik

Kauzal tizimning joriy chiqishi y(n) kelajakdagi kirish qiymatlariga x(n + k), k > 0, bog'liq emas.

Ma'ruza: y(n) = x(2n) — kauzal emas: masalan, y(2) = x(4), ya'ni 2-lahzada 4-lahzadagi (kelajak) kirishni bilish kerak.

y(n) = x(n) + x(n − 1) — kauzal: faqat joriy va oldingi qiymat.

Ehtiyot bo'ling: y(n) = x(−n) ham kauzal emas (n = −3 da y(−3) = x(3) — kelajak). Faqat bitta n uchun kelajakka qarash kifoya — tizim kauzal emas.

5. Xotira

Xotirasiz tizim: y(n) faqat shu lahzadagi x(n) ga bog'liq. Aks holda tizimda xotira bor — o'tgan (yoki kelajak) qiymatlarni saqlashi kerak.

y(n) = 3x(n) — xotirasiz.

y(n) = 2x(n) − 3x(n − 1) — xotira 1; y(n) = 3x(n − 3) — xotira 3 (ma'ruza).

y(n) = Σk=0N αkx(n − k) — xotira N. N < ∞ — chekli xotira, aks holda cheksiz xotira.

6. Passivlik

Chekli energiyali Ex kirishga energiyasi Ey ≤ Ex < ∞ bo'lgan chiqish beradigan tizim — passiv: Σ|y(n)|² ≤ Σ|x(n)|². Tenglik bajarilsa — isrofsiz (lossless): energiyani saqlaydi.

y(n) = ½x(n) — passiv (Ey = Ex/4). y(n) = x(n − 3) — isrofsiz (energiya surishga bog'liq emas, 23-dars). y(n) = 2x(n) — passiv emas (Ey = 4Ex).

8. LTI tizimlar va ayirmali tenglama

Amalda eng muhim sinf — bir vaqtda chiziqli va statsionar tizimlar (LTI). Kauzal diskret LTI tizim o'zgarmas koeffitsiyentli chekli ayirmali tenglama bilan tavsiflanadi (odatda a0 = 1):

y(n) = −Σk=1M ak·y(n − k) + Σk=0N bk·x(n − k)

Ya'ni chiqish = joriy kirish x(n), N ta oldingi kirish va M ta oldingi chiqishning chiziqli kombinatsiyasi. (Uzluksizdagi differensial tenglamaning diskret o'xshashi: hosila o'rniga surish.)

  • Rekursiv: kamida bitta ai ≠ 0 (i = 1 … M) — chiqish o'z o'tmishiga bog'liq ("qayta aloqa"). 31-darsda: IIR.
  • Norekursiv: hamma ai = 0 — chiqish faqat kirishlardan. 31-darsda: FIR.

9. Ayirmali tenglamani yechish: ZSR va ZIR

Vazifa: x(n) va boshlang'ich shartlar y(−1), …, y(−M) ma'lum bo'lsa, n ≥ 0 uchun y(n) ni topish. Umumiy yechim ikki qismga ajraladi:

y(n) = yso(n) + yio(n)
  • yso(n) — nol holat javobi (Zero State Response, ZSR): boshlang'ich shartlar nol, kirish bor. Tenglama: yso(n) + Σakyso(n − k) = Σbkx(n − k), y(−M) … y(−1) = 0.
  • yio(n) — nol kirish javobi (Zero Input Response, ZIR): kirish nol, faqat boshlang'ich shartlar: yio(n) + Σakyio(n − k) = 0, yio(k) = y(k), k = −M … −1.

Turg'un LTI tizimlarda ZIR vaqt o'tishi bilan so'nadi — shuning uchun uni o'tkinchi javob (transient) ham deyishadi. Ma'ruza: keyingi darslarda barqaror (steady) xulqqa e'tibor beramiz, ya'ni boshlang'ich shartlarni nol deb olamiz.

Ma'ruza misoli: y(n) = ½y(n − 1) + x(n), y(−1) = 1

ZSR (yso(n) = 0, n < 0): qadamma-qadam:

yso(0) = ½·0 + x(0) = x(0);   yso(1) = ½x(0) + x(1);   yso(2) = ¼x(0) + ½x(1) + x(2); …

yso(n) = Σk=0n (½)n−kx(k) = (1/2ⁿ)·Σk=0n 2kx(k)

ZIR (x = 0, yio(−1) = 1): yio(0) = ½, yio(1) = ¼, yio(2) = ⅛, … → yio(n) = 1/2n+1.

To'liq: y(n) = (1/2ⁿ)·[½ + Σk=0n 2kx(k)].

Davomi: kirish x(n) = u(n) bo'lsa

yso(n) = Σk=0n (½)n−k = 1 + ½ + … + (½)ⁿ = 2[1 − (½)n+1] = 2 − (½)ⁿ (chekli geometrik qator).

y(n) = 2 − (½)ⁿ + (½)n+1 = 2 − (½)n+1. Tekshiruv rekursiya bilan: y(0) = ½·1 + 1 = 1,5 ✓ (2 − ½); y(1) = 0,75 + 1 = 1,75 ✓ (2 − ¼). n → ∞ da y → 2 — barqaror qiymat, ZIR so'nib ketdi.

10. Yechilgan misol (Exercises 3, 1-masala): impuls javobi rekursiya bilan

Tizim: y[n] = x[n] − x[n − 1] + (3/2)·y[n − 1] (sxemada ikki z−1 bloki: biri kirishni, biri chiqishni kechiktiradi). Impuls javobini toping.

Ta'rif bo'yicha (mashg'ulotdagi muqobil yechim): impuls javobi h[n] — kirish δ[n] bo'lganda, nol boshlang'ich holatda (h[n] = 0, n < 0) chiqish:

h[n] = δ[n] − δ[n − 1] + (3/2)·h[n − 1]

h[0] = 1 − 0 + (3/2)·0 = 1;   h[1] = 0 − 1 + (3/2)·1 = ½;   h[2] = 0 − 0 + (3/2)·½ = ¾;   h[3] = (3/2)·¾ = (3/2)²·½; …

Qonuniyat: h[n] = δ[n] + ½·(3/2)n−1·u[n − 1].

Z orqali (mashg'ulotdagi asosiy yechim, 29-dars usuli): Y(1 − (3/2)z−1) = X(1 − z−1) → H(z) = (1 − z−1)/(1 − (3/2)z−1) = 1/(1 − (3/2)z−1) − z−1/(1 − (3/2)z−1). Teskari: h[n] = (3/2)ⁿu[n] − (3/2)n−1u[n − 1] = … = ½(3/2)n−1u[n − 1] + δ[n] ✓ — bir xil.

E'tibor: h[n] cheksiz o'sadi (qutb 3/2 > 1) — bu tizim turg'un emas (32-dars).

📝 Konspekt

Shularni bilsangiz, bu mavzuni bilasiz (34-ma'ruza):

  1. Tizim: y(n) = L[x(n)].
  2. Chiziqli: L[α1x1 + α2x2] = α1L[x1] + α2L[x2]. Buzadi: x², √x, |x|, cos x, + o'zgarmas.
  3. Statsionar: L[x(n − k)] = y(n − k). Tekshirish: L[x(n−k)] da faqat x argumentidagi n almashtiriladi, y(n−k) da hamma n. Buzadi: n·x(n), x(2n), x(−n).
  4. Kauzal: y(n) kelajak x(n + k), k > 0 ga bog'liq emas. x(2n), x(−n), x(n+1) — kauzal emas.
  5. Xotirasiz: faqat x(n). Σk=0Nαkx(n − k) — xotira N.
  6. Passiv: Ey ≤ Ex; tenglik — isrofsiz.
  7. Ma'ruza misollari: x(n) + x(n−1) — L, TI; √x(n) — L emas, TI; n·x(n) — L, TI emas.
  8. Kauzal LTI: y(n) = −Σk=1Maky(n−k) + Σk=0Nbkx(n−k). Rekursiv — biror ak ≠ 0; norekursiv — hammasi 0.
  9. y = yso + yio: ZSR — nol boshlang'ich holat; ZIR — nol kirish (turg'un tizimda so'nadi, "o'tkinchi").
  10. Ma'ruza: y = ½y(n−1) + x, y(−1) = 1 → ZIR = 1/2n+1, ZSR = Σ(½)n−kx(k).
  11. Impuls javobi rekursiya bilan: x = δ, nol holat, qadamma-qadam hisoblash.
