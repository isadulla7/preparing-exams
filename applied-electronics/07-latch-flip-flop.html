7. Latch va flip-flop: 1 bitni saqlash

Bu darsda nimani bilib olasiz: sxema 1 bitni qanday eslab qolishini. Latch va flip-flop orasidagi farq, D, JK, T flip-floplar va reset (tozalash) buyrug'i. Bu A mavzu: imtihonda deyarli har safar flip-flop masalasi tushadi. Testlarda latch va flip-flop haqida 5 ta savol bor, ularning hammasini shu darsda yechamiz. Manba: B2 slaydlari. O'qish vaqti: 25 daqiqa.

5-darsdan eslatma: kombinatsion sxemalar hech narsani eslab qolmaydi. Endi eslab qoladigan sxemalarni o'rganamiz.

1. Takt signali (clock)

Takt (CK yoki CLK) to'xtovsiz 0-1-0-1 almashib turadigan signal. U sxemaga "hozir yangilan" deb buyruq beradi, xuddi orkestrdagi dirijyor tayoqchasi yoki metronom kabi.

  • Ko'tariluvchi front (rising edge, positive edge): 0 → 1 o'tish lahzasi. Belgisi ↑.
  • Tushuvchi front (falling edge, negative edge): 1 → 0 o'tish lahzasi. Belgisi ↓.
  • Davr T: bir to'liq tsikl vaqti. Chastota f = 1/T. Masalan T = 10 ns → f = 100 MHz.

2. Latch: eshik ochiq bo'lsa kuzatadi, yopiq bo'lsa eslab qoladi

D latch ikkita kirishga ega: D (ma'lumot) va LE (latch enable, ruxsat). Chiqishi Q.

LE (high-level latch uchun)Holat nomiQ nima qiladi
LE = 1Shaffof (transparent)D ni kuzatadi: D o'zgarsa, Q ham o'zgaradi
LE = 0Xotira (latched, memory)Oxirgi qiymatni saqlaydi, D o'zgarsa ham o'zgarmaydi
Deraza: ochiq bo'lsa (LE = 1) ko'chadagi hamma narsani ko'rasiz. Yopilgan lahzada ko'rgan manzarangiz "rasm" bo'lib qoladi va ko'chada nima bo'lsa ham o'zgarmaydi.

Low-level latch (past darajaga sezgir) teskari ishlaydi: LE = 0 da shaffof, LE = 1 da xotira. Slayd yoki savolda "high level sensitive" yoki "low level sensitive" deyilganiga diqqat qiling. Butun savol shunga bog'liq.

Imtihon savollari: 004, 088, 092

004: A high level sensitive latch has the command LE (latch enable) = 1. In this condition:
a) the output always remains at 1   b) the output does not change even if the input changes   c) the output changes state following the input   d) the output always remains at 0

High-level latch, LE = 1 → shaffof → Q kirishni kuzatadi. Javob c).

088: A high-level sensitive latch has the LE command (latch enable) = 0. In this condition:
a) the output always remains at 0   b) the output changes state following the input   c) the output does not change even if the input changes   d) the output always remains at 1

High-level latch, LE = 0 → xotira → Q o'zgarmaydi. Javob c).

092: A low level sensitive latch has the LE command (latch enable) = 1. In this condition:
a) the output always remains at 1   b) the output does not change even if the input changes   c) the output changes state following the input   d) the output always remains at 0

Diqqat: bu low-level latch. Uning uchun LE = 1 bu xotira holati → Q o'zgarmaydi. Javob b).

Qoida: "always remains at 0/1" variantlari latch savollarida deyarli har doim noto'g'ri. Latch faqat ikki narsa qiladi: kuzatadi yoki saqlaydi.

3. Flip-flop: faqat front lahzasida "suratga oladi"

D flip-flop (D FF) latchdan farqli ravishda D ni faqat takt frontida o'qiydi. Qolgan butun vaqt davomida Q o'zgarmaydi, D qanday o'zgarishidan qat'i nazar.

  • Positive edge-triggered: ko'tariluvchi frontda (0→1) ishlaydi. Belgisida CK kirishi yonida kichik uchburchak ▷ bor.
  • Negative edge-triggered: tushuvchi frontda (1→0) ishlaydi. Belgisida uchburchak oldida doiracha bor.
Latch = video kamera (deraza ochiq paytda hammasini yozadi). Flip-flop = fotoapparat (faqat tugma bosilgan lahzani suratga oladi).

Ichkaridan flip-flop ikkita latchdan yasaladi: master va slave (master-slave D FF). Ular teskari LE bilan ishlaydi, shuning uchun hech qachon ikkalasi bir vaqtda shaffof bo'lmaydi va natijada faqat front lahzasi muhim bo'ladi.

4. JK va T flip-floplar

JK flip-flop ikkita kirishga ega: J va K. Takt frontida quyidagini qiladi:

JKFrontdan keyin QEslab qolish
00O'zgarmaydi"hech narsa qilma"
010K = "Kill" (o'chir)
101J = "Jump" (yoq)
11Teskarisiga almashadi (toggle)"almashtir"

T flip-flop (toggle): T = 1 bo'lsa har frontda almashadi, T = 0 bo'lsa saqlaydi. JK da J = K = 1 qilsak, u T flip-flopga aylanadi. D FF da D = Q̄ (o'z chiqishining teskarisi) ulansa ham xuddi shunday bo'ladi.

Muhim natija: flip-flop chastotani 2 ga bo'ladi

Har bir toggle qiluvchi flip-flop chastotani 2 ga bo'ladi. Ketma-ket N ta shunday FF chastotani 2N ga bo'ladi. Masalan, 100 MHz takt va 3 ta FF → oxirgi chiqish 100/8 = 12.5 MHz. Bu hisoblagich (counter) masalalarining asosi (9-dars).

Imtihon savoli: 055

A JK flip-flop has inputs J and K both logical one. The output Q:
a) is equal to the output Qn   b) is always equal to one   c) changes state at each clock cycle   d) changes state every two clock cycles

J = K = 1 → toggle → Q har takt tsiklida almashadi. Javob c). (Qn bu Q̄, ya'ni teskari chiqish.)

5. Asinxron reset va set

Ko'p flip-floplarda qo'shimcha kirishlar bor:

  • RESET (yoki CLEAR, CLR): Q ni majburan 0 qiladi.
  • SET (yoki PRESET): Q ni majburan 1 qiladi.

Asinxron degani: taktni kutmaydi, darhol ishlaydi va aktiv bo'lib turgan butun vaqt davomida takt va D ni e'tiborsiz qoldiradi.

Active low (past darajada aktiv) degani: buyruq signal 0 bo'lganda ishlaydi. Nomining ustida chiziq bo'ladi: RST̄ yoki nRST. Active high esa 1 da ishlaydi.

Imtihon savoli: 103

In a negative edge-triggered flip-flop with asynchronous active low reset (RST), if RST = 0:
a) the output goes to 0 if the input D is at 0
b) the output goes to 0 if CK goes from 1 to 0
c) the output goes to 0 if CK goes from 0 to 1
d) the output always remains at 0

Tahlil: reset active low, RST = 0 → reset aktiv. Reset asinxron → taktni kutmaydi va D ga qaramaydi. Demak Q doim 0. Javob d). "Negative edge-triggered" so'zi chalg'itish uchun: reset aktiv bo'lganda front ahamiyatsiz.

📝 Konspekt (daftarga yozib oling)

Latch (darajaga sezgir)

  • High-level: LE = 1 → shaffof (Q = D); LE = 0 → saqlaydi.
  • Low-level: LE = 0 → shaffof; LE = 1 → saqlaydi.
  • Testda: "follows the input" yoki "does not change". "Always 0/1" deyarli doim noto'g'ri (004, 088, 092).

Flip-flop (frontga sezgir)

  • Faqat frontda D ni oladi va keyingi frontgacha saqlaydi.
  • Positive edge ↑ (0→1), negative edge ↓ (1→0, belgida doiracha).
  • Vaqt diagrammasi: har frontda D ga qarang → Q ga yozing.

JK jadvali

00 → saqla · 01 → 0 · 10 → 1 · 11 → almashtir (toggle)
  • J = K = 1 → har tsiklda almashadi (055). T FF = JK (J=K=1) = D FF (D = Q̄).
  • Toggle FF chastotani 2 ga bo'ladi; N ta FF → f / 2N.

Asinxron reset/set

  • Taktni va D ni kutmaydi. Aktiv bo'lsa Q doim 0 (reset) yoki 1 (set).
  • Active low (RST̄): 0 da aktiv. RST = 0 → Q doim 0 (103).
