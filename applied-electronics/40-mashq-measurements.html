40. Mashq: Measurements (imtihon uslubidagi masalalar)

Bu dars nima uchun: Measurements qismi imtihonda 9 ball beradi, 2019 imtihonlarida bu 6 ballik "sensor + noaniqlik" masalasi edi (39-dars). Bu yerda shu turdagi 3 ta yangi masala bor (raqamlarini men tuzdim, usuli rasmiy yechimlardagidek). Avval o'zingiz yeching, keyin javobni oching. Vaqt: 45 daqiqa.
Eslatma: sizning materiallaringizda Measurements bo'yicha test savollari yo'q, faqat 2019 yilgi 3 ta masala bor. Shuning uchun bu mashqlar slaydlardagi mavzular asosida tuzildi. Agar 2020–2021 yillardagi Measurements savollarini topsangiz, yuboring, ularni ham qo'shaman.

Retsept (yodlang)

  1. Model: chiqish = f(o'lchanuvchi, boshqa kattaliklar).
  2. Kalibrovka: o'lchanuvchi = f−1(chiqish, …).
  3. Nominal qiymatlarni qo'yib qiymatni toping.
  4. Har bir noaniq kattalik bo'yicha |hosila|.
  5. Foizlarni absolyutga aylantiring.
  6. δ = Σ |hosila|·δx (+ sensor noaniqligi).
  7. (qiymat ± δ) birlik, 2 muhim raqam.

Masala 1: rezistiv sensor, bo'luvchi (2019-06 B kabi)

Sxema 39-darsdagi B variant kabi: VS → Rθ → RF → yer, VF RF da o'lchanadi. Rθ = R0(1 + Aθ), R0 = 500 Ω, A = 0.0039 °C−1. Sensor noaniqligi δθ = 0.3 °C + 0.005·|θ|. RF = 500 Ω ± 0.1%, VS = (3.300 ± 0.003) V. VF = (1.500 ± 0.002) V bo'lganda θ ni toping.

Yechim

θ = (1/A)(RF·VS/(R0·VF) − RF/R0 − 1) = 256.4·(3.3/1.5 − 1 − 1) = 256.4·0.2 = 51.3 °C.

  • |∂θ/∂RF| = (1/A)·|VS/(R0·VF) − 1/R0| = 256.4·|0.0044 − 0.002| = 0.615 °C/Ω; δRF = 0.5 Ω → 0.31 °C
  • |∂θ/∂VS| = RF/(A·R0·VF) = 171 °C/V; δVS = 0.003 V → 0.51 °C
  • |∂θ/∂VF| = RF·VS/(A·R0·VF²) = 376 °C/V; δVF = 0.002 V → 0.75 °C
  • Sensor: 0.3 + 0.005·51.3 = 0.56 °C

δθ = 0.31 + 0.51 + 0.75 + 0.56 = 2.1 °C. θ = (51.3 ± 2.1) °C.

Masala 2: fotodiod (2019-06 A kabi)

Fotodiod: ISC = S·Ev + IOFF, S = (5.00 ± 0.05) nA/lux, IOFF = (2 ± 10) nA. Trans-rezistiv kuchaytirgich RF = 200 kΩ ± 0.5%. Vout = (1.002 ± 0.004) V. Ev = ?

Yechim

RF·S = 2·105 · 5·10−9 = 10−3 V/lux. Ev = Vout/(RF·S) − IOFF/S = 1002 − 2·10−9/5·10−9 = 1002 − 0.4 = 1001.6 lux.

  • Vout: 1/(RF·S)·δVout = 1000 · 0.004 = 4.0 lux
  • S: Vout/(RF·S²)·δS = 2.004·1011 · 0.05·10−9 = 10.0 lux (diqqat: aniq formulada IOFF/S² hadi ham bor, u juda kichik: 0.004 lux)
  • RF: Vout/(RF²·S)·δRF = 0.005 · 1002 = 5.0 lux
  • IOFF: (1/S)·δIOFF = 2·108 · 10−8 = 2.0 lux

δEv = 4.0 + 10.0 + 5.0 + 2.0 = 21 lux. Ev = (1002 ± 21) lux.

Masala 3: volt-ampermetr usuli + Pt1000

Pt1000 (R0 = 1000 Ω, A = 3.9083·10−3 °C−1, chiziqli model R = R0(1 + Aθ), class A: δθS = 0.15 °C + 0.002·|θ|) orqali I = 1.0000 mA tok o'tkaziladi va kuchlanish o'lchanadi.

  • Voltmetr: o'qish 1.2345 V, shkala 2 V, δV = ±(0.01% reading + 0.002% range).
  • Ampermetr: o'qish 1.0000 mA, shkala 2 mA, δI = ±(0.05% reading + 0.01% range).

R va θ ni noaniqligi bilan toping.

Yechim

Asbob noaniqliklari: δV = 0.0001·1.2345 + 0.00002·2 = 123.5 µV + 40 µV = 0.16 mV. δI = 0.0005·1 + 0.0001·2 = 0.5 µA + 0.2 µA = 0.7 µA.

R = V/I = 1.2345/0.001 = 1234.5 Ω. Bo'linma: εR = εV + εI = 0.16/1234.5 + 0.7/1000 = 0.013% + 0.070% = 0.083% → δR = 1.03 Ω. R = (1234.5 ± 1.0) Ω.

θ = (R/R0 − 1)/A = 0.2345/0.0039083 = 60.0 °C.

|∂θ/∂R| = 1/(R0·A) = 0.256 °C/Ω → 1.03 · 0.256 = 0.26 °C. Sensor: 0.15 + 0.002·60 = 0.27 °C.

δθ = 0.26 + 0.27 = 0.53 °C. θ = (60.0 ± 0.5) °C.

Nazariy savollar (slaydlardagi "final check" uslubida)

  1. Absolyut va nisbiy noaniqlik farqi nima? Nega nisbiy kerak?
  2. "±(0.003% reading + 0.0007% range)" qanday o'qiladi?
  3. To'g'ridan-to'g'ri va bilvosita o'lchash farqi?
  4. Eng yomon holat modelida nega |…| olinadi?
  5. Yuklama effekti nima? Voltmetr misolida qanday tuzatiladi?
  6. Repeatability va reproducibility farqi?
Javoblar
  1. Absolyut = birlikda (δm), nisbiy = δm/m0. Nisbiy o'lchash sifatini ko'rsatadi (bir xil δ katta qiymatda yaxshiroq).
  2. O'qilgan qiymatning 0.003% i plus shkalaning 0.0007% i.
  3. To'g'ridan-to'g'ri: bitta asbob ko'rsatkichi. Bilvosita: formula orqali boshqa o'lchashlardan.
  4. Xatolar bir-birini kamaytirib yubormasligi uchun: hammasi bir vaqtda eng yomon tomonda bo'lishi mumkin.
  5. Asbob ulanganda o'lchanayotgan sxema o'zgaradi. VO = Vm(1 + RO/RV).
  6. Repeatability: bir xil usul, asbob, operator, sharoitda takrorlash farqi. Reproducibility: turli usul/asbob/operator bilan farq.
